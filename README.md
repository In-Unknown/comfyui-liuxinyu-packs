# ComfyUI liuxinyu 节点包

面向日常工作流的图片、长图、文件路径、字符串、数学和分包子流工具，同时提供工作区文件显示、节点标记、文件同步提示、交互预览、动态端口和虚拟连接等前端功能。适合多目录详情页整理、长图切分与拼接、批次图片挑选保存、提示词组合，以及把多步处理限制在同一个对象范围内。

当前包含 **75 个用户节点**，另有 **7 个由分包与条件循环功能自动创建的内部节点**。下方按用途完整列出名称、用途和节点 ID。中文名称可直接在 ComfyUI 添加节点的搜索框中查找，ID 用于识别 API 工作流和错误报告。

## 环境与兼容范围

| 项目 | 要求或范围 |
| --- | --- |
| ComfyUI | 需要较新的后端及配套前端，支持 `comfy_api.latest`、V3 节点、Autogrow 动态输入。分包还使用原生循环边界和执行调度接口，旧版可能无法加载或执行。 |
| 当前核对环境 | Windows，ComfyUI **0.38.0**（核心提交 `6b747c04`），Python **3.13.14**，PyTorch **2.14.0+cu130**。这是当前核对环境，不是经过兼容性测试得出的最低版本。 |
| Python 依赖 | 复用 ComfyUI 环境中的 PyTorch、NumPy、Pillow、aiohttp；整理节点还使用环境已有的 NetworkX。当前包没有独立 `requirements.txt`，正常 ComfyUI 环境无需另装模型或 API SDK；仅「结构化数据变换（JSONata）」需要额外安装 `jsonata-python==0.6.3`。 |
| 浏览器 | 使用与 ComfyUI 配套的现代浏览器前端。动态端口、图片预览和遮罩编辑器均依赖前端脚本，更新 JS 后需要刷新浏览器。 |
| Windows 专用功能 | 文件/目录选择按钮使用 Windows 原生对话框；“排序字符串数组”的中文拼音排序使用 Windows API；“运行cmd命令”调用 `cmd.exe`。 |
| Linux、macOS、无桌面环境 | 未完成跨平台全量验证，不承诺全功能兼容。可手动输入服务器路径；Windows 选择器、中文拼音排序、cmd 节点不能按 Windows 方式使用。 |
| 计算资源 | 本包不加载生成模型，也不要求独立 API Key。超长图、颜色统计和大规模排列组合可能占用大量内存；下游模型的显卡要求由下游决定。 |

**路径和对话框属于运行 ComfyUI 的电脑。** 在另一台电脑的浏览器访问 ComfyUI，不会让服务器读取浏览器所在电脑的磁盘；文件选择窗口也出现在服务器桌面。

## 安装与更新

### 安装

在 `ComfyUI/custom_nodes` 目录打开终端：

```shell
git clone https://github.com/In-Unknown/comfyui-liuxinyu-packs.git
```

也可下载 ZIP，解压为 `ComfyUI/custom_nodes/comfyui-liuxinyu-packs`。确认目录中直接包含 `__init__.py`，不要多嵌套一层同名文件夹。目录名建议保持不变，部分公共预览资源按此路径引用。

安装后重启 ComfyUI，再刷新浏览器。搜索“字符串转为字面量”或“预览超长图片”，确认节点已经加载。

### 更新

在本包目录运行：

```shell
git status --short
git pull --ff-only
```

如果第一步显示自己的修改，先备份或提交后再更新；提示分支分叉时先检查差异，不要直接强制覆盖。ZIP 安装不能直接 `git pull`，需备份本地修改后替换文件。

更新 Python 后重启 ComfyUI；更新 JS 后刷新浏览器，仍显示旧界面时再强制刷新。只修改 Markdown 帮助文档通常不需要重启后端。

前端扩展随节点包自动加载。工作区、节点标记等全局功能无需添加节点；预览、选图和动态端口在对应节点上使用，完整入口见[前端功能](#前端功能)。

## 快速上手

### 先确认文本节点能运行

1. 添加“字符串转为字面量”，填入 `["苹果", "香蕉"]`。
2. 将第一个 **字面量** 输出连接到“预览参数组合或字符串数组”。
3. 运行，预览中应能看到两项文本，先确认安装和显示正常。

### 查看一张图片或长图

```text
从路径加载图片 → 预览超长图片
```

填写 ComfyUI 所在电脑上的图片绝对路径，或在 Windows 桌面使用选择按钮。运行后点击缩略图进入单图查看；超长或超宽内容可滚动查看。预览不等于永久保存，需要保存时另接保存节点。

本文箭头表示端口连线，**不是可直接导入的工作流 JSON**。表格中的链接提供详细参数说明；已有节点帮助页也可从“选中节点 → 属性面板 → 信息”打开。

## 前端功能

本包既有自动生效的画布与侧栏扩展，也有节点上的交互控件。下面按实际使用场景列出功能；前端脚本和公共模块不计入用户节点数量。新增或更新 JS 后刷新页面，仍显示旧界面时使用 `Ctrl+F5` 强制刷新；仅更新本节文档不需要刷新或重启。

### 工作区、节点辨认与界面修正

| 功能 | 在哪里、怎样使用 | 范围与行为 |
| --- | --- | --- |
| 工作区入口与文件后缀 | 左侧“工作区”按钮；展开目录、查看书签或搜索文件 | 原“工作流”入口及悬停提示、面板标题改为“工作区”，搜索框显示“搜索工作区…”。书签、浏览、搜索结果以及设在侧栏的已打开列表显示真实后缀，例如 `快速设计详情页.json`、`渠道报告系统提示词.md`；不改磁盘文件名。详见[工作区说明](docs/WorkspaceLabels.md)。 |

| 节点 JSON ID 标记 | 节点框外底部左侧，自动显示 `ID: 522` | 对应工作流 JSON 的节点 `id`，方便对照报错和沟通节点位置。覆盖普通节点、子图节点和子图内部节点，折叠后仍绘制标记，复制后跟随新 ID；不改节点标题或数据。 |
| 原始节点名称标记 | 普通节点标题上方，自动显示节点定义中的原始名称 | 即使将节点标题改成业务说明，也能辨认它实际是哪种节点。适用于具备相应绘制接口的节点，不仅限于本包；子图容器自身不加原始名称标记，子图内部普通节点仍显示。标记会避开已有徽标背景，不覆盖自定义标题。 |
| 节点端口显示排序 | 选中节点 → 悬浮端口圆点或文字 → 按 ↑ / ↓ | 与同侧上下相邻端口交换位置；悬浮时显示快捷键提示，无需右键窗口。只影响当前悬浮的已选节点，顺序随工作流保存。端口标签、点击区域与连线落点一起移动，实际索引和连接关系不变。支持经典画布的普通节点与嵌套子图节点；带输入框的端口与控件整行一起移动，多行框按实际高度占位，不重复显示标签。Vue Nodes 模式暂停应用。详见[操作示例、动态端口与保存行为](docs/PortOrder.md)。 |
| 整理节点 | 框选 2～40 个节点 → 右键“整理节点” | 联合调整位置和端口显示顺序，保留节点、参数和连接关系。按固定外部端点约束入口，找到零交叉方案后压缩空白并复核实际端口几何，再一次应用，可撤销、保存。显示实时阶段、尝试数及冲突数量，可取消；等待时缩放、平移不会作废结果。失败列出具体冲突，区分“拓扑不可能”和“暂未找到”。支持经典画布样条连线及当前子图层，不调用付费模型。详见[操作示例、检查范围与限制](docs/GraphLayout.md)。 |
| 节点搜索同步 | 页面初始化、后端重新连接、从浏览器往返缓存恢复页面时自动触发 | 重新获取并注册节点定义，同时更新画布节点注册与现代搜索列表，减少后端已更新而搜索仍旧的情况。后端新增 Python 节点仍须先重启后端；此功能不替代后端加载。 |
| 队列进度浮层布局修正 | 顶部出现队列进度浮层时自动生效 | 将进度浮层放在操作栏下方，避免它撑高顶部布局而挤偏画布框选的裁剪区域。只修正界面布局，不改变任务队列的顺序或执行方式。 |

例如把“字符串转为字面量”重命名为“解析本组回复”后，仍可从上方原始名称标记确认节点类型，再通过下方 ID 与工作流文件中的记录对应。

### 工作流文件变动提示与未保存差异

当外部编辑器、脚本或开发工具改了实际工作流文件，本包会在页面按原生方式恢复后检查文件修改时间，并提示是否同步。

| 入口或操作 | 实际效果 |
| --- | --- |
| 自动“工作流文件有新变动”提示 | 实际文件修改时间晚于上次前端成功保存时间时提示。切换工作流、后端重连、窗口重新获得焦点时检查；页面可见且没有加载或待处理提示时，每 5 秒检查一次。 |
| “同步到实际文件” | 重新读取文件，替换当前页面内容，清除该工作流的旧草稿；等待节点初始化完成后以新画布作为已保存基准。此操作不向后端文件写入内容。 |
| “什么都不做”、关闭提示或按 Esc | 保留当前页面及草稿；同一版文件不再自动提示，文件再次修改后可以再次提示。 |
| 右键画布空白处 → “检查/同步后端工作流文件” | 手动重新检查，即使此前选择过“什么都不做”也可再次选择同步；仍需在提示中确认同步才会替换页面。 |
| 右键画布空白处 → “查看未保存差异” | 对比“已保存基准 → 前端已记录状态”和“前端已记录状态 → 当前画布”，显示变化字段和值；每组最多显示前 60 处，可选中复制。只供定位未保存白点的来源，不保存文件或清除标记。 |

使用例：在外部修改工作流 JSON 后回到浏览器，检查提示中的文件路径，再选择“同步到实际文件”；如果要保留浏览器中尚未保存的编辑，选择“什么都不做”。没有对应实际文件的临时工作流不检查。检测依据文件时间，不是自动合并；外部工具刻意保留或回拨修改时间时无法据此识别变化。详见[工作流文件变动提示](docs/WorkflowFileSync.md)。

### 文件选择、即时预览与选图保存

| 功能 | 对应节点与入口 | 操作及结果 |
| --- | --- | --- |
| 文件与目录选择器 | 加载路径、从路径加载图片、加载文本文件、加载目录、目录匹配、图片保存等节点上的“选择文件”或“选择文件夹” | 打开 Windows 原生对话框，把所选绝对路径填回控件；也可以直接输入路径。对话框在运行 ComfyUI 的机器上打开，不是在远程浏览器所在电脑上打开。 |
| 批次加载的图片多选 | “从路径加载图像批次”上的“选择图片（多选）”及“选择文件夹” | 多选图片后按节点要求填写多路径文本，或选择目录进行加载；不需要手工拼接 CSV。批次统一尺寸规则见[加载说明](docs/LoadImageBatchFromPath.md)。 |
| 路径即时图片预览 | 加载路径、从路径加载图片、从路径加载图像批次 | 直接填写或选择路径后请求预览，不必先执行整条工作流；批次节点修改宽高控件也会刷新。错误会关联到节点，路径修正后清理本次预览错误。路径接入上游时不拿旧控件文字预检，实际内容由执行结果决定；连接上游尺寸时，选图预览不一定等于最终输出尺寸。 |
| 缩略图选中与手动保存 | “从批次中选择保存图片” | 先运行生成预览，再点击缩略图切换选择，绿色高亮表示选中。填写目录和文件名后点击“保存所选”，无需重新执行上游；再次点击保存会追加编号。预览可汇集不同尺寸图片，手动按整个预览列表选择。 |

最小操作：将图片接到“从批次中选择保存图片”，保持“多选序列”和文件夹为空，运行预览；随后选择文件夹、填写 `detail.png`、点击要保存的图片，再点“保存所选”。自动保存序列按每个输入批次的下标解释，和手动预览中的全局选择不同，详见[选图保存](docs/SaveSelectedFromBatch.md)。

### 图片、文本与对象的交互预览

| 功能 | 使用入口 | 交互方式 |
| --- | --- | --- |
| 超长图片浏览 | [预览超长图片](docs/LiuxinyuPreviewLongImage.md) | 多图显示缩略图网格，单击进入单图；超宽图横向滚动，超高图纵向滚动，查看起点由节点方向选项决定。左右方向键切图，Esc 或关闭按钮返回；拖动节点尺寸改变视口。长图缩略图可能只显示开头，进入单图才能看完整内容。 |
| 文本与参数组合表格 | [预览参数组合或字符串数组](docs/LiuxinyuPreviewText.md) | 参数组合按 `t1`、`t2` 等分列，字符串列表按下标显示，单个字符串保留换行。连续滚动浏览，可见行列按需呈现，点击“复制全部”复制内容；普通滚轮滚动表格，`Ctrl+滚轮`缩放画布。 |
| 对象与数组树 | [预览JS对象或数组](docs/LiuxinyuPreviewJSObject.md) | 点击箭头逐层展开，显示键、下标、类型和值；点选条目查看完整内容。“复制JSON”复制整体，“复制此值”复制当前详情，“收起”收拢树；滚轮浏览内容，`Ctrl+滚轮`缩放画布。 |
| 字面量类型提示 | [字符串转为字面量](docs/LiuxinyuStringToLiteral.md)节点内 | 未运行时显示“类型：等待运行”，运行后显示后端返回的解析类型；多项类型去重显示。提示用于理解结果，不改变两个输出口各自的整体/展开语义。 |
| 画笔与蒙版编辑入口 | [绘制蒙版绘制画笔于比例图像](docs/LiuxinyuRatioPaint.md)的“打开遮罩编辑器” | 先执行所需上游并更新底图，再打开官方遮罩编辑器；保存退出后再次运行，才向下游输出合成图像与蒙版。同比例底图复用图层，比例改变需重新绘制；图层文件应随工作流备份。 |

图片预览还共用以下显示能力：

- **流畅缩放与清晰度恢复**：缩放、平移期间优先显示小图，停稳后恢复当前显示尺度需要的清晰度；公共加载队列优先处理视窗中心附近的可见图片。改变的是屏幕预览档位，不是输出图像数据。
- **适应容器的缩略图排列**：根据节点视口和图片比例计算排列，支持末行不满；超长图使用相应的裁切缩略图与行布局。拖动尺寸时重新排版，不要求图片数量能被行列数整除。
- **超长图按可见区域加载图块**：单图按当前缩放与滚动位置加载需要的清晰图块，避免每次查看都绘制整张高清长图。
- **DOM 预览的缩放手柄**：接入公共预览控件的节点在底部两角保留尺寸拖动入口，预览覆盖节点内容区后仍可调整大小。
- **可复用图库**：包内公共图库提供单击放大、左右键切换、Esc/按钮返回和双击打开原图地址等交互；带选择逻辑的节点可改用点击选择。并非给所有 ComfyUI 图片节点统一替换预览，只有接入该基底的节点使用这些行为。

公共模块也可供其他节点包接入；当前另一图片包 `comfyui_mxwq_gpt_image` 的“GPT Image 2 · 中转站图片编辑”可选使用此图库，该节点不属于本包。接入与性能边界见[公共流畅预览](docs/SmoothImagePreview.md)、[缩略图排列规则](docs/ThumbnailGrid.md)。

### 文本控件、动态输入与端口类型

| 功能 | 使用入口 | 实际行为 |
| --- | --- | --- |
| 多行输入连接后收起 | 本包 `Liuxinyu` 系列及 `RunCmd` 的适用多行控件 | 仅在文本框自身对应的输入接到上游时隐藏并收缩高度，断开后恢复，保留框内文字。每次按端口名称判断连接，动态端口重排或重新加载不会串用其他输入的状态；例如模板节点连接 t1 不会隐藏模板框。旧画布高度不足时恢复到可容纳编辑框的高度。只处理能关联到输入口的多行控件。 |
| 动态增加文本块 | [动态多块多行字符串](docs/LiuxinyuDynamicMultilineText.md)的“+ 添加下一个输入框” | 每次新增一组文本框和对应输入/输出，最多 100 块；连入上游后收起该块文本框并使用上游值，断开恢复框内文字。块数与文本随工作流保存。 |

例如将 JSONata 的结果从“字典”改为“数组”，应同时检查下游是否接受 `ARRAY`；不能把仍然可见的业务标题当作输出类型。

## 数组、执行列表和图片批次

三者都能表示“多个”，但决定下游执行几次、在哪一步合并。**只看插口写着 IMAGE 或“数组”，不能确定执行方式。**

| 形式 | 含义 | 例子 |
| --- | --- | --- |
| 完整数组 ARRAY | 多个元素作为一个值传递 | “多个数值组成数组”的 `[0.1,0.2]`，一次提供全部切点。 |
| ComfyUI 执行列表 | 普通下游通常逐项执行，主动收集列表的节点则整体处理 | 匹配路径、长图切片、分包回归结果。 |
| IMAGE 图片批次 | 一个 `[B,H,W,C]` 张量，批内尺寸一致 | 一个值含四张图片；先转为一个执行项后，分包起点仍视为一个整体。 |

执行列表可以装尺寸不同的图片批次。例如两项列表，每项四张图，总计八张图，但分包起点处理的是两包。“批量任意为执行列表”也只重复整体，不拆开批次。

“字符串转为字面量”输入 `[0.1,0.2]`：第一个输出供普通下游依次收到 0.1、0.2；第二个 **完整字面量** 才是一次收到两个切点。更多例子见[数据形式入门](docs/DataLists.md)。

## 典型工作流与分包使用场景

### 多个详情页目录，各自加载、拼接

每个对象经过“拆成子项 → 逐项处理 → 合并”后，再处理下一个对象，防止不同目录的图片被同一个拼接节点合在一起。

```text
目录执行列表 → 分包起点 → 匹配图片路径 → 加载图片 → 拼接图片 → 分包回归 → 预览/保存
                 └────────── 分包回归条件 ─────────────────→ 条件输入
```

1. 用“在绝对路径中的相对路径”生成各产品目录，或用目录匹配筛选子目录，将结果接起点输入1。
2. 起点输出1接另一个目录匹配节点，对象选文件，正则填 `(?i)\.(png|jpe?g|webp)$`，按需设置递归。
3. 路径接“从路径加载图像批次”，例如宽790、高0。每次传入一个文件，各图按自己的比例缩放。
4. 接“从批次列表拼接图片”，选择纵向拼接，再将结果接回归输入1。
5. 起点条件直接连接配对回归的条件输入；回归输出1接预览或保存。

结果是先拼完目录 A，再拼目录 B。**拼接必须放在起点与回归之间**；回归后再接整体收集列表的拼接节点，仍会合并所有结果。

直接让加载节点一次读整个目录，会形成同尺寸批次；只设宽度时也按第一张图计算统一高度。长短不一的详情页应按上例逐文件加载。详见[分包接线](docs/LiuxinyuPacketStart.md)。

### 多张长图，各自切块、处理、再拼回

```text
长图执行列表 → 起点 → 最终切分 → 逐块处理 → 本包拼接 → 回归 → 多张处理后长图
                └──────────── 条件 ────────────────→ 条件输入
```

适用于一个对象的子项需要在内部汇合的任务。“切分预览”带标尺，正式处理选“最终切分”；带重叠的预览块直接拼接会重复内容，并非还原原图。

分包不是任意跳转或无限循环工具。多个输入按位置配对，非空短列表复用末项。嵌套必须为 `A起点 → B起点 → B回归 → A回归`，不支持交叉闭合。需要等待的分支必须接入回归；没有数据输出的保存、预览节点通常放在回归之后。

### 从文本切点到正式裁切

```text
文本 [0.1, 0.2] → 字符串转为字面量（完整字面量） → 切分数组
原图 ──────────────────────────────────────→ 最终切分
```

两刀得到三段：`0～10%`、`10%～20%`、`20%～100%`。也可输入 `[{"percent":10},{"percent":20}]`。先将同一数组接“切分检查图（边界放大）”检查是否切到文字或主体；左右切分时，位置按宽度解释。

### 提示词排列组合

```text
候选组1：[红色, 蓝色] ─┐
候选组2：[杯子, 花瓶] ─┴→ 字符串排列组合 → 从模板生成文本 → 文本预览/下游生成
```

候选可接字符串列表，或输入标准 JSON 数组文本，如 `["红色","蓝色"]`。模板填 `{t1}的{t2}`，两组各两项得到四种组合。普通文本中的逗号/换行不会自动成为多个候选；组合数量是各组长度的乘积，先用少量候选确认。

需要接收记录、读取多个位置或给对象补字段时，可按当前数据形状选择工具。文本解析、列出记录路径、展开赋值方案、多项读取和批量插入均可独立使用；输入来源与后续用途由工作流决定。

## 缓存、预览与文件保存

| 内容 | 位置与生命周期 |
| --- | --- |
| 处理结果缓存 | ComfyUI 缓存配合文件内容检查；输入或参数变更时重新处理，不变时尽量复用。 |
| 临时图片预览 | ComfyUI 配置的 temp 目录；每个预览节点保留最近一组，成功替换后清理旧组，旧执行历史的临时图可能失效。 |
| 永久结果 | 保存节点指定的路径，不会被预览缓存清理。 |
| 比例绘制图层 | ComfyUI input 中的 `liuxinyu_ratio_paint` 及官方编辑器相关文件，是继续编辑所需素材，应随工作流备份。 |
| 文本和节点设置 | 随工作流保存；路径指向的源文件不会自动打包进工作流。 |

预览的小图用于减轻缩放和平移负担，停稳后恢复显示尺度所需清晰度，不代表永久结果被缩小。临时 PNG 保留输入像素，实际保存质量还取决于输出格式，如 JPEG 本身有损。

本包预览缓存是**进程内、最近结果复用**，不是跨重启的持久断点。永久保存不随取消自动撤销；同样输入可能不重复自动保存，手动“保存所选”仍按每次点击追加。详见[缓存说明](docs/ImageCache.md)。

文件读写和 cmd 使用 ComfyUI 进程的权限。导入别人提供的工作流时，先检查绝对路径、覆盖选项和实际命令；目录属性表达式也只适合可信输入。

## 常见问题排查

| 现象 | 优先检查什么 |
| --- | --- |
| 搜不到节点或启动导入失败 | 检查目录层级、是否重启；看启动日志 `[comfyui-liuxinyu-packs]` 后的异常。缺少 V3、Autogrow、循环接口时检查核心及前端版本。 |
| 缺少 torch、PIL、numpy | 确认使用的是 ComfyUI 的 Python，修复该环境依赖；不要只装到另一套 Python，也不要为本包随意替换 CUDA/PyTorch。 |
| 动态输入、按钮或预览失效 | 刷新/强制刷新，检查 F12 控制台及 `/extensions/comfyui-liuxinyu-packs/` 资源；避免安装多份包或使用陈旧前端。 |
| 文件选择无反应、远程浏览器没有对话框 | 窗口依赖 Windows 桌面，出现在运行 ComfyUI 的机器；可手动填服务器绝对路径。 |
| 目录匹配后没有图片 | 检查文件/目录选项、递归、名称匹配或完整路径；目录不存在、无匹配或错误正则可能返回空列表。 |
| 图片拉伸或提示比例不一致 | 批次要求同尺寸；宽高均0时要求比例一致，只设一边时以第一张图计算统一另一边。保留不同高度时逐文件加载。 |
| 多个详情页变成一张长图 | 拼接收取了整个列表，将“匹配 → 加载 → 拼接”放进一对分包起点/回归之间。 |
| 分包没按批次内张数循环 | IMAGE 批次整体算一个值，需先转为逐张图的执行列表；重复节点不负责拆图。 |
| 分包报缺少回归、缺输入或交叉闭合 | 条件直接配对，输出编号对应输入，需等待的分支接回归；嵌套按 A/B/B/A 闭合。 |
| 切分数组错误或只收到一个切点 | 接“完整字面量”输出；数值切点在0与1之间，对象形式使用 `percent`。 |
| 切换工作流后缩略图一直模糊 | 等画布停止缩放/平移，检查图片请求及控制台；确认前后端已更新后强制刷新，仍复现时记录操作步骤。 |
| 超长图拼接、编码或保存内存不足 | 降低加载宽度、拆分处理、减少同时驻留的大图；理论格式上限不保证内存/编码器能处理，拼接的格式选项也不负责保存。 |
| 重跑没有新增保存、历史预览失效 | 可能是缓存复用或旧临时图已替换。永久结果需显式保存，不把 temp 当素材备份。 |
| 比例绘制报图层丢失或笔迹消失 | 确认 input 配套图层还在；比例改变会启用空白层，编辑器保存后需再次运行。 |
| 数学运算报错 | 检查除数、对数底数/真数、开根及反函数定义域；阶乘需非负整数，三角函数确认角度单位。 |
| Linux/macOS 中文排序、cmd 报错 | 相关路径使用 Windows API/命令，当前没有跨平台替代实现。 |

先用一张图、两个目录或两三个候选重现，再扩大数据量。单纯文档更新无需重新跑大型生成工作流。

### 开发检查

后端测试依赖 ComfyUI 模块，应使用其实际 Python。Windows 便携版在便携版根目录运行：

```powershell
.\python_embeded\python.exe -X utf8 -s -m unittest discover -s ComfyUI\custom_nodes\comfyui-liuxinyu-packs\tests -v
```

前端逻辑测试需要 Node.js，在本包目录用 PowerShell 执行：

```powershell
Get-ChildItem tests\*.cjs | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { throw "前端测试失败" } }
```

测试覆盖分包顺序/嵌套、图片切分、保存、缓存、像素/数学和预览生命周期等。模拟前端测试不能代替真实浏览器的视觉、性能和交互验证，也不代表所有版本及系统都兼容。
