# 数字取整

把整数或浮点数转成 INT 整数，适合把尺寸、坐标等数学计算结果接到要求整数的节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `数值` | 要取整的数字，须为有限数字 | INT / FLOAT | 是 |
| `方式` | 取整规则：四舍五入（默认）/ 向上取整 / 向下取整 / 截断小数，详见下表 | COMBO | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `整数` | 取整后的 INT 结果，可接目标宽高、像素坐标等 INT 输入；上游接执行列表时逐项各算一次 | INT |

## 取整规则

| 方式 | 2.5 的结果 | -2.5 的结果 | 规则 |
| --- | --- | --- | --- |
| 四舍五入 | 3 | -3 | 恰好一半时远离零 |
| 向上取整 | 3 | -2 | 向正无穷取整 |
| 向下取整 | 2 | -3 | 向负无穷取整 |
| 截断小数 | 2 | -2 | 丢弃小数部分，朝零 |

## 例子

宽度 791 乘 0.5 得到 395.5，接本节点选四舍五入得到 396。想保证尺寸不超过计算值，可选向下取整。

“向上”不等于让绝对值变大；对负数，向上得到的是更接近零的整数。输入须是有限数字，文字须先转换为数值。
