# 三角与反三角函数

选择 sin、cos、tan、asin、acos、atan 计算，输入一个数字，输出 FLOAT。用于周期变化、角度与坐标换算。

## 角度单位怎么选

- 普通三角函数 sin/cos/tan：角度单位表示输入数字的单位。
- 反三角函数 asin/acos/atan：输入是比值，角度单位表示输出角度的单位。
- “角度”以一周 360 度计；“弧度”以一周 2π 计，π≈3.14159265。

| 函数 | 示例 |
| --- | --- |
| sin | 30，选角度 → 约 0.5 |
| cos | 60，选角度 → 约 0.5 |
| tan | 45，选角度 → 约 1 |
| asin | 0.5，选角度 → 约 30 |
| acos | 0.5，选角度 → 约 60 |
| atan | 1，选角度 → 约 45 |

例如圆周上的 X 偏移可用“半径 × cos(角度)”计算，Y 偏移用“半径 × sin(角度)”计算，再接乘法节点。

## 范围和注意事项

asin/acos 输入必须在 -1～1 之间。asin 输出主值为 -90～90 度，acos 为 0～180 度，atan 为 -90～90 度之间。

tan 在 90 度加整数倍 180 度处无定义，浮点计算可能返回极大的有限值，不能将它当作准确答案。三角函数允许常规浮点误差。
