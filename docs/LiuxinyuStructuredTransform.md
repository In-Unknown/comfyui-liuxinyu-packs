# 结构化数据变换（JSONata）

按照 JSONata 表达式查询、筛选、分组、关联或重组 JSON 数据，并检查结果是否符合所选类型。适合明确知道处理规则、需要组合多路数据的工作流；不包含商品、分类、模型回复等特定业务规则。

只有一个数据结果出口，输出原生数据，不附带一份重复的 JSON 文本。需要序列化时，再接「JS对象转换为字符串」；只需要读取一个字段时，也可以直接使用「使用js点符号语句读取对象」。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `data0`、`data1`… | 每路是一个完整 JSON 值。表达式中按编号访问；端口随连接增加，最多 100 路 | DICT / ARRAY / STRING / INT / FLOAT / BOOLEAN / NULL | 至少一路 |
| `JSONata 表达式` | 指定处理规则，可多行；默认 `data0`，返回第一路输入的独立副本 | STRING | 是 |
| `结果类型` | 字典、数组、字符串、整数、浮点数、布尔值或空值。默认字典；决定结果端口类型，并在运行时严格核对 | COMBO | 是 |

输入端口只接受上述 JSON 类型，连接具体类型后跟随上游显示该类型；断开后恢复 JSON 类型集合。未知类型的上游仍需通过运行时检查。图片、模型、张量等不属于支持的数据。

结果类型在节点上固定选择，不能通过连线动态改变。表达式可以通过连线提供，但每轮结果必须符合固定的结果类型。更改结果类型会立即更新结果端口，并断开不兼容的下游连接。

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `结果` | 成功时输出符合所选类型的一个完整值；数组不会自动拆成执行列表。失败时不发送占位数据，此结果分支跳过执行 | 由结果类型确定 |
| `执行成功` | 表达式得到一个结果，且输入、结果和结果类型检查全部通过时为 true；否则 false | BOOLEAN |
| `错误信息` | 成功时为空字符串；失败时说明输入问题、表达式错误或结果类型不符 | STRING |

结果本身为 `false`、`0`、`""`、`[]`、`{}` 或显式 `null`，都可以是成功结果。例如结果类型选布尔值，表达式为 `false`，输出是 **结果 false、执行成功 true、错误信息空文本**。

## 直接照做：数组求和

1. 将完整数组 `[10,20,30]` 接入 `data0`。
2. 表达式填 `$sum(data0)`。
3. 结果类型选「整数」。
4. 输出结果 `60`，执行成功 `true`，错误信息 `""`。

上游如果是逐项执行的列表，先接「执行列表收集为数组」。本节点不会替你收集执行列表；直接连接时会按 ComfyUI 的执行列表规则逐项运行。

## 常用表达式

| 输入例子 | 表达式 | 结果类型 | 结果 |
|---|---|---|---|
| `data0={"name":"杯子"}` | `data0.name` | 字符串 | `"杯子"` |
| `data0=[10,20,30]` | `{"合计":$sum(data0)}` | 字典 | `{"合计":60}` |
| `data0=[{"price":5},{"price":20}]` | `[data0[price > 10]]` | 数组 | `[{"price":20}]` |
| `data0=[{"percent":2},{"percent":3},{"percent":1}]` | `$sort(data0,function($a,$b){$a.percent > $b.percent})` | 数组 | `[{"percent":1},{"percent":2},{"percent":3}]` |
| `data0={"a":1}`，`data1={"b":2}` | `$merge([data0,data1])` | 字典 | `{"a":1,"b":2}` |
| 任意合法输入 | `false` | 布尔值 | `false`，执行成功仍为 true |
| 任意合法输入 | `null` | 空值 | `null`，执行成功为 true |

`$merge` 的重复键行为由 JSONata 定义，后面的值覆盖前面的值。需要遇到重复键就拒绝时，可使用「并和数组中的字典字段为字典」。

## 数组、单项与无结果

JSONata 的查询序列不等于固定类型的数组。`data0[price > 10]` 没有匹配项时可能没有结果，只有一项时可能得到字典，多项时才得到数组。

需要稳定的数组输出，请写 **`[data0[price > 10]]`**，并选择「数组」：零项得到 `[]`、一项得到 `[对象]`、多项得到 `[对象,对象]`。本节点不会自动把字典包成数组，也不会把无结果改成空数组。

字段不存在与显式 `null` 会区分：读取不存在的字段会失败；表达式 `null` 或读取值为 null 的已有字段，选择「空值」可以成功。需要自定义默认值时可写 `$exists(data0.name) ? data0.name : "未命名"`。

## 类型与数据范围

- 字典键必须是字符串。整数键、布尔键等直接失败，不先转成字符串，以免键冲突导致数据丢失。
- 数组使用原生列表。元组、集合、张量、自定义对象和循环引用不接受。共享但不成环的数据可以输入；输出是独立副本。
- 字符串按字符串处理。输入 `"{\"a\":1}"` 不会自动解析为字典；先使用 JSON 解析节点，或在表达式中明确处理。
- 字典、数组内部可以包含 null。「空值」的 NULL 出口仅供支持该类型或通用数据的下游使用。
- 整数、浮点数、布尔值严格区分，不互相转换。底层 JSONata 可能把整数值的运算结果表示为整数，例如 `1 / 1` 得到整数 `1`，应选择整数；选择浮点数而实际得到整数会失败。
- 输入和结果中的整数必须位于 `[-9007199254740991,9007199254740991]`。超出范围会失败，避免 JSONata 浮点运算造成静默精度损失；长编号应使用字符串。该限制不代表浮点计算具有十进制精确性。
- 浮点数必须有限；NaN、正负 Infinity 不接受。表达式生成的非 JSON 数据也会失败。

## 失败之后如何继续

表达式语法错误、`$assert` 失败、字段不存在、结果类型不符、数据不支持和缺少依赖，都返回 `执行成功=false` 与错误信息。节点不把这些运行失败直接升级为全局报错。结果出口的下游跳过，状态和错误信息仍可正常使用。端口连入不支持的类型、结果类型配置非法等接线错误会在提交执行前被拒绝。

### 明确停止

执行成功 → Not →「条件为真时报错停止」；错误信息接停止节点的错误信息。需要让后续操作等待检查时，用停止节点的「继续执行」控制切换节点，再放行结果。当前电商分类工作流使用这条显式停止线路。

### 使用备用值

当前 ComfyUI 的原生 If/Else Switch 会传播已经缓存的执行阻断标记，即使该标记来自未选中的分支。因此，不要将失败的结果出口直接与其状态一起接入同一个备用切换节点。

可用两个现有切换节点隔开依赖：

1. 切换 A 的条件固定为 true，「为真时」接本节点结果。
2. 切换 B 的条件接执行成功，「为真时」接 A 的输出，「为假时」接备用值。
3. 下游接 B。失败时 B 只读取备用值，A 不运行；成功时通过 A 取结果。A 不要另接会被执行的消费者，否则其缓存的阻断标记仍会影响 B。

这个接法已用真实执行器验证。备用值也应符合下游所需类型。

### 重试

将执行成功和错误信息用于条件循环，保留原输入供下一轮重新处理。失败时不要把结果分支当作下一轮数据，因为该分支已跳过。重试次数、输入修正和重新生成由外部工作流决定。

不连接状态处理分支时，失败不会输出伪装成成功的空数组或空字典；结果的消费者会跳过。希望每次失败都明确报错，就接上述停止线路。

## 依赖与迁移

ComfyUI 的 Python 环境需要 `jsonata-python==0.6.3`。本节点不执行 Python、系统命令或文件操作。

旧版第二个输出是 JSON 文本；新版第二个输出改为执行成功，第三个输出为错误信息。旧工作流应重新核对端口并选择结果类型，原 JSON 文本连接需要改接独立序列化节点，不能把旧第二出口当成新状态出口。当前电商分类子图已同步迁移：三处均选择数组，并显式连接失败停止线路。
