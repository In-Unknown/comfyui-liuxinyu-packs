# 结构化数据变换（JSONata）

用 JSONata 表达式对 JSON 数据做查询、分组、关联或变换。适合聚合执行列表结果、按条件筛选、把多路数据拼成新结构。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `data0`、`data1`… | 参与变换的数据，每个输入应为一个完整值；在表达式中按编号访问。端口随连接增加，最多 100 路 | ANY | 是（至少一路） |
| `JSONata 表达式` | JSONata 查询表达式，默认 `data0` 即原样输出第一路输入，支持多行 | STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `结果` | 变换结果，保留原始类型（数字、数组、对象等）；一个完整值，即使结果是数组也整体传递，不会自动拆成逐项执行的列表 | ANY |
| `JSON文本` | 结果的紧凑 JSON 文本；同样是一个完整值，不会逐项执行 | STRING |

## 准备工作

需在 ComfyUI 的 Python 环境中安装 `jsonata-python==0.6.3`。未安装时运行会报错：请在 ComfyUI Python 中安装 jsonata-python==0.6.3。

## 直接照做：给数组求和

1. “执行列表收集为数组”的“完整数组”接 `data0`。
2. “JSONata 表达式”填 `$sum(data0)`。
3. 运行后“结果”输出数字，“JSON文本”输出如 `6`。

## 输入规则

每个输入应为一个完整值。执行列表直接接入会按列表规则多次运行本节点，需要整体处理时先经“执行列表收集为数组”。输入在参与计算前会经 JSON 往返转换：张量等无法 JSON 序列化的内容会被拒绝，同时避免本节点修改上游对象。字典、数组、数字、字符串、布尔值都可以接。

## 表达式示例

| 表达式 | 作用 |
| --- | --- |
| `data0.name` | 取字段 |
| `data0[price > 10]` | 筛选数组 |
| `$sum(data0)`、`$count(data0)` | 聚合 |
| `$sort(data0, function($v){$v.percent})` | 按字段排序 |
| `{"合计": $sum(data0), "明细": data0}` | 重塑结构 |

JSONata 只做数据变换，不执行 Python、系统命令或文件操作。表达式写错或数据不匹配时报 `JSONata 数据变换失败：…`，按提示检查字段名和语法。“JSON文本”可直接接下游文本节点保存或查看。
