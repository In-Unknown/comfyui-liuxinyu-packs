# 组装任意为数组

把多个同类型的值按输入编号组成一个完整数组。成员类型可以选择字符串、整数、浮点数、布尔值、字典、数组、图片批次或其他节点对象，但同一次组装不能混用不同类型。适合打包多个同类对象，整体交给支持 ARRAY 的下游。

节点 ID：`LiuxinyuAnyArray`；分类：`utils/conversion`。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `任意值 1`、`任意值 2`… | 初始一个备用输入口；连接末尾口后自动追加一个，无固定数量上限。首次连接确定类型，全部输入同步限制为该类型；全部断开后恢复 ANY。按输入编号顺序组装，未连接口不占位置。没有文本框或隐式默认值 | ANY → 成员的实际端口类型 | 否 |

断开中间端口时保留空位及后续编号，避免把已有连线移到其他输入；末尾多余的空口会收起，只留一个备用口。端口的视觉排序不会改变输入编号的组装语义。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `完整数组` | 按编号收集本次各输入值，新建一个外层数组；每项原样保留。不拆成执行列表，没有输入时输出 `[]` | ARRAY |

## 直接照做：组装多个字典

1. 字典 `{"渠道":"综合"}` 接“任意值 1”；已有及新增输入口都会显示并限制为 DICT。
2. 字典 `{"渠道":"销量"}` 接自动出现的“任意值 2”。
3. “完整数组”接“预览JS对象或数组”，或接 JSONata 的 `data0`。

结果为：

```json
[{"渠道":"综合"},{"渠道":"销量"}]
```

此时 STRING、INT 等不同类型不能接入。如果要改为字符串数组，先断开全部输入，再连接字符串。只接一个数组 `[3,4]` 时输出 `[[3,4]]`，不会展开成 `[3,4]`。

## 成员类型锁定与校验

- 类型限制作用于全部输入，包括末尾新增加的备用口；断开部分输入后，仍按剩余已连接输入限制类型。上游明确改变类型、与其他成员冲突时，断开这条冲突连接。
- `INT`、`FLOAT`、`BOOLEAN` 是三种不同类型；不因为 `1` 与 `1.0` 数值相等就允许混用，不自动转换。
- 多个数组输入的成员类型都是 `ARRAY`，允许内部形状及内容不同；多个字典也不要求字段相同。这是外层成员类型约束，不递归限制内部结构。
- 上游端口若自身声明为 `ANY（*）`，连线阶段无法知道它运行后返回什么；多类型端口只可先取共同的候选类型。后端会检查已知来源类型，并在执行时严格检查实际成员的 Python 类型，拒绝隐藏在 ANY 后面的混合类型，不生成混合数组。
- 空值也有自己的类型：多个空值可组成 `[null,null]`，空值不能与字符串、字典等混合。未接线则完全不占数组位置。

## 类型、嵌套与图片

| 输入 | 输出 |
| --- | --- |
| 整数 `2`、整数 `3` | `[2,3]`，保持整数 |
| 整数 `2`、浮点数 `3.5` | 类型不同，不允许组装 |
| 空字符串、字符串 `文案` | `["","文案"]`，空字符串不被丢弃 |
| `false`、`true` | `[false,true]`，保持布尔值 |
| `[1,2]`、`[3]` | `[[1,2],[3]]`，各数组保持完整 |
| 一个含 4 张图的 IMAGE 批次 | `[<4图批次>]`，一项，不拆图、不拼接、不编码 |

新建的是外层数组，内部对象保持原引用，不深拷贝，也不修改输入。任意类型并不意味着一定可转为 JSON：含图片张量或专用对象的数组仍需要兼容这些值的下游。

## 与执行列表及其他组装节点的区别

本节点是普通逐项执行节点。若第一个输入是整数执行列表 `1、2`，第二个是单值整数 `9`，ComfyUI 会执行两次，依次产生 `[1,9]` 和 `[2,9]` 两个完整数组；不会自动收集成 `[1,2,9]`。多路执行列表依照 ComfyUI 的列表对齐规则运行，较短的非空列表重复末项，不计算笛卡尔积。每次执行分别校验成员类型。

| 需求 | 节点 |
| --- | --- |
| 多个同类型独立值组成数组，保留类型和嵌套 | 本节点 |
| 将某一路的全部执行项一次收成数组 | [执行列表收集为数组](LiuxinyuCollectExecutionList.md) |
| 多个数字组成数组，混合输入统一为浮点数 | [多个数值组成数组](LiuxinyuNumberArray.md) |
| 字符串专用组装及字符串列表合并 | [组装字符串为字符串数组](LiuxinyuStringArrayBuild.md) |

更多执行语义见 [数组、执行列表与图片批次](DataLists.md)。

## 常见问题

- 输出明确是 `ARRAY`，不能直接接 LLM 的 STRING 提示词。JSON 兼容内容可先经 JSONata 的 `$string(data0)`，结果类型选“字符串”，再连接提示词。
- 一个输入数组只占一项；本节点不会自动展平、合并字典字段、去重或排序。
- 上游失败或阻断时，遵循 ComfyUI 的执行机制，不把失败替换为空值，也不跳过失败项继续生成残缺结果。
- API 输入名为 `value0`、`value1`…，按数字后缀排序，允许中间编号空缺。其他输入名会报“未知任意值输入口”。
- Python 新节点需重启后端，动态端口前端需刷新页面后生效。
