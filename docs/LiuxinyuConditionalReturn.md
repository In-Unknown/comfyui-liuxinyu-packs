# 条件回归

连接「跳回点」的调回句柄后，自动出现与起点对应的数据输入和输出，端口类型跟随起点。标签会显示具体类型，如「输入 1 · IMAGE」「输出 2 · INT」。输入和输出的实际连接类型同时改变，不仅是标签变化；不兼容的连线不能连接。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `调回句柄` | 直接连接配对跳回点的同名输出 | HANDLE | 是 |
| `跳回循环（true）/ 进入下游（false）` | true：携带本轮数据跳回，再执行一轮循环；false：结束本循环，输出本轮结果并执行下游节点 | BOOLEAN（默认 false） | 是 |
| `输入 1`、`输入 2`…… | 本轮处理结果，与起点已连接输入的编号和类型一一对应；端口随连接增加，最多 100 个 | ANY | 否（与跳回点已连接输入对应） |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `输出 1`、`输出 2`…… | 循环结束时最后一轮的对应结果，编号与输入一一对应；上游接执行列表时下游逐项处理 | ANY |

每轮先等待本节点所有已连接输入完成，再根据布尔值选择执行方向：

- **true：跳回并重跑循环。** 把本轮输入的数据送回配对的「跳回点」，再执行一轮两节点之间的处理。此时不执行「条件回归」输出之后的下游节点。
- **false：离开循环，执行下游。** 不再跳回，把本轮更新后的数据从对应输出传给下游节点，下游正常执行。结束的只是这一层循环，**不是停止整个工作流**。

无论最后执行了多少轮，下游收到的都是 false 所在这一轮的结果，不会退回最初输入的数据。

例如同时反馈图片和计数器：起点输入 1 是 IMAGE，输入 2 是 INT；回归输入 1 接更新后的图片，输入 2 接加一后的整数，布尔输入接根据最新结果计算的“是否再跳回一轮”。每轮需要保持的状态都应设置一个对应输入；没有变化的值也需要接回。

初次添加只有句柄和布尔输入。若没有出现数据端口，先连接起点初值和句柄；更新节点包后需重启 ComfyUI 并刷新浏览器。改动起点类型或移除句柄时，不再兼容的回归连线会断开，需要检查并重新连接。

数组、字典和图片批次整体反馈；空或多项执行列表需先合并或在外层分包。缺少对应输入、类型变化、交叉闭合都会报错。条件始终为 true 时，10,000 轮后报错，也可手动中断。

完整接线、嵌套和使用场景见 [跳回点](LiuxinyuReturnPoint.md)。节点 ID：`LiuxinyuConditionalReturn`。
