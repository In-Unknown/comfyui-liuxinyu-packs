# 在绝对路径中的相对路径

把相对路径拼接到绝对路径上并规范化。纯字符串计算，不访问文件系统，路径不存在也能计算。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `绝对路径` | 作为基准的绝对路径。只有端口，必须连接上游字符串输出。 | `STRING` |
| `相对路径` | 相对于基准路径的部分。可手动填写，也可连接上游。 | `STRING` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `绝对路径` | 拼接并规范化后的完整路径。 | `STRING` |

## 支持的写法

- `b\c.png` — 普通子路径
- `..\d.txt` — 上一级
- `.\x.jpg` — 当前级
- `sub/../other/file.png` — 混合 `..` 与 `.`
- `../../../../y` — 多层向上，超过根目录时在根处截断

## 使用示例

| 绝对路径 | 相对路径 | 输出 |
| --- | --- | --- |
| `C:\project\a` | `b\c.png` | `C:\project\a\b\c.png` |
| `C:\project\a\b` | `..\d.txt` | `C:\project\a\d.txt` |
| `C:\project\a` | `sub/../other/file.png` | `C:\project\a\other\file.png` |

## 一次准备多个目录

本节点每次处理一个相对路径，不会把输入框里的 JSON 文本自动拆成多个路径。

1. 在“字符串转为字面量”里写 `["产品A", "产品B"]`。
2. 用第一个“字面量”输出连接本节点的“相对路径”，让它逐项执行。
3. 将基准目录字符串如 `D:\详情页素材` 接“绝对路径”。
4. 输出依次为 `D:\详情页素材\产品A`、`D:\详情页素材\产品B`。

只需要单个子目录时，直接在相对路径输入框填 `产品A`，不用加引号或方括号。多个目录分别拼接图片时，输出接“分包执行子流回归”，让各目录内部完成匹配、加载、拼接。

## 注意事项

- 相对路径为空时，只对绝对路径做规范化。
- 绝对路径为空时返回空字符串。
- 为了拼在基准目录之下，相对路径开头不要写斜杠或盘符。Windows 上以 `/` 或 `\` 开头会从当前盘的根目录重新定位；带完整盘符的绝对路径会替换基准目录。
- 不检查路径是否真实存在，也不会因为路径不存在而报错。
