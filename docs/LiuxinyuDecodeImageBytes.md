# 图像字节解码为图像

将编码图像字节恢复成普通ComfyUI图像，并单独输出透明遮罩。适合把字节输入交给裁切、拼接或绘图节点；不更改原始文件，也不保存文件。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `图像字节` | 一个完整可解码的图像文件bytes；支持执行列表，不接受任意未验证BYTES、路径或Base64文本 | IMAGE_BYTES | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `图像` | RGB浮点张量，范围0～1；每帧一个 `[1,H,W,3]`，按帧顺序输出执行列表 | IMAGE |
| `透明遮罩` | 与图像逐项对应的 `[1,H,W]`；1完全透明、0不透明，保留半透明；不透明图片全0 | MASK |

## 怎么用

1. “从路径加载字节数据”读入 `C:\images\logo.png`。
2. 接“字节数据提取图像字节”，选择PNG，将验证后的字节接本节点。
3. “图像”接普通预览、裁切或拼接节点。若要重新编码并保持透明，将“图像”和“透明遮罩”分别接“图像张量编码为图像字节”的同名输入，选PNG、开启保留透明度。
4. 例如一张100×80透明PNG得到图像形状 `[1,80,100,3]`、遮罩形状 `[1,80,100]`；完全透明处遮罩值为1。

## 帧顺序与方向

多帧或多页文件按原顺序输出，不拼成同尺寸批次，因此不同帧尺寸可不同。EXIF方向会应用到像素；90度方向标签可使宽高互换。逐帧输出不携带动画时间，不能自动重建原动画。

## 精度、颜色和缓存

输出8位解码像素归一化后的RGB与MASK；不是HDR/16位无损解码工具，不做ICC色彩空间管理。仅“图像”输出没有Alpha，透明信息在第二个输出。转换使用ComfyUI缓存；原字节仍由上游持有，需要原样保存时直接连接字节输出，不必先解码。

## 常见问题

图片字节必须能完整解码，损坏、截断、空输入会报错。支持格式取决于当前Pillow；如上游只提供任意BYTES，先接提取节点验证。完整类型、动画与保存语义见[图像编码与字节数据](ImageBytes.md)。
