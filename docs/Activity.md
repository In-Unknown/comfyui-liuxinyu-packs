# 活动节点总览

在右侧“工作流总览”的第一个 **活动** 标签中集中查看正在运行的节点。无需逐层进入子图，也无需添加监控节点。列表使用运行中的真实节点状态，显示只读节点镜像；点一下镜像，即可定位它在画布中的实际位置。

适合并发生成、多层子图和长时间等待回复的工作流。活动页负责展示节点已有的内容；“等待首字”“正在生成”“等待审核”等具体文字仍由对应节点提供，不根据停留时间猜测执行阶段。

## 入口与操作

1. 更新本包前端文件后刷新 ComfyUI 页面，无需重启后端。
2. 在未选中节点时打开右侧“工作流总览”，点击位于“参数”前面的“活动”。
3. 开始一次工作流执行时，侧栏会自动打开、取消当前节点选择并切到全局活动页。该操作只在每次执行初始开始时触发，后续节点开始、状态变化和文本更新不会反复切换标签。
4. 正在运行的节点自动加入，完成的节点自动移除。没有活动节点时显示“当前没有正在运行的节点”。
5. 点击任一镜像，或用键盘 Tab 选中后按 Enter／空格，进入对应子图并居中查看原节点。镜像内部的按钮、输入框和审核控件不执行操作；需要操作时在定位后的原节点上进行。

运行期间可以关闭侧栏或切换其他标签，不会因为每个新节点运行而反复打开。正常结束或中断后恢复执行开始前的侧栏状态；报错时让原生错误界面接管，具体规则见下节。浏览器在后台时暂停镜像绘制，回到页面后继续更新。

活动入口与“参数”等按钮位于同一个原生标签组。普通、悬浮、键盘聚焦、选中以及按下效果沿用当前前端标签的样式类；活动页的全局标题、标签组和关闭图标也复用原生结构，不另设一套按钮配色或动画。

## 执行结束后的侧栏恢复与错误优先

自动打开活动页前，记录侧栏是否展开、原生标签以及是否正在看活动页。完成或中断后恢复这份状态，不以运行期间自动打开的活动页作为恢复目标。

| 执行前状态 | 正常完成或中断后的行为 |
| --- | --- |
| 侧栏收起 | 再次收起，并保留原来选择的标签 |
| 侧栏展开，查看参数、节点、设置等其他标签 | 保持展开并切回原标签 |
| 侧栏展开，正在查看活动 | 保持活动页，已结束的节点从列表移除 |

运行期间主动切换其他标签不影响这份运行前快照；正常完成仍按表恢复。重复的开始或结束通知不会重复覆盖快照或恢复。多个执行重叠时，保留首次开始前的状态，等这些执行全部结束后恢复。若已经切换到另一个工作流，旧工作流的完成通知不会恢复它的侧栏状态。

**错误优先于恢复。** 收到执行错误时，立即移除活动页对原生内容的覆盖，取消本次恢复，不主动关闭侧栏，也不把原生标签切回运行前位置。错误提示、错误标签是否打开及其定位继续由 ComfyUI 原生功能处理；活动页不拦截错误事件。之后迟到的成功或中断通知也不会把错误页切走。

点击原生“查看错误”等入口打开 `errors` 标签时，同样立即让出显示，包括原生底层已经选中错误标签、上面仍显示活动页的情况。原生标签值直接切换到错误页时也会让出显示。即使运行前本来就在活动页，发生错误也优先展示原生界面；用户之后仍可手动切回活动。

记录只保存在当前页面内存中。刷新或重连时若仅恢复到正在执行的任务、没有经历本页的自动打开步骤，则没有可恢复的运行前快照，不猜测刷新前的标签。

## 输入

本功能是前端总览，没有节点输入端口。

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `执行状态` | 自动读取 ComfyUI 的运行事件。支持完整运行状态快照；只提供旧 `executing` 事件的环境按该事件报告当前节点 | 前端执行事件 | 自动读取 |
| `当前工作流` | 从当前主图及其实际实例化的嵌套子图查找节点，通过完整显示路径对应运行状态。不读取磁盘上其他工作流 | 画布图对象 | 自动读取 |
| `节点显示内容` | 读取节点绘制方法、控件当前值和已有 HTML 内容，包括节点扩展提供的状态、流式文字及图片 | 画布与 DOM 状态 | 自动读取 |
| `连续跟踪` | 仅在节点对象稳定超过 2 秒且高度连续变化时显示；默认开启，关闭后停止自动滚动。当前页面内保留选择，刷新后恢复默认 | BOOLEAN（前端开关） | 否 |

## 输出

没有节点输出端口，不发起额外生成请求，也不创建第二个执行节点。

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `活动镜像` | 只读显示正在运行节点的标题、端口、控件、预览和绘制标签；按可用宽度从左至右、从上至下排列 | 前端视图 |
| `定位视图` | 点击后复用 Ctrl+F 查找节点的定位函数，逐层进入目标图、选中并居中节点 | 画布视图状态 |
| `兼容提示` | 绘制接口缺失或节点绘制失败时显示提示，并保留点击定位入口；不存在原生总览侧栏时提示无法挂载 | STRING |

## 使用示例

假设工作流有两个同时等待回复的 LLM 节点：主图中的 `15`，以及子图 `771` 内子图 `745` 中的 `729`。

1. 点击 ComfyUI 运行，右侧自动切到“工作流总览 → 活动”。
2. 后端报告两个节点正在运行时，活动页显示两张镜像。LLM 节点已有的状态文字和回复内容随源控件更新，不需要先定位该节点。
3. 点击 `729` 的镜像，共用定位函数沿 `771:745:729` 打开子图并居中原节点。
4. 定位期间，`15` 如果完成就从活动页移除，新开始的节点仍可加入。定位不会等待活动列表暂停，也不以定位完成为条件恢复侧栏。
5. 若 `729` 等待人工审核，点击镜像定位后，在原节点上执行审核；镜像中的审核按钮不触发操作。

## 运行集合、重试与缓存

- 以 ComfyUI 报告的 `running` 状态决定成员，不根据节点是否进入当前视口判断。因此切换到其他子图不会把仍在执行的节点移除。
- 并发状态快照可以同时包含多个节点。循环展开产生的临时执行编号优先映射到 `display_node_id`；同一显示节点有多个同时运行的临时实例时只显示一张镜像。
- 首次加入的顺序保持稳定。运行完成、失败或中断后清理该次执行；保留最近结束任务的标记，防止迟到的进度消息让已结束任务重新出现。
- 节点内部重试期间，只要后端仍将其标记为运行，就继续显示；具体重试轮数由源节点的状态控件提供。
- 直接命中 ComfyUI 缓存而没有实际执行的节点通常不会出现。节点内部自己的缓存仍可能经过执行状态，出现时间由后端事件决定；活动页不会人为延长显示时间。
- 旧版本只有单节点 `executing` 事件时，只能显示该事件提供的节点，不能从一个编号推导未报告的并发集合。
- 工作流切换后不会把原工作流的活动编号匹配到新工作流中，不从历史记录伪造实时状态。

刷新或重连时，一些后端只重发 `executing`，不立即发送完整 `progress_state`；新版前端的原生运行绿框却依赖后者。因此之前会出现“页面刚打开没有高亮和活动节点，直到下一次进度变化才一起恢复”的空窗。

如果断线期间任务已经结束，旧活动快照也可能暂时残留，而任务列表通过历史查询已经显示失败。活动页收到原生成功、失败或中断事件后会清理整个任务，包括流程控制节点；已结束任务的迟到快照不会重新加入。安装 Harness 包时，其终态恢复会从本地队列与任务历史补回错过的原生终态事件，连同原生错误提示和运行高亮一起同步，详见 [Harness 节点运行状态](../../comfyui-llm_harness_engineering/web/docs/llm_remote_reply.md#节点运行状态)。活动页本身不根据停留时间猜测成功或失败。

扩展在模块加载时就监听重连消息，按队列核对浏览器客户端、任务与工作流，将后端确认的当前执行节点转换为原生进度事件，由 ComfyUI 自身恢复绿框，活动页读取同一状态。任务结束或工作流不匹配时不恢复。完整进度快照到达后以它为准，不允许单节点兼容消息覆盖并发状态；页面初始化期间收到的快照也会用于恢复活动列表。旧服务器只补发一个节点时，只能先恢复该节点及原生规则涵盖的子图宿主，未报告的其他并发节点仍需等待完整快照，不能凭猜测点亮。

## 镜像内容与尺寸

画布部分调用运行环境实际提供的节点绘制方法，并沿用节点已有的背景、前景和徽标回调。因此本包的原始名称、节点 ID 以及后来通过同一绘制链路添加的标签可以一起显示，不维护一份固定的标签列表。

镜像有独立的尺寸、位置、端口和控件布局，不实例化或注册新节点。标题、端口和普通字段按内容测量宽度，HTML 内容允许换行，文本区域随内容扩高；保留原节点已有的预览区域。折叠的原节点在活动页按展开状态显示，原节点仍保持折叠。

输出端口的横坐标由原生布局按镜像宽度重新计算，保持位于右侧；纵向仍保留源节点的显示顺序，包括只有端口、没有普通控件的流程节点。保存过端口排序的位置不会让输出停留在原宽度的中间位置。

侧栏宽度不足时优先保持文字可读，宽镜像可以横向滚动，长内容随活动页纵向滚动。绘图缓冲按两个方向分块，只分配可见区域的图块，避免长回复或很长单行字段创建巨大 Canvas。节点内部自定义绘制若主动截断文字或使用固定坐标，仍需要该控件自身提供自适应能力。

HTML 内容通过只读副本显示，跟随 DOM 变化，并同步仅通过属性变化的输入值。可读取的开放 Shadow DOM 会复制其显示内容；不会挂载另一个自定义元素实例。Canvas／视频复制当前可读取的画面，媒体尚未解码或浏览器禁止读取时可能没有画面。原节点的计算和提交逻辑不会通过镜像按钮再次触发。

活动页更新目标约为每 150 毫秒一次，受浏览器主线程、页面可见性和源控件更新频率影响；没有活动页可见时不绘制镜像。它不能让服务商尚未返回的内容提前出现，也不能修复源节点本身延迟更新的流式控件。

## 连续跟踪变化节点的底部

流式回复使节点不断增高时，活动页可以持续跟随该节点底部，减少反复向下滚动。符合条件时，标签栏下方、节点列表上方才出现 **连续跟踪** 开关；开关复用原生设置开关的结构和主题样式，不占用节点内部空间。

判定与操作规则：

1. 同一批活动节点对象、显示顺序和执行任务保持不变超过 **2 秒**。这里的“对象不变”指节点身份不变，不要求流式正文停止更新。
2. 稳定后，同一节点在 **2 秒内至少两次**发生超过 **0.5 像素**的高度变化，才视为连续变化。单次尺寸调整和亚像素抖动不会立即触发。
3. 默认开启跟踪，将目标节点底部对齐活动列表可见区域底部，并保留边距。多个节点符合条件时，选择显示顺序中的最后一个；它短暂停顿时不会因其他节点的一次更新来回跳动。
4. 关闭开关后仍更新节点内容，但不再自动调整滚动位置，可以手动向上阅读。连续变化期间开关保持可见，可以再次打开。关闭选择在当前页面内保留，包括新任务、工作流切换、侧栏重新挂载；刷新页面后恢复默认开启。
5. 节点连续 **2 秒**没有高度变化后取消其跟踪资格；没有其他符合条件的节点时隐藏开关。再次开始连续变化时，开关重新出现并沿用当前选择。

例如，一个 LLM 节点在活动页保持超过 2 秒，之后回复换行让卡片连续增高，开关出现并跟踪到底部。此时关闭开关、向上滚动查看开头，后续文字仍更新，但不会把你拉回底部。另一个活动节点加入或完成时，重新等待集合稳定，不立即跳到新卡片。

节点加入、移除、对象替换、任务变化、工作流变化或侧栏宽度改变时重新计时。隐藏活动页或浏览器页面期间暂停采样，返回后重新判断。高度增加和减少均可触发；正文变动但高度不变不会触发。离屏卡片也会约每 500 毫秒检查一次显示更新，绘图仍只分配可见区域图块。

跟踪仅修改活动列表自己的纵向滚动位置，不调用画布定位，不改变原节点尺寸，也不滚动整个网页。列表滚动到边界时会停在可达位置；如果目标下方还有其他节点，目标是该卡片底部，**不是整个列表底部**。开启跟踪期间手动滚动可能被后续跟踪拉回，阅读历史内容时请关闭开关。

## 定位与页面更新相互独立

点击时捕获完整节点路径及目标对象，立即交给 `node_find.js` 的 `revealNode()`，与 Ctrl+F 选择结果后的路径完全相同。子图导航、缩放比例和返回父图行为详见[按节点 ID 或名称查找](NodeFind.md)。

定位按侧栏之外实际可见的画布区域居中并适配缩放；活动侧栏开着或调整宽度后，目标不会仍按被遮挡的整张 Canvas 居中。左右侧栏及底部面板的布局变化在每次定位时重新读取。

活动页不等待定位结束，也没有“定位结束后恢复活动页”的回调。即使镜像随后因为执行完成而消失、侧栏按运行前状态恢复，已发起的定位仍继续；真正切换工作流或目标被删除时，则遵循查找功能的失效保护。

## 版本兼容与显示边界

镜像按自身宽度重新布局端口和控件。尚未打开过的子图可能还没有完成源节点布局；这时绑定控件的输入口使用镜像新计算的位置，与对应控件保持在同一行，不复制源节点的临时占位坐标。已连接的布尔控件是否保留、是否置灰，遵循原生节点规则，不另加或删除一份控件。

已连接并收起的多行输入仍保留一行端口及名称，包括提示词、系统提示词、报错信息等。与[多行文本输入连接后收起](MultilineCollapse.md)共用紧凑行状态，名称按镜像当前输入与控件的绑定关系绘制；原节点和镜像分别使用自己的坐标，不修改源节点尺寸、连线或控件值。

实现不内嵌某个 ComfyUI 版本的整份绘制代码，也不引用带版本哈希的前端文件。运行时检测绘制与布局能力；有原生 `arrange()` 时使用它，没有时为旧布局分配控件空间。新版运行状态和旧 `executing` 事件分别处理。

以下边界需要区分：

| 环境或内容 | 行为 |
| --- | --- |
| 经典画布、普通 Canvas 节点及可读取 HTML 控件 | 复用实际绘制链路并同步显示内容；仍受第三方绘制实现约束 |
| Vue Nodes 模式 | 当前不支持完整镜像，卡片明确提示使用经典画布；不会悄悄显示空白节点 |
| 开放 Shadow DOM | 复制可读取的渲染内容及其变化，不重复创建运行组件 |
| 封闭组件、iframe、object、embed | 不运行第二份嵌入内容，显示查看原节点的提示；可点击定位 |
| 伪元素、第三方独立浮层或未实例化的组件 | 不属于可直接复制的节点内容，不能保证镜像一致；无可读取内容时需查看原节点 |
| 不含“工作流总览”右侧栏的旧版前端 | 无法在要求的位置插入标签，会在执行开始尝试打开时报告缺少接口 |
| 修改了侧栏结构或 Pinia 存储接口的前端 | 挂载桥接可能需要适配；该侧栏尚无公开的内部标签扩展接口，不能承诺任意未来版本零维护 |

复用所在版本绘制方法可以减少外观漂移，但不等于所有版本、渲染模式与第三方控件已经验证。单个镜像绘制失败不会终止工作流；卡片显示错误并允许定位原节点，浏览器控制台记录对应节点路径与异常。

## 常见问题

| 现象 | 说明或处理 |
| --- | --- |
| 看不到活动标签 | 刷新前端；在未选中节点的全局总览中查看，确认前端具有右侧总览侧栏 |
| 节点运行很快，一闪即逝或没看到 | 列表反映实时运行集合，不保留已完成节点；缓存及很短的执行可能发生在两次绘制之间 |
| 节点显示等待，但没有新的回复 | 活动页只展示源节点当前内容；检查源节点是否已经收到服务商数据 |
| 镜像中不能输入或审核 | 这是只读显示；点击定位后在原节点操作 |
| 点击后列表继续变化 | 正常行为，活动更新与画布定位互不等待 |
| 看不到连续跟踪开关 | 只有活动对象稳定超过 2 秒、同一节点随后连续改变高度时才出现；仅更新文字但高度不变不会出现 |
| 想向上查看已经生成的文字 | 关闭“连续跟踪”后手动滚动；节点内容仍持续更新 |
| 镜像出现兼容错误 | 点击查看原节点，错误包含在该卡片和控制台中；检查表格中的渲染模式与接口边界 |
