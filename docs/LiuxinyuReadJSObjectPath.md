# 使用js点符号语句读取对象

按点号路径和数组下标从对象或数组中取值，结果保留原始类型——数字、字符串、布尔值、null、对象或数组。

## 语句写法

“读取语句”留空时返回整个输入。常用写法：

| 语句 | 含义 |
| --- | --- |
| `a.b.c` | 逐层取键 |
| `a[12]` | 取数组第 13 项，下标从 0 开始 |
| `a.b.c[10].d` | 取键与下标混合使用 |
| `[0]` | 根输入本身是数组时取第一项 |
| `a["a.b"]` 或 `a['键名']` | 键名含点号等特殊字符时用方括号加引号 |
| `a.items.length` | 数组的 length 返回元素个数 |

例如输入 `{"menu":{"items":["苹果","香蕉"]}}`：语句 `menu.items[1]` 输出 `香蕉`；语句 `menu.items.length` 输出 `2`。

## 报错情况

- 路径不存在：提示读取失败及不存在的键名。
- 下标越界：提示下标值和数组实际项数。
- 对数组使用文本键名：提示需要从 0 开始的整数下标或 length。
- 上一级已是数字、字符串、布尔值或 null 还继续取属性：提示不能继续读取。
- 语句格式错误：提示出错的字符位置，例如方括号中要填非负整数或带引号的键名。

数组结果整体输出，不自动拆分执行列表。输入需是“字符串转为JS对象”等节点解析后的对象或数组，而不是原始 JSON 文本。
