# 从字符串数组读取字符串

按下标从字符串数组中取出元素，下标从 0 开始。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `字符串数组` | 被读取的字符串数组，整批收取 | STRING | 是 |
| `下标` | 元素下标，从 0 开始，越界时报错；默认 0，范围 0～2147483647 | INT | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `字符串` | 从数组里读出的字符串；完整值：上游执行列表整批收取，输出与下标项数对应的执行列表——“下标”只有一项时输出一项，多项时按每个下标各读一次、输出对应多项，下游逐项处理 | STRING |

例如输入数组 `苹果`、`香蕉`、`梨子`，“下标”为 1 时输出 `香蕉`，下标 0 是第一项。下标超出范围时报错，例如 5 个元素的数组取下标 5，提示“下标 5 超出范围，数组共 5 个元素，下标从 0 开始。”

给“下标”连接多项执行列表时，会按每个下标各读一次，输出对应多项：例如下标为 `0`、`2` 两项时，对三个元素的数组输出 `苹果`、`梨子` 两项。

想一次查看整个数组而不是取单项，接[预览参数组合或字符串数组](LiuxinyuPreviewText.md)；想把多项合并成一段文字，接[拼装字符串数组为字符串](LiuxinyuStringArrayJoin.md)。
