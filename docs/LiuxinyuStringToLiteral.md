# 字符串转为字面量

把看起来像数字、数组或对象的文本转换成对应数据。最常见用途是把 LLM 返回的切点文本转换成切分节点能使用的完整数组。

## 最重要的是选对输出

在字符串里填 `[0.1, 0.2]`：

| 输出 | 下游得到什么 | 适用情况 |
| --- | --- | --- |
| 字面量（第一个） | 执行列表中的 0.1、0.2，普通下游分别执行 | 每个元素分别处理，例如多个相对目录名 |
| 完整字面量（第二个） | 一整个 `[0.1,0.2]` 数组 | 切分数组、完整配置对象等 |

普通单个值在第一个输出中为一项；字典整体为一项，不按键拆开。数组只展开第一层。

## 将 LLM 切点传入切分节点

```text
LLM远程回复 → 字符串 → 本节点的完整字面量 → 最终切分/切分检查图的切分数组
```

推荐要求模型：

> 只输出合法 JSON 数组，例如 [{"percent":10},{"percent":20}]。percent 是相对整张原图、沿切分方向的位置百分比，大于 0 且小于 100；按位置排序，不重复，不包含两端，不添加解释文字。

也可以用 `[0.1,0.2]`。对象形式的 10 和数值形式的 0.1 都表示 10%。不要给整段数组再套一层字符串引号。

支持完整的 Markdown JSON 代码块：以三个反引号和 `json` 开头、内容另起一行、最后一行用三个反引号结束。代码块之外不要加解释段落。

## 常见输入

| 文本 | 解析结果 |
| --- | --- |
| `12` | 整数 12 |
| `0.25` | 浮点数 0.25 |
| `"12"` | 字符串 12，保留字符串类型 |
| `[1,2,3]` | 数组 |
| `[{"percent":10},{"percent":20}]` | 对象数组 |
| `{"name":"产品A","width":790}` | 字典/对象 |
| `产品A` | 普通字符串 |

对象使用 JSON 双引号语法。切分节点只接受两种切点数组；本节点能解析字典，不代表切分输入可以接任何字典。旧的 `y_percent`、`x_percent` 或外层 `boundaries` 包裹不能作为当前切分格式。

## 路径与解析失败

Windows 路径如果写在 JSON 字符串内，反斜杠要写两次，例如 `["D:\\素材\\产品A"]`；也可使用正斜杠 `["D:/素材/产品A"]`。

解析不成立时保留原始字符串，不一定在本节点报错。下游若提示“需要数组”，检查是否接错输出、JSON 引号是否配对、文本里是否混入解释。运行后节点底部会显示解析类型，可用来确认。
