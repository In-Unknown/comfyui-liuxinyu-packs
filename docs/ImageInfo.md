# 图片信息节点

节点 ID：`LiuxinyuImageInfo`。输入 `IMAGE` 张量，无需路径。

输出依次为：宽度、高度、色彩数、明度中位数、明度最高值、明度最低值、R 最高/最低值、G 最高/最低值、B 最高/最低值。尺寸、色彩数和 RGB 通道极值为整数；整体明度为浮点数。

- 所有统计基于 8 位 RGB：输入像素限幅到 0～1，乘 255 后取最近整数（恰好半整数时取偶数）。色彩数是不同 RGB 三元组的数量。
- 明度采用 `0.299R + 0.587G + 0.114B`，范围 0～255。纯红、纯绿、纯蓝分别为 76.245、149.685、29.07。
- 中位数针对所有像素计算，重复颜色按实际像素数计入；偶数个像素取排序中间两项的平均值。
- R/G/B 极值是各通道自身的 0～255 数值，不乘明度权重。
- 灰度图按 R=G=B 计算。RGBA 忽略透明度，包括完全透明像素内保存的 RGB；不会与背景合成。
- 多张图片分别统计。各输出是顺序对应的 ComfyUI 执行列表，普通下游节点会逐项执行；单张图片只有一项。输入包含多个张量批次时，先按输入列表顺序，再按批次内部顺序输出。

长图按行分块统计，不缩小图片，不抽样；计算精确颜色数量和明度中位数，无须排序或复制完整长图。中间统计数据在本次执行结束后释放。
