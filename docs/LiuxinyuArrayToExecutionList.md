# 将任意数组转为执行列表

输入一个数组（Python `list` 或 `tuple`），将第一层元素依次输出为 ComfyUI 执行列表，让普通下游节点逐项处理。节点 ID：`LiuxinyuArrayToExecutionList`。

- 输入：`数组`，可连接任意类型端口，实际值必须是数组。
- 输出：`执行列表`，元素可以是字符串、数字、对象、图片、Latent 或嵌套数组等。
- 保留顺序、重复项和对象引用，不经过字符串序列化，不深拷贝张量。
- 只展开一层：`["A", ["B", "C"]]` 输出两项 `"A"` 和 `["B", "C"]`。
- 空数组 `[]` 输出零项；上游含多个数组执行项时，按顺序逐个展开。
- 字符串、字典、图片张量等不能直接作为输入数组；它们可以作为数组中的元素。

例如，对象读取节点输出 `recordPaths = ["[0][0]", "[2][0]"]`，接此节点后，下游依次收到两个路径。不再需要先转 JSON 字符串再转回字面量。
