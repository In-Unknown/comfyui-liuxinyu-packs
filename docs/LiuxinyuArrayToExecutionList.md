# 将任意数组转为执行列表

输入一个数组（Python `list` 或 `tuple`），将第一层元素依次输出为 ComfyUI 执行列表，让普通下游节点逐项处理。节点 ID：`LiuxinyuArrayToExecutionList`。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `数组` | 一个完整的 list 或 tuple；端口允许连接任意类型，但运行时检查实际值必须为数组 | ANY | 是 |

没有其他配置项。输入若是 JSON 数组文本，先解析为原生数组。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `执行列表` | 按输入数组顺序输出第一层元素，每个元素为一个执行项；保留重复项、原始类型和对象引用 | ANY（执行列表） |

ANY 说明每项允许任意类型；本输出明确声明为执行列表。它可以接[分包执行子流回归](LiuxinyuPacketStart.md)的输入，或[分包跳回](LiuxinyuPacketReturnStart.md)的分包数据口。

## 示例：逐项读取记录路径

1. 对象读取节点输出完整路径数组 `["[0][0]", "[2][0]"]`，接本节点的“数组”。
2. “执行列表”接读取节点的“读取语句”，原始完整数据接其“对象或数组”。
3. 下游依次读取 `[0][0]` 和 `[2][0]`，得到对应的两个完整记录执行项。这里的索引从 0 开始，不能把记录中的业务编号当成数组下标。

不需要先将数组序列化为 JSON，再重新解析。要让每条记录完成整个子流后才处理下一条，将本节点输出接分包起点，并按分包文档闭合循环。

## 嵌套数组与整体保留

本节点只展开一层：`["A", ["B", "C"]]` 输出两项 `"A"` 和 `["B", "C"]`。分包节点收到后是两包，第二包仍是完整数组。若还要拆第二包的数组成员，在该包内部再次使用本节点。

若目标是让 `[1,2]` 整体作为一包，应使用[批量任意为执行列表](LiuxinyuRepeatAnyToExecutionList.md)，次数设为 1；本节点会得到两项 `1`、`2`。

## 空输入、多份数组与引用

- 空数组 `[]` 输出空执行列表。分包起点可以据此执行零包；普通下游若同时有非空固定输入，须按下游规则处理空列表，不能假定整个工作流都会自动跳过。
- 上游是多个数组执行项时，按顺序展开各数组。例如 `[1,2]`、`[3]` 两项会得到 `1`、`2`、`3` 三项。
- 不转字符串，不深拷贝张量，也不拆 IMAGE 内部批次。元素对象按原引用传递，下游应避免原地修改共享对象。

## 常见错误

| 情况 | 行为或修正 |
| --- | --- |
| 输入字符串、字典、数字或图片张量 | 报错：输入必须是数组；这些值可以作为数组中的元素 |
| 输入看起来是数组的字符串 `"[1,2]"` | 先解析成数组，再连接本节点 |
| 普通数组直接连接分包口 | 分包节点报错；在两者之间显式添加本节点 |
| 希望保留整个数组为一包 | 改用次数为 1 的“批量任意为执行列表” |

更多区别见[数组、执行列表与图片批次](DataLists.md)。
