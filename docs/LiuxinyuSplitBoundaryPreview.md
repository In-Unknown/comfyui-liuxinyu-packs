# 切分检查图（边界放大）

在正式裁切前查看每条切线附近的内容，确认是否切到了文字、产品或画面主体。每个切点输出一张带位置标尺和放大区域的检查图。

## 接线步骤

1. 原图接“图片”。
2. 准备切点数组，接“切分数组”。可以用两个浮点数 0.1、0.2 接“多个数值组成数组”。
3. 选择切分方向，并设置“边界放大范围”，例如 200。
4. 检查图接“预览超长图片”，运行查看。
5. 如需移动切点，调整数组中的位置后重跑；满意后将**原图及同一切点数组**接到“最终切分（按边界）”。

检查图是辅助图，不要把它接到最终切分的图片输入。

## 切分数组支持两种格式

| 格式 | 示例 | 含义 |
| --- | --- | --- |
| 数值比例数组 | `[0.1,0.2]` | 整张图的 10%、20% |
| 对象百分比数组 | `[{"percent":10},{"percent":20}]` | 同样是 10%、20% |

对象可加名称：`[{"percent":10,"name":"标题后"}]`。数字比例严格大于 0、小于 1；对象 percent 严格大于 0、小于 100。不要混用两种形式，不写两端的 0/1 或 0/100，不使用 y_percent、x_percent 或外层 boundaries 对象。

LLM 返回的是文本时，先接“字符串转为字面量”，再用其第二个“完整字面量”输出连接切分数组。

## 范围与方向

上下切分按高度算位置，左右切分按宽度算位置。例如高 10000 的图，10% 在 Y=1000；宽 2000 的图，左右 10% 在 X=200。

“边界放大范围”表示向切点两侧各取多少像素：200 通常会覆盖边界前后共 400 像素，靠近图片两端时缩短。它不改变实际切点，也不是最终切片的长度。

上下模式的标尺在左边、放大区域在顶部；左右模式的标尺在底边、放大区域在左边。数字不旋转，拥挤时会省略部分刻度文字。

## 输出与排错

两条切点产生两张检查图；最终切分会产生三段，这两个数量不同是正常的。输入多张图时分别使用同一组比例，各张的检查图按顺序输出为执行列表。

不能传空数组。位置会换算为整数像素；正式切分时过于接近或重复的切点可能落在同一个像素上，造成空片，应拉开距离。检查图只用于辅助判断，不代表最终切片。
