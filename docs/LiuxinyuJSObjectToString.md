# js对象转换为字符串

把对象、数组或参数组合转成 JSON 文本；字符串则原样通过。保留中文和嵌套结构，不生成 \uXXXX 转义。

## 怎么用

“值”输入口可以接四种来源：

| 输入 | 输出 |
| --- | --- |
| 字符串 `苹果` | 原样 `苹果` |
| 对象 `{"name":"苹果"}` | `{"name": "苹果"}` |
| 数组 `["苹果","香蕉"]` | `["苹果", "香蕉"]` 整体一个字符串 |
| 参数组合（t1=红，t2=S） | `{"t1": "红", "t2": "S"}` |

数组或参数组合整体转换成一个字符串，不逐项拆分执行；既不是字符串也不是对象、数组的输入会报错提示无法转换。

## 用途

- 把对象文本化后接[字符串拼接](LiuxinyuStringConcatenate.md)或保存类节点。
- 与[字符串转为JS对象](LiuxinyuStringToJSObject.md)往返配合；含中文的对象走本节点可避免转义。
- 参数组合转成 JSON 文本后便于调试，逐条查看 t1、t2…的取值。
