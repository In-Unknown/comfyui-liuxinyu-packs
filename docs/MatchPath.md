# 从目录中匹配路径或目录

在指定目录下按条件筛选文件或目录，返回匹配项的完整路径执行列表。支持字符串包含、正则表达式、文件属性布尔表达式三种方式。输出口虽叫“路径数组”，实际是 STRING 执行列表，普通下游每次收到一个路径字符串。

## 直接照做：找一个目录的图片

目录路径填写素材所在目录，模式选“正则表达式”，内容填 `(?i)\.(png|jpe?g|webp)$`，对象选“文件”，只找当前层就关闭递归。输出接“从路径加载图像批次”，即可逐文件加载。`(?i)` 表示扩展名不区分大小写。

若只想找下一层文件夹，匹配对象选“目录”，字符串匹配内容留空，关闭递归。返回的是目录路径，适合接到分包起点；它不会直接加载目录内的图片。

多个详情页目录需要各自拼接时，在分包子流内使用本节点、加载节点和拼接节点，以免下游整体合并所有目录的图片。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `目录路径` | 要搜索的文件夹绝对路径。可点击「选择文件夹」按钮选择，也可手动输入。 | `STRING` |
| `匹配模式` | 三选一：`字符串匹配`、`正则表达式`、`文件属性布尔表达式`。 | 下拉 |
| `匹配内容` | 随匹配模式变化，见下方说明。 | `STRING` |
| `匹配对象` | 三选一：`文件`、`目录`、`文件和目录`。 | 下拉 |
| `是否递归` | 为真时递归子目录，为假时只看当前一层。 | `BOOLEAN` |
| `匹配完整路径` | 默认关闭。关闭时字符串匹配和正则只对名称（含扩展名）匹配；开启时对完整路径匹配。属性表达式不受此开关影响。 | `BOOLEAN` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `路径数组` | 匹配到的完整路径列表。下游节点逐项执行，每次收到一个路径字符串。 | `STRING`（列表） |

## 三种匹配模式

### 字符串匹配

默认只在**名称**里找包含关系。例如输入 `花`，会命中 `花卉图.jpg`，但不会因为上级目录叫 `花素材` 而命中目录下的其他文件。

开启「匹配完整路径」后改为对完整路径做包含判断，那时输入 `花` 会命中 `D:\花素材\任意文件.txt`。

### 正则表达式

默认只对**名称**做 `re.search`。例如 `^R\d+\.jpg$` 只命中名称形如 `R20.jpg` 的文件。

开启「匹配完整路径」后改为对完整路径做 `re.search`，此时需要自己加锚点和分隔符，例如 `[\\/]R\d+\.jpg$`。

正则语法错误时不报错，返回空结果。

### 文件属性布尔表达式

匹配内容写一个对文件属性求值的布尔表达式，可用字段：

| 字段 | 含义 |
| --- | --- |
| `name` | 名称（含扩展名） |
| `stem` | 无后缀名称 |
| `suffix` | 扩展名（含点） |
| `suffix_lower` | 小写扩展名 |
| `path` | 完整路径字符串 |
| `is_file` / `is_dir` | 是否为文件 / 是否为目录 |
| `is_hidden` | 是否隐藏 |
| `size` | 字节数 |
| `size_kb` / `size_mb` | 按 KB / MB 计算，保留两位小数 |
| `mtime` | 修改时间戳（浮点） |
| `mtime_str` | 修改时间，格式 `YYYY-MM-DD HH:MM:SS` |
| `atime_str` | 访问时间，格式同上 |
| `ctime_str` | 创建时间。Windows 是创建时间，Linux/macOS 是 inode 变更时间 |

表达式示例：

- `size > 1024` — 大于 1 KB 的文件
- `suffix_lower == '.png'` — 所有 PNG
- `'R20' in name` — 名称包含 R20
- `is_dir and name.isdigit()` — 名称全为数字的目录
- `is_hidden == False and size_mb > 1` — 非隐藏且大于 1 MB

表达式写错、字段不存在、求值异常时返回假，不报错，也不影响同批次其他条目的判断。表达式开头若以 `.` 开头会自动去掉。

## 使用示例

- 名称包含「花」的文件：字符串匹配 `花`，匹配对象选文件，递归开。
- 名称形如 `R20.jpg`、`R21.jpg` 的文件：正则 `^R\d+\.jpg$`，匹配对象选文件。
- 名称是无前导零数字的文件夹：属性表达式 `is_dir and name.isdigit() and (name == '0' or not name.startswith('0'))`。
- 按目录结构筛选：开启「匹配完整路径」，字符串匹配 `2024`，可命中路径中任意位置出现 2024 的条目。

## 注意事项

- 目录不存在或为空时返回空数组，不报错。
- 字符串匹配和正则默认只对名称，避免因上级目录名导致的误命中。需要按路径筛选时再开启「匹配完整路径」。
- 属性表达式在受限环境中求值，清空了内置函数，不能调用 `int()`、`str()` 等，但可用对象自身方法如 `isdigit()`、`startswith()`。它不是硬沙箱，只适合本机可信输入。
- `is_hidden` 在 Windows 上读文件属性位，在 Linux/macOS 上回退为名称以 `.` 开头。
- 对目录条目，`size` 返回的是目录项本身的大小，通常不是想要的值。
