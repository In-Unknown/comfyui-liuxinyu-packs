# 视窗回归原点

将当前画布的查看位置移回坐标 `(0, 0)`，适合拖动画布后快速返回原点。保留当前缩放比例，只平移视窗，不移动节点或调整布局。

## 入口与操作

1. 在画布空白处或节点上右键，无需选择节点。
2. 点击 **视窗回归原点**。菜单项右侧带有 `liuxinyu` [来源标签](MenuSource.md)。
3. 视窗立即回到原点，继续按原生方式拖动、缩放即可。

## 输入

本功能是前端菜单，没有节点输入口或需要填写的参数。

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `当前画布` | 使用当前打开的主图或子图画布，以及它的视窗平移状态 | 画布对象 | 自动读取 |

## 输出

没有节点输出口，不产生工作流执行数据。

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `视窗位置` | 将画布平移偏移设置为 `[0, 0]`，画布左上角对应图坐标 `(0, 0)`；缩放比例保持原值 | 画布视图状态 |

## 使用示例

当前把画布拖到很远的位置，缩放比例为 `50%`。右键点击 **视窗回归原点** 后，查看位置回到 `(0, 0)`，缩放仍为 `50%`。节点仍处在原来的图坐标上。

## 原点、子图与保存

- 回归的是图坐标原点，原点位于画布左上角；不会自动居中到所选节点，也不会缩放至全部节点可见。
- 在子图中使用时，仅改变当前子图的查看位置，不退出子图。回到父图仍由原生导航处理。
- 平移使用原生画布视图状态，保存工作流时沿用 ComfyUI 原有的视图保存机制，没有额外配置或浏览器存储。
- 这是视窗操作，不修改节点、连线、分组、文本或端口，不添加节点编辑的撤销记录；可继续拖动视窗。

## 常见问题

| 现象 | 说明或处理 |
| --- | --- |
| 更新后没有菜单项 | 刷新页面，仍未出现时使用 `Ctrl+F5`；无需重启后端 |
| 回归后没有看到节点 | 节点可能不在原点附近；需要浏览全部节点时使用原生适配画布功能 |
| 端口菜单中没有此项 | 使用画布空白处或普通节点右键菜单；端口专用菜单不在此入口范围内 |

## 开发与验证

`viewport_origin.js` 沿用包的前端扩展加载方式，通过 `getCanvasMenuItems` 和 `getNodeMenuItems` 加入菜单。复用 `menu_source.js` 的来源标签，修改原生 `canvas.ds.offset` 后请求重绘，缩放和可见区域更新沿用原生画布机制。
