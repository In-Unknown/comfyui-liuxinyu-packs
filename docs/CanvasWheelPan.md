# 画布滚轮平移

全局画布快捷操作，无需添加节点，前端扩展加载后生效。

## 操作

| 操作 | 镜头移动方向 |
| --- | --- |
| Shift＋滚轮向下／向上 | 向下／向上 |
| Ctrl＋滚轮向下／向上 | 向右／向左 |
| Ctrl＋Shift＋滚轮 | 按 Ctrl 处理，左右移动 |
| 普通滚轮 | 保留列表滚动及画布原有缩放 |

鼠标位于画布及画布内节点时生效，优先于表单列表的滚动；镜头移动时节点在屏幕上向相反方向移动。缩放比例不变，同样的滚轮距离在不同画布缩放下保持相同屏幕移动距离。支持鼠标滚轮的像素、行、页单位以及 Shift 导致的横向滚轮事件。

## 范围与生效

原生输入框、展开菜单、侧栏和其他 DOM 弹窗仍使用各自滚动行为。Alt 或 Meta 同时按下时交给原有处理。不改变节点位置、连线或填写值，不产生节点移动的撤销记录。

刷新页面加载，无需重启后端。实现沿用本包 `axis_drag.js` 的全局扩展注册方式，由 `canvas_wheel_pan.js` 在窗口捕获阶段处理画布滚轮，先于表单列表监听器。
