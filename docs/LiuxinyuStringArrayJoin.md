# 拼装字符串数组为字符串

把字符串数组的所有条目按顺序首尾连成一段，不额外添加分隔符，保留原有空格和换行。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `字符串数组` | 被拼接的字符串数组；整批收取完整列表，上游是执行列表时先全部收齐再一次性拼接，而不是逐项执行 | STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `字符串` | 一个拼好的完整文本；完整值：上游执行列表整批收取，输出单个字符串，不再拆分，也不会逐份输出相同文本 | STRING |

例如数组 `苹果`、`香蕉`、`梨子` 输出 `苹果香蕉梨子`；数组 `第一章。`、`第二章。` 输出 `第一章。第二章。`。想保留分隔痕迹，可在[切分字符串为数组](LiuxinyuStringArraySplit.md)打开“保留分隔符”，两边对接即可还原原文。

想插入分隔符（如逗号或换行），先用“组装字符串为字符串数组”把分隔符穿插进数组，或直接用切分的“保留分隔符”。下游若需要逐项处理，请接在拼装之前而不是之后。

需要给每段分别加前缀后缀时，改用[字符串拼接](LiuxinyuStringConcatenate.md)。
