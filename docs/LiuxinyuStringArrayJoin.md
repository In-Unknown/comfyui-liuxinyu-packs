# 拼装字符串数组为字符串

把字符串数组的所有条目按顺序首尾连成一段，不额外添加分隔符，保留原有空格和换行。

例如数组 `苹果`、`香蕉`、`梨子` 输出 `苹果香蕉梨子`；数组 `第一章。`、`第二章。` 输出 `第一章。第二章。`。想保留分隔痕迹，可在[切分字符串为数组](LiuxinyuStringArraySplit.md)打开“保留分隔符”，两边对接即可还原原文。

本节点整体收取完整列表，而不是逐项执行：上游是执行列表时，先全部收齐再一次性拼接成一个字符串。想插入分隔符（如逗号或换行），先用“组装字符串为字符串数组”把分隔符穿插进数组，或直接用切分的“保留分隔符”。

需要给每段分别加前缀后缀时，改用[字符串拼接](LiuxinyuStringConcatenate.md)。
