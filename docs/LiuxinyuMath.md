# 多输入数学运算

将两个或更多数字做计算，输出一个 FLOAT 浮点数。输入可连接 INT 或 FLOAT，连接后自动增加插口，最多 100 个，至少连接两个。

## 快速例子：按比例计算宽度

图片信息节点的“宽度”接第一个数值，浮点数 0.5 接第二个，运算选“乘”。宽度 790 得到 395.0。下游若需要 INT，再接“数字取整”，得到 395。

## 运算怎么选

以下 a 为当前累计结果，b 为下一个输入：

| 运算 | 含义 | 两个输入示例 |
| --- | --- | --- |
| 加 / 减 / 乘 / 除 | a+b、a-b、a×b、a÷b | 10、2 的除法得到 5 |
| 幂 | a 的 b 次方 | 2、3 得到 8 |
| 开根 | a 的 b 次根 | 8、3 得到 2 |
| 对数 | 以 b 为底，求 a 的对数 | 8、2 得到 3 |
| 最大值 / 最小值 | 取较大或较小值 | 10、2 得到 10 或 2 |
| 取模 | 余数，符号与除数相同 | -5、3 得到 1 |
| 整除 | 除后向负无穷取整 | -5、3 得到 -2 |
| 平均 | 整组算术平均数 | 1、2、3 得到 2 |
| 方差 | 总体方差，除以 N | 1、2、3 得到约 0.6667 |
| 样本方差 | 除以 N-1 | 1、2、3 得到 1 |
| 标准差 | 总体方差的平方根 | 1、2、3 得到约 0.8165 |
| 中位数 | 排序后居中的值；偶数项取中间两数平均 | 1、4、9 得到 4 |

平均、方差、标准差、中位数针对所有输入一次计算，不做逐对平均，也不受方向影响。

## 从左至右 / 从右至左

按数值输入口的编号顺序排列。左至右从第一个开始累计；右至左先反转输入，再逐个累计。

输入 10、3、2，选减法：

- 左至右：(10-3)-2 = 5。
- 右至左：(2-3)-10 = -11。

右至左不表示 10-(3-2)。幂也按累计规则计算：2、3、2 左至右为 (2³)²=64。

## 错误与精度

除数或取模的除数不能为 0。开根的次数不能为 0，负数只支持整数奇次实根。对数要求 a>0、b>0 且 b≠1。超出实数定义域或得到非有限结果会报错。

输出为双精度浮点数，0.1+0.2 等可能出现正常的末位误差。本节点不把输入执行列表自动收集成一组；需要同时计算的数值应连接到各个数值插口。
