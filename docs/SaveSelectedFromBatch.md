# 从批次中选择保存图片

SaveSelectedFromBatch 节点将输入的整批图片先暂存到 ComfyUI 临时目录用于在节点上预览，再根据「多选序列」自动保存到目标文件夹，或等待你在节点预览中勾选后手动点击「保存所选」按钮保存。适合在批次生成后从多张图片中挑选保存。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `图片` | 要保存的输入图像批次。整批图片会先暂存到 ComfyUI 临时目录用于在节点上预览，然后根据「多选序列」自动保存到目标文件夹，或等待你在节点上勾选后手动保存。 | `IMAGE` |
| `文件夹` | 保存文件的绝对路径。必须为绝对路径，不能为空。可点击下方的「选择文件夹」按钮调用系统原生对话框进行选择。 | `STRING` |
| `文件名` | 保存时使用的文件名前缀，需包含扩展名（支持 .png / .jpg / .jpeg / .webp / .bmp）。仅接受纯文件名，不能包含路径分隔符。保存时按 `{stem}_{k}.{ext}`（k 从 1 递增）的顺序写入目标文件夹；多次保存会追加编号，不会覆盖已有文件。 | `STRING` |
| `多选序列` | 可选。指定要自动保存的批次下标，0-based，以英文逗号分隔，例如 `1,3,6,0`。为空时进入手动选择模式，需在节点预览中勾选图片后点击「保存所选」按钮。非空时按这些下标自动保存到目标文件夹，但仍可继续手动勾选并触发额外保存。 | `STRING` |
