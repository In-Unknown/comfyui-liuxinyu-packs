# 从批次中选择保存图片

SaveSelectedFromBatch 节点将输入的整批图片先暂存到 ComfyUI 临时目录用于在节点上预览，再根据「多选序列」自动保存到目标文件夹，或等待你在节点预览中勾选后手动点击「保存所选」按钮保存。适合在批次生成后从多张图片中挑选保存。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `图片` | 图像张量批次或图像字节；同口支持两种类型及执行列表，每份字节按一个文件预览和选择 | IMAGE,IMAGE_BYTES | 是 |
| `文件夹` | 默认空，仅预览时可留空；实际保存需有效绝对目录，可点击“选择文件夹” | STRING | 是 |
| `文件名` | 默认 `image.png`；纯文件名，包含下文支持的后缀，保存为 `{stem}_{k}.{ext}`，从1递增追加，不覆盖已有文件 | STRING | 是 |
| `多选序列` | 默认空为手动模式；可填 `1,3,6,0` 自动保存，索引从0开始，按每个输入批次解释；忽略非法、越界、重复索引 | STRING | 是 |

## 输出

没有数据输出口。界面显示预览和保存结果，手动保存使用本次预览关联的内容；不需要重新执行上游。

## 图像字节保存

同口接受IMAGE或IMAGE_BYTES，不接受任意未验证BYTES、路径或Base64字符串。字节先完整验证；实际格式与目标后缀相同时直接保存原文件字节，自动保存和“保存所选”均不再压缩JPEG。格式不同时按[编码默认值](ImageBytes.md)转码，需要控制质量时请先使用“图像字节转码”。

支持 `.png`、`.jpg/.jpeg`、`.webp`、`.bmp`、`.tif/.tiff`、`.gif`、`.avif`（需Pillow支持）。原有张量保存方式保持，JPEG/WEBP质量95。字节动图或多页文件同格式完整保存，预览仅首帧；多帧跨格式保存会报错，请先显式转码或解码拆帧。

例如编码节点输出3个JPEG字节项，接本节点后多选序列留空，运行得到3张预览；文件夹填 `C:\images\selected`、文件名填 `product.jpg`，选中第1、3张并“保存所选”，得到两个JPEG，分别与对应输入字节完全相同。自动模式对每份字节仅有索引0，可填 `0` 保存所有项；不能用自动序列 `2` 表示整个字节列表的第3项。

预览PNG旁保存原字节缓存，随本节点预览一起失效和清理；手动保存读取原字节，不从显示用的PNG重新编码。原字节缓存缺失会提示重新执行，避免静默退回重压缩；相同输入重建缓存不会重复自动保存永久文件。永久输出不随缓存清理。

## 先预览，再保存

最小示例：图片接入，文件夹和多选序列留空，运行后查看缩略图；选择一个保存目录，文件名填 `detail.png`，点击需要的图片，再点“保存所选”。第一次保存通常得到 `detail_1.png` 等文件，再保存会继续编号。

自动保存示例：同一个输入批次有5张图片，多选序列填 `0,2,4`，表示第1、3、5张；运行前先填写有效保存目录。索引从0开始，最后一张的索引是图片数量减1。

自动模式的索引按每个输入批次分别解释，不是整个执行列表的全局索引。例如切分输出的每项只有1张图，给多选序列填 `2` 会越界；希望从所有切片中挑第3张时，保持序列为空，先运行，再在完整预览中手动选择。

将图片接入本节点，保持「多选序列」为空即可运行预览，此时不用填写保存目录。
预览完成后选择文件夹、勾选图片，再点击「保存所选」，无需重新运行上游节点。
手动选择支持切分节点输出的不同尺寸图片列表，按预览中的全局下标选择。
点击缩略图后以绿色高亮及边框标记选中，不再显示对勾。
自动保存的「多选序列」仍按每次输入批次内的下标解释。
运行后，预览会将本次多选序列实际选中的图片显示为绿色高亮，包含连接上游传入的序列；不会清空或改写原来的序列。复用缓存预览时也会恢复本次选中状态。

空目录在实际保存时会提示「请先选择保存文件夹」，不会再先转换成 `.` 而误报相对路径。

完全相同的图片和参数会复用上次预览，不重复自动追加保存文件；如果就是想再保存一份，可再次点击“保存所选”。文件名只能是带扩展名的纯文件名，目录单独填写。本节点没有图片数据输出，分包工作流中通常放在回归之后。
缺少批次维度的输入会在写文件前被拒绝，避免把图片的每一行当成一张图片。

缩略图与长图预览共用官方列数计算，支持质数数量、末行不足和条件合适时贴节点外缘。
具体排列及本轮检查范围见 [缩略图排列规则](ThumbnailGrid.md)。

图片网格已接入公共模块：缩放或平移时用预先准备的小图，停稳后从画布视窗中心附近开始恢复当前尺度所需的清晰度。
选择蒙层与保存逻辑沿用原来的行为，保存读取原始临时文件。

## 端口显示排序

选中节点，悬浮端口后按 `↑` / `↓` 可以调整显示顺序。“选择文件夹”按钮随文件夹输入移动，“保存所选”按钮随原本相邻的文件名控件移动；图片预览仍位于参数区域之后。选中下标、文件名及实际保存行为不随显示顺序改变。具体操作和保存行为见[端口显示排序](PortOrder.md)。
