# 阶乘

计算非负整数 n 的阶乘：1×2×…×n。用于组合数量或数值公式。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `数值` | 非负整数，可以输入 5.0 这类整值浮点数 | FLOAT / INT | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `阶乘` | n 的阶乘，0! = 1；上游接执行列表时逐项各算一次 | INT |

## 怎么用

整数 5 接“数值”，输出“阶乘”为 120。0 的阶乘规定为 1，1 的阶乘也是 1。

可以输入 5.0，但不能输入 5.5 或负数。要先取整时请明确接“数字取整”，本节点不会偷偷舍弃小数。

阶乘增长很快，例如 10!=3628800，20!=2432902008176640000。后端保留整数，但浏览器对大于 2^53-1 的整数可能无法精确显示；后续 FLOAT 计算也可能损失精度。
