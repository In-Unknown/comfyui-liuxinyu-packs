# 节点端口显示排序

需要同时整理一组节点的位置与端口时，可使用[整理节点](GraphLayout.md)：框选后右键操作，与本页手动排序共用保存属性。

在单个节点上分别调整输入口和输出口的上下位置，让相邻节点的连接顺序更接近，减少交叉线。排序记录随工作流保存，刷新页面、重新打开文件或换电脑后可以恢复。

这是节点包提供的前端功能，不需要新增节点，也不需要运行工作流。适用于当前经典画布中使用标准端口布局的节点，包括其他包的普通节点、子图节点及子图内普通节点。

## 入口与操作

**选中节点，将鼠标悬浮在端口圆点或文字上，等端口按原生效果高亮、变大后，按键盘 ↑ 或 ↓。** 无需右键菜单或排序窗口。

| 操作 | 结果 |
| --- | --- |
| 选中节点并悬浮在端口圆点或文字上 | 显示“↑ / ↓ 与相邻端口交换”的提示；同侧至少有两个端口时可用 |
| 按 `↑` | 与画布上同侧紧邻的上一个端口交换；已在最上方则不变 |
| 按 `↓` | 与画布上同侧紧邻的下一个端口交换；已在最下方则不变 |
| 交换后移动鼠标到需要继续调整的端口 | 下一次按键调整此时悬浮的端口 |
| 保存工作流 | 将当前节点的显示顺序写入工作流文件 |
| 使用 ComfyUI 原生撤销、重做 | 恢复相应编辑步骤中的顺序 |

提示和快捷键直接跟随 ComfyUI 原生端口高亮；鼠标位于端口文字区域而使圆点高亮时同样有效。松开鼠标完成选中后会刷新提示，无需再移动一次鼠标。

每次按下只交换一次，按住箭头键不连续交换，避免鼠标不动时两个端口反复换位。交换后高亮更新为鼠标当前位置下的端口；若要继续移动刚才的端口，把鼠标移到它的新位置再按键。

上下相邻关系依据端口的实际显示位置，包括原生位于参数控件旁的端口，不直接使用内部编号判断。输入只与输入交换，输出只与输出交换。多选节点时，只调整鼠标悬浮的那个节点。

在文本框、下拉框或可编辑区域中输入时，方向键保持原用途。按着 Ctrl、Alt、Shift 或系统修饰键、拖动连线或按着鼠标按钮时不触发排序。节点未选中、鼠标在未高亮的节点正文上、节点折叠或画布只读时，也不触发。

## 输入与输出

本功能没有执行输入、执行输出或后端计算，不改变节点输入输出的数据类型、数组结构、执行列表语义或返回值。

| 对象 | 排序后的行为 |
| --- | --- |
| 输入口 | 圆点、标签、点击区域和连线落点一起移动；仍连接原输入参数 |
| 输出口 | 圆点、标签、点击区域和连线落点一起移动；仍代表原返回项 |
| 节点连线 | 保留原连接关系，不断线重接，不替换连线编号 |
| 节点实例 | 只修改所操作的节点，其他同类型节点不受影响 |
| 工作流文件 | 保存当前节点的显示顺序设置；实际端口数组与执行索引保持不变 |

## 使用示例：让两侧连线对齐

假设节点 A 从上到下输出“报错信息”“校验通过”，节点 B 从上到下输入“校验通过”“报错信息”。当前两条连线发生交叉。

1. 单击节点 A，将它选中。
2. 把鼠标移到“校验通过”的输出圆点上，等它高亮。
3. 按一次 `↑`。A 的输出立即显示为“校验通过”“报错信息”，与 B 对齐。
4. 保存工作流。重新打开后，A 保持这个显示顺序。

假设 A 原本返回：

```python
("第 1 项的 'count' 必须是 integer。", False)
```

排序后其返回值仍完全相同。顶部的“校验通过”仍对应原输出索引 `1`，底部的“报错信息”仍对应原输出索引 `0`。向顶部端口新建连线时，也会连接索引 `1`，不会把错误文字接到布尔输入。

## 带参数控件的输入口

**输入口与关联的输入框作为一整行一起交换位置。** 普通端口按端口行占位；字符串、数值、下拉框等输入口连同对应控件一起移动，多行文本框按实际高度占位。不会把圆点移到上方、却将输入框留在下方，也不会额外重复显示一份控件名称。

例如原先从上到下为“绝对路径”端口、“相对路径”文本框：悬浮“相对路径”并按 `↑` 后，整个“相对路径”文本框连同左侧端口成为第一行，“绝对路径”端口成为第二行。框内内容、上游连线、控件与参数的对应关系均保持不变。

没有对应输入口的其他控件继续按原顺序放在输入行之后。若移动后的输入框与右侧输出标签处于同一高度，会给右侧标签留出空间，避免输入框盖住输出文字。只调整输出顺序时，输入侧仍使用原生布局。

排序不改变控件数组的原始顺序，因此保存时各参数值仍对应原参数。端口、输入框及点击区域一起更新；重新打开工作流后恢复整行布局。节点高度不足时会增高，撤销后可能保留已扩大的高度，可手动缩小。

此功能排序已有端口，不会凭空增加输入，也不将没有端口的控件自动转换为输入口。

没有输入端口的节点保持原生控件布局，例如 Note 的文本框仍由 ComfyUI 按节点尺寸分配高度。旧工作流中的空输入排序记录不会启动控件重排；反复布局不会因此累积高度。自动整理也不再给没有端口的 Note 写入空排序记录。

## 动态端口与类型变化

- 排序记录使用稳定端口 ID；无 ID 时使用内部名称及同名端口的出现序号，不以中文显示标签或数据类型作为身份。
- 新增动态端口追加到当前侧的显示末尾，其他已存在端口保持顺序。
- 端口暂时消失时跳过该项；如果同一身份的端口重新出现，可恢复原有位置。
- 类型或显示标签改变，不会使端口因为“改名”而丢失排序。若节点实际改了内部名称且没有稳定 ID，则作为新端口处理。
- 多个端口内部名称完全相同时，依靠它们在原始数组中的同名出现次序区分；删除其中一项后，无法保证识别剩余同名端口原先的独立身份。
- 再次交换某一侧端口时，重新记录该侧当前存在的端口顺序，不继续保留已不存在的旧项；另一侧的排序设置不变。

分包、虚拟连接等节点仍按原来的通道编号和输入输出索引配对。移动“输出 2”的显示位置不会把它变成“输出 1”；排序不会更改这些节点原有的动态增删、类型同步或执行逻辑。

## 保存、复制与撤销

顺序保存在工作流节点的 `properties.liuxinyu_port_order` 中，包含版本号以及自定义的输入、输出顺序。只设置一侧时，另一侧继续使用默认布局。

保存的是显示偏好，临时绘制坐标不会替代原有端口坐标写入文件。撤销到排序前时，节点原先指定的自定义端口坐标继续使用。

应用排序使用工作流变更事件，纳入正常编辑记录；复制节点时随节点属性复制，复制之后两份节点可独立排序。撤销、重做或重新载入工作流后按恢复的属性重新布局。

文件必须正常保存，才能带到其他电脑。另一台电脑需要安装含此扩展的节点包并启用扩展；没有扩展时仍按原有逻辑执行，画布使用默认顺序。

## 子图与支持范围

支持主画布上的子图节点，以及嵌套子图里的普通节点和子图节点。分别进入对应画布，选中节点并悬浮端口后按方向键即可。

子图内部专门的“图输入 / 图输出”边界面板不是普通节点，使用另一套端口管理接口，本功能不调整这些面板。更改边界端口的定义顺序也不属于显示排序操作。

当前适配经典 LiteGraph 画布的端口布局与绘制接口。启用 **Vue Nodes / Nodes 2.0** 时，快捷键与悬浮提示不启用，已有排序设置保留但暂停显示。返回经典画布后恢复应用。

自行接管绘制、命中测试或布局的第三方特殊节点，需要另外核对其接口；不能把某个特殊节点的自绘区域等同于标准端口。

## 常见问题

| 现象 | 说明或处理方法 |
| --- | --- |
| 悬浮后没有提示或按键不生效 | 先刷新前端，选中节点，再悬浮在端口圆点或文字上；确认同侧至少有两个端口，且使用经典画布和标准端口布局。 |
| 正在编辑文字，方向键没有调整端口 | 正常行为；结束文本编辑、点击画布选中节点后再操作。 |
| 应用后节点变高 | 完整控件行需要按实际高度占位，尤其是多行文本框。 |
| 旧版整理后 Note 持续变长 | 更新并刷新前端后停止增长，已有空排序记录无需手动删除。已经增大的尺寸不会自动还原，可拖动边缘缩回合适高度后保存；Note 文字不受影响。 |
| 顶部端口不再是索引 0 | 这是显示排序的预期结果。数据仍按端口名称和原索引对应，不按屏幕上的上下位置重新编号。 |
| 换电脑后顺序未显示 | 确认保存了工作流文件，并在另一台电脑安装和启用新版扩展。 |
| 动态新增端口出现在底部 | 新端口默认追加，可悬浮该端口并按 ↑ 调整。 |
| 撤销排序后节点仍较高 | 顺序已恢复，可手动调整节点高度。 |
| 排序后仍有交叉线 | 本功能提供端口排序，不自动移动节点或添加转接点；复杂布局仍需结合节点位置调整。 |

## 开发与验证

实现位于 [`port_order.js`](../port_order.js)，通过包现有 `WEB_DIRECTORY` 自动加载；不新增 Python 节点、不改后端执行规则，也不改工作流文件中的业务配置。

命令行验证：

```powershell
node tests/test_port_order.cjs
```

还可向测试传入当前前端的 `settingStore-*.js` bundle 路径，直接验证安装版本中的坐标计算和点击边界函数。测试覆盖端口身份与连线不变、临时坐标不落盘、保存重载、动态端口、控件与端口整行移动、多行控件高度及点击区域、节点移动与缩放尺寸、折叠、子图安装、键盘交换、悬浮提示，以及编辑文字和拖动时不触发排序的检查。

Note 回归使用原生控件布局和弹性空间分配函数，验证带旧空排序记录的弹性文本框连续布局 100 次高度不变，以及手动缩小后尺寸稳定；同时覆盖没有端口和只有输出端口的节点。

模拟测试不替代页面视觉验收。更新后先保存页面中的编辑，再刷新浏览器；本功能只改前端，不需要为它重启后端。
