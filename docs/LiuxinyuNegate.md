# 取负

返回数值的相反数，输出 FLOAT，等同乘以 -1。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `数值` | 要取负的数字，可连接 INT 或 FLOAT | INT / FLOAT | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `相反数` | 输入乘以 -1 的结果；即使没有小数部分也属于 FLOAT，下游要求 INT 时可接“数字取整”。上游接执行列表时逐项各算一次 | FLOAT |

## 例子

- 3 → -3.0。
- -3 → 3.0。
- 0 → 0.0。

适合把偏移量或方向参数反向。如果只想去掉负号，请用“绝对值”。
