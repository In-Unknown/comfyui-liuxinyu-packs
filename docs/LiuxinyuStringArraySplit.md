# 切分字符串为数组

按一段完整的分隔文本把字符串切开，输出字符串执行列表，下游逐项处理（见[数组、执行列表与图片批次](DataLists.md)）。

## 怎么用

把被切分的文本接到“被切分字符串”，分隔用的文本接到“分隔符”（也是输入口）。例如：

| 被切分字符串 | 分隔符 | 输出 |
| --- | --- | --- |
| `苹果,香蕉,梨子` | `,` | `苹果`、`香蕉`、`梨子` 三项 |
| `a,,b` | `,` | `a`、空、`b`，空元素保留 |
| `,a,` | `,` | 空、`a`、空 三项 |

分隔符按原文完整匹配，不使用正则表达式，可以是一个或多个字符。分隔符为空时报错“分隔符不能为空。”；想按换行切分，请传入实际换行，例如把一个含换行的多行文本接到“分隔符”。

## 保留分隔符

“保留分隔符”打开时，分隔符追加到前一个元素末尾。例如 `第一章。第二章。` 按句号切分：

- 关闭：`第一章`、`第二章`、空
- 打开：`第一章。`、`第二章。`、空

两种设置下，把输出接[拼装字符串数组为字符串](LiuxinyuStringArrayJoin.md)都能还原原文。
