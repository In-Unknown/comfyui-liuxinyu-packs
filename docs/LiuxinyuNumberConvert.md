# 数字转换

每次把一个数字、布尔值或数字字符串转换为一个浮点数和一个整数。适合在 LLM 文本、开关状态和数学节点之间做类型衔接。不接收或隐式展开数组。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `值` | 连接一个整数、浮点数、布尔值或数字字符串；无默认值。标量执行列表由原生机制逐项传入 | INT / FLOAT / BOOLEAN / STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `浮点数` | 本次输入转换出的一个浮点数，不声明为执行列表输出 | FLOAT |
| `整数` | 本次输入转换出的一个整数，浮点向零截断；不声明为执行列表输出 | INT |

## 直接照做：把文本里的数字转成可用数值

1. 用字符串节点输出 ` 3.5 `，连接本节点的“值”。
2. “浮点数”得到单个 `3.5`，“整数”得到单个 `3`。
3. 将需要的输出接数学节点；不会额外展开或增加执行项。

单个值同样适用：布尔 `true` → 浮点数 `1.0`、整数 `1`；字符串 `" 3.5 "` 会先去掉首尾空白再解析，得 `3.5`。

## 转换规则

| 输入 | 浮点数 | 整数 |
| --- | --- | --- |
| 整数 `3` | `3.0` | `3` |
| 浮点数 `3.9` | `3.9` | `3`（向零截断，不是四舍五入） |
| 浮点数 `-3.9` | `-3.9` | `-3` |
| 布尔值 `true` / `false` | `1.0` / `0.0` | `1` / `0` |
| 字符串 `"2.5"` | `2.5` | `2` |

来自通用输出口的原生 `Decimal` 标量仍按数值转换；这不增加数组等容器的兼容行为。

## 数组必须显式转换为执行列表

如需处理 `[1,"2.5",true]`：

1. 用“字符串转为JS对象”解析这段 JSON，得到完整数组。
2. 连接“将任意数组转为执行列表”，显式将其展开。
3. 将执行列表接本节点的“值”。ComfyUI 依次传入 `1`、`"2.5"`、`true`，每次调用只产生一个浮点数和一个整数。
4. 原生执行器汇集得到浮点数执行项 `1.0、2.5、1.0`，整数执行项 `1、2、1`。需要完整数组时，再接“执行列表收集为数组”。

本节点既不设置整体接收执行列表，也不声明主动输出执行列表。只有上游已经产生执行列表时，才由原生调度逐项调用。若上游执行列表的某项仍是数组，该项也不能转换。

## 端口限制与旧工作流

输入口明确声明 `INT / FLOAT / BOOLEAN / STRING`，已知类型为 `ARRAY`、`DICT`、`IMAGE` 的输出无法直接连接，后端也按端口类型验证连线。

通用 `ANY` 上游可能实际返回任意类型，无法仅从连线判定其值；运行时仍检查数组等不支持的类型。旧工作流若直接传入数组，需要补上显式展开节点；单个标量和标量执行列表的正常转换保持不变。节点 ID、输入名称和两个输出的顺序不变。

修改后重启后端并刷新页面，使前端读取新的端口类型及标量输出声明。

## 会报错的情况

- 空字符串，或无法解析为数字的字符串，例如 `"abc"`。
- 字符串解析出非有限数值，例如 `"nan"`、`"inf"`。
- 任何数组或元组，包括空数组、一维数组和嵌套数组；不会逐项转换。
- `None`、字典、图片、张量等其他类型。

上游输出的是数组文本时，先解析为完整数组，再显式展开为执行列表；不能把完整数组或数组文本直接接入本节点进行批量转换。
