# 数字转换

把数字、布尔值、数字字符串或一维数组统一转换为浮点数与整数，两个输出口各给一份结果。适合在 LLM 文本、开关状态和数学节点之间做类型衔接。

## 直接照做：把文本里的数字转成可用数值

1. “字符串转为字面量”的字符串填 `[1, "2.5", true]`，接它的“完整字面量”输出。
2. “完整字面量”接本节点的“值”。
3. “浮点数”输出为执行列表 `1.0、2.5、1.0`，“整数”输出为 `1、2、1`，普通下游逐项执行。

单个值同样适用：布尔 `true` → 浮点数 `1.0`、整数 `1`；字符串 `" 3.5 "` 会先去掉首尾空白再解析，得 `3.5`。

## 转换规则

| 输入 | 浮点数 | 整数 |
| --- | --- | --- |
| 整数 `3` | `3.0` | `3` |
| 浮点数 `3.9` | `3.9` | `3`（向零截断，不是四舍五入） |
| 浮点数 `-3.9` | `-3.9` | `-3` |
| 布尔值 `true` / `false` | `1.0` / `0.0` | `1` / `0` |
| 字符串 `"2.5"` | `2.5` | `2` |
| 一维数组 `[1,"2.5"]` | 逐项 `1.0、2.5` | 逐项 `1、2` |

两个输出都是执行列表：数组逐项输出，普通下游每次收到一项；单个标量为一项。

## 会报错的情况

- 空字符串，或无法解析为数字的字符串，例如 `"abc"`。
- 字符串解析出非有限数值，例如 `"nan"`、`"inf"`。
- 空数组，或数组里套数组（只支持一维数组）。
- `None`、字典、图片、张量等其他类型。

报错时会提示实际收到的类型和值。上游输出的是数组文本时，先用“字符串转为字面量”的“完整字面量”转成真数组，再接本节点。
