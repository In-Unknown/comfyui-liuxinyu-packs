# 下标范围提取数组

指定起始下标 `min` 和结束下标 `max`，提取原数组在这个闭区间内的全部元素，组成一个新数组。适合选取连续记录、按范围抽取素材或截取数组的一段，无需先生成下标数列。

节点 ID：`LiuxinyuArrayRange`；分类：`liuxinyu/结构化数据`。沿用[下标提取数组元素为新数组](LiuxinyuExtractArray.md)的完整数组约定、从 0 开始的下标及越界报错规则；本节点专门选择连续范围。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `数组` | 待提取的完整原生数组，元素可为数字、字符串、字典、嵌套数组、null 等；无默认值，需要连接 | ARRAY | 是 |
| `min` | 起始下标，包含该项；默认 `0`。可填写或连接整数；控件范围为 `0` 至 `2147483647`，执行时还必须小于数组长度且不大于 `max` | INT | 是 |
| `max` | 结束下标，包含该项；默认 `0`。可填写或连接整数；控件范围为 `0` 至 `2147483647`，执行时还必须小于数组长度 | INT | 是 |

数组输入不解析 JSON 文本，不接受元组或单个对象。两个下标不接受布尔值、浮点数（包括 `1.0`）或数字字符串，不自动转换。下标合法范围为 `0` 到数组长度减 `1`，不支持负数倒数索引。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `提取出来的数组` | 按原数组顺序输出下标 `min` 到 `max` 的所有元素，包含两端；作为一个完整数组输出，不展开为执行列表 | ARRAY |

## 示例：提取连续三项

1. 用“字符串转为JS对象”解析 `["甲","乙","丙","丁","戊"]`，将结果接到 `数组`。
2. 将 `min` 设置为 `1`，`max` 设置为 `3`。
3. 将 `提取出来的数组` 接到“预览JS对象或数组”，运行后得到：

```json
["乙", "丙", "丁"]
```

两个范围参数也可连接整数输出。若使用“字符串转为字面量”提供原数组，应连接其保留完整数组的输出。

## 闭区间、顺序与原数据

`max` 指最后一项的下标，不是提取数量，也不是排除的边界。合法输入的输出长度为 `max - min + 1`。

| 原数组 | min | max | 输出 |
| --- | --- | --- | --- |
| `[10,20,30,40]` | 1 | 2 | `[20,30]` |
| `[10,20,30,40]` | 2 | 2 | `[30]`，仍是数组 |
| `[10,20,30,40]` | 0 | 3 | `[10,20,30,40]`，新的外层数组 |
| `[[1,2],{"a":3},null]` | 0 | 1 | `[[1,2],{"a":3}]`，不展开嵌套元素 |

按下标递增提取，保留重复值，不排序、不去重、不逆序。节点创建新的外层数组，不修改输入；元素保留原对象引用，不深拷贝字典、嵌套数组或图片张量。

需要不连续的下标、重新指定顺序或重复选择同一项时，使用“下标提取数组元素为新数组”。

## 空数组与输入错误

| 输入情况 | 结果及处理方式 |
| --- | --- |
| 原数组为 `[]` | 没有合法下标，报越界错误；闭区间必须包含至少一项 |
| `min` 或 `max` 为负数，或不小于数组长度 | 报告参数名、下标值及数组长度，不截断或跳过；调整到合法范围 |
| 两端合法但 `min > max` | 报告两个值及范围顺序错误，不自动交换，不返回空数组 |
| 任一下标为 `1.0`、`"1"`、`true` 或 null | 类型错误；提供明确的整数输出 |
| 输入 JSON 文本、元组或单个对象 | 数组类型错误；JSON 文本先用独立解析节点处理 |

输入不合法时本次节点报错，不交付部分提取结果。例如长度为 4 的数组，最后下标是 `3`，设置 `max=4` 会报错。

## 执行列表怎样处理

本节点不主动收集或展开执行列表，按 ComfyUI 原生规则逐项调用。每次调用的 `数组` 必须是完整数组，`min` 和 `max` 各为一个整数。输出的每个执行项也是一个完整数组。

例如 `数组` 上游有两项 `["甲","乙","丙"]`、`["丁","戊","己"]`，`min=1`、`max=2`，分别得到 `["乙","丙"]` 和 `["戊","己"]`，不合并为一个数组。多路执行列表按原生规则逐项配对，非空短路输入复用最后一个执行项。

需要先把单个元素的执行列表收集为数组时，使用“执行列表收集为数组”；需要将提取结果逐项交给下游时，再连接“将任意数组转为执行列表”。空执行列表由原生执行器处理，本节点不将其自动收集为完整空数组。

## 开发与验证

实现位于包根目录 `array_range_node.py`，使用 V3 `io.Schema` / `io.NodeOutput`，由根目录自动扫描注册，无需额外前端脚本。节点帮助按节点 ID 从本页加载。新增后重启 ComfyUI 后端并刷新页面，搜索“下标范围提取数组”即可添加。

使用 ComfyUI 的 Python 环境运行 `tests/test_array_range.py`，覆盖闭区间、单项和完整范围、嵌套元素引用与原数组保留、非法类型、越界及反向范围，以及原生执行列表映射。
