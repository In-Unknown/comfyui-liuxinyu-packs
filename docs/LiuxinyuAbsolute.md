# 绝对值

返回一个数到 0 的距离，去掉负号。适合计算不区分方向的差值距离。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `数值` | 输入值，须为有限数字 | FLOAT / INT | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `绝对值` | 输入的绝对值；上游接执行列表时逐项各算一次 | FLOAT |

- `-3` → `3.0`。
- `3` → `3.0`。
- `0` → `0.0`。

将两个位置先用“多输入数学运算”的减法求差，再接本节点，可以得到不区分方向的距离。例如位置 20 和 70 的差是 -50，绝对值为 50。

下游要求整数时再接“数字取整”。
