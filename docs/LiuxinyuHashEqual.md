# 判断哈希相等

输入两个完整数据值，输出一个 BOOLEAN：相同返回 `true`，不同返回 `false`。可用于比较图片处理前后是否变化，或给条件回归提供判断结果。

## 怎么比较

先检查类型，再计算数据内容的 **SHA-256 和 MD5**。任一摘要不同就返回 false；两者均相同时，还会逐块比较实际内容，所以不会只凭哈希相同就判定数据相同。摘要在本次调用内使用，不写入磁盘，也不长期缓存比较结论。

| 数据 | 比较规则 |
| --- | --- |
| 图片、普通 PyTorch 张量 | 比较 dtype、形状、每个元素的完整二进制内容，包括批次内所有图；忽略 CPU/GPU 位置、连续性和梯度标记 |
| NumPy 数组与标量 | 比较 dtype、形状和数据；对象数组逐项比较，结构化数组逐字段比较 |
| 列表、元组 | 比较容器类型、长度、顺序和每项内容；列表与元组不同 |
| 字典、Latent | 比较所有键和值，忽略字典插入顺序；Latent 内的 samples 张量也会完整比较 |
| 集合 | 比较集合类型与内容，忽略排列顺序 |
| 文本、数值、字节、None | 严格比较类型及内容；`1`、`1.0`、`true` 和 `"1"` 互不相同 |

这是严格数据比较，不是视觉相似度或容差比较。两张图片即使肉眼一样，只要浮点像素有微小差异也返回 false。浮点的正零和负零不同；NaN 只有二进制位模式相同才相同。图片尺寸相同但 dtype 不同也返回 false。

文件路径作为字符串比较，**不会打开对应文件比较文件内容**。比较图片文件时，应先加载图片像素数据。

## 执行列表

本节点一次接收两边的完整执行列表，输出一个布尔值，不按最短/最长列表逐项展开。

- A 是两项 `图片1、图片2`，B 也是两项时，比较数量、顺序与每项内容。
- 一边一项、一边两项，即使都是同一张图片，也返回 false。
- 完整数组 `[1,2]` 是一个值，与执行列表中的两个值 `1、2` 不同。
- 两边都是空执行列表时返回 true。

## 与条件回归配合

将本轮处理前后的数据分别接 A、B。本节点输出 true 表示数据没有变化；但「条件回归」收到 true 表示**跳回再执行一轮循环**，收到 false 才会**离开循环并将结果交给下游执行**。

如果希望“有变化就再处理一轮，没有变化就离开循环”，需要先把本节点的布尔结果取反，再接条件回归：数据相同 → true → 取反为 false → 进入下游；数据不同 → false → 取反为 true → 跳回循环。

## 支持边界

端口接受任意类型连接，但只有能够读取完整内容的数据才能可靠比较。模型、CLIP、连接句柄、未知自定义对象、循环引用会明确报错，请先提取要比较的张量、配置字典等实际数据。稀疏、量化或 meta 张量需先转换为普通有实际数据的张量。不会用 `repr()`、对象地址、Python 的 `hash()` 或不完整的序列化结果冒充完整数据。

大图相同时需要额外读取一次进行精确复核；GPU 张量需复制数据到 CPU，可能有耗时。比较不会把原图压成 8 位或缩小来节省计算。过程中可用 ComfyUI 中断。
