# 从模板生成文本

把模板里的 {t1}、{t2}…占位符替换成对应输入文本，可直接接 CLIP 文本编码等提示词输入。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `模板` | 含 {t1}、{t2}…占位符的文本；模板里写了却没提供的占位符原样保留，替换进去的内容不会再被递归解析。默认 `你好，我喜欢喝{t1}，且我喜欢吃{t2}，我在{t3}里面做{t4}`，支持多行 | STRING | 是 |
| `参数组合` | 连接[字符串排列组合](LiuxinyuStringCombinations.md)的输出；连接后忽略单独的 t1、t2…输入，由 ComfyUI 逐条处理组合 | TEMPLATE_PARAMETERS | 否 |
| `t1`～`t100` | 对应模板中的 {t1}、{t2}…占位符的输入文本，可接单个字符串或字符串执行列表；端口随连接增加，动态参数最多 100 个 | STRING | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `字符串数组` | 生成的文本，STRING 执行列表，下游逐项处理（见[数组、执行列表与图片批次](DataLists.md)）：接参数组合时每条组合生成一行文本；直接接列表时多路按行对齐，第 i 行取各路第 i 项，较短的一路复用其最后一项凑齐行数，某一路为空列表时输出空列表 | STRING |

## 单独填写参数

在 t1、t2…输入口接上字符串即可替换对应占位符。

## 连接参数组合（推荐）

把[字符串排列组合](LiuxinyuStringCombinations.md)的“参数组合”接到本节点“参数组合”输入后：

1. 单独的 t1、t2…输入被整体忽略，不再参与。
2. 每条组合生成一行文本，输出为字符串执行列表。
3. 下游逐条执行，例如逐条提示词编码出图。

## 示例

| 模板 | 参数 | 输出 |
| --- | --- | --- |
| `你好{t1}` | t1 接 `苹果` | `你好苹果` |
| `你好{t1}` | t1 未提供 | `你好{t1}` |

模板 `{t1}{t2}` 接参数组合（t1：红、蓝；t2：S、M）时输出四行：红S、红M、蓝S、蓝M。
