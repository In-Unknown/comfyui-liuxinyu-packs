# 字节数据提取图像字节

验证任意字节确实是一份完整图片，并输出可连接图片字节口的IMAGE_BYTES。实际格式与目标一致时直接透传原字节；不一致时转换为所选编码。它不是从ZIP、PDF或任意二进制容器中搜索图片的工具。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `字节数据` | 完整文件bytes；允许任意BYTES或已有IMAGE_BYTES；每项独立验证，不接受路径、URL、字典或Base64文本 | BYTES,IMAGE_BYTES | 是 |

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `图像格式` | 默认 PNG；PNG、JPEG、WEBP、BMP、TIFF、GIF，以及 Pillow 支持时出现的 AVIF | COMFY_DYNAMICCOMBO_V3 | 是 |
| `压缩等级`（PNG） | 0～9，默认6；只影响体积和编码时间，不改变像素 | INT | 选择PNG时 |
| `交错扫描`（PNG） | 默认关闭；开启写入 Adam7 交错 PNG，影响逐步显示，不控制透明 | BOOLEAN | 选择PNG时 |
| `质量`（JPEG / WEBP / AVIF） | 1～100，默认95；JPEG/有损WEBP/AVIF一般越高越精细且越大；WEBP无损时影响压缩努力程度 | INT | 选择对应格式时 |
| `色度采样`（JPEG） | 4:4:4、4:2:2、4:2:0；默认4:4:4保留更多彩色边缘细节 | COMBO | 选择JPEG时 |
| `渐进式`（JPEG） | 默认关闭；开启后逐步显示整图，不恢复有损丢失的细节 | BOOLEAN | 选择JPEG时 |
| `优化编码`（JPEG） | 默认开启；优化编码表，可能增加编码耗时 | BOOLEAN | 选择JPEG时 |
| `无损`（WEBP） | 默认关闭；开启使用无损像素压缩，保留透明像素的RGB | BOOLEAN | 选择WEBP时 |
| `压缩力度`（WEBP） | 0～6，默认4；越高通常压缩更慢、更充分 | INT | 选择WEBP时 |
| `压缩方式`（TIFF） | 无压缩、LZW、Deflate，默认Deflate；均为无损编码 | COMBO | 选择TIFF时 |
| `颜色数`（GIF） | 2～256，默认256；保留Alpha时留一个调色板索引用于透明 | INT | 选择GIF时 |
| `抖动`（GIF） | 默认开启；用误差扩散改善有限颜色的渐变，可能呈现颗粒感 | BOOLEAN | 选择GIF时 |
| `编码速度`（AVIF） | 0～10，默认6；越大通常编码越快、压缩效率越低 | INT | 选择AVIF时 |
| `保留透明度`（PNG / WEBP / TIFF / GIF / AVIF） | 默认开启；有Alpha时保留。GIF只能全透明或不透明，Alpha小于128的像素转为全透明 | BOOLEAN | 选择对应格式时 |
| `去透明背景`（全部格式） | 白色、黑色，默认白色；仅在目标不支持透明或关闭保留透明度时合成背景 | COMBO | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `图像字节` | 格式一致时输出原文件一项；不一致时逐帧转码输出执行列表，顺序与原帧顺序相同 | IMAGE_BYTES |

## 怎么用

1. “从路径加载字节数据”读取 `C:\images\product.jpg`，将字节输出接本节点。
2. 图像格式选JPEG。有效JPEG保持每个原字节，即使将质量改为20也不重新压缩。
3. 输出接“保存图像到绝对路径”，文件名 `copy.jpg`，可以得到与原文件完全相同的字节；也可接Harness远程图片输入。
4. 若希望输出PNG，将格式改为PNG；这次会解码并重新编码。若希望调整同格式JPEG质量，改用“图像字节转码”。

## 完整验证，不只改标记

格式依据文件内容，忽略原扩展名。先验证图片结构，再实际解码每一帧，避免仅有正确文件头的损坏图片通过；JPEG扫描数据也会读取。格式相同仍需验证，并非未经检查就更换连线类型。

## 同格式与跨格式的区别

同格式透传保留原编码、元数据、透明度、动画和全部帧，不应用质量、交错、Alpha或背景参数。跨格式则应用当前参数，按EXIF纠正方向后转换为8位图像，不保证保留ICC/EXIF等元数据；多帧分为独立文件，不保留动画时序，不自动缩放。

PNG交错不是透明开关。要调整一个已经是PNG的文件的透明度或交错方式，使用“图像字节转码”，因为本节点在同格式时不会改文件。所有参数含义见[图像编码与字节数据](ImageBytes.md)。

## 缓存与报错

验证与转换使用ComfyUI正常缓存，不自动保存。空字节、非图片、截断图片、错误类型会报错；损坏文件需重新获取源文件。格式插件不可用或目标不支持图片尺寸时也会报错，不能通过改扩展名规避。
