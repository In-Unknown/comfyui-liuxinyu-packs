# 预览参数组合或字符串数组

无输出节点，仅用于画布上查看：连接后运行工作流，在节点上直接浏览内容，不修改、不拆分输入文本。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `参数组合 / 字符串数组 / 字符串` | 三种内容都能接，显示方式见下表；上游执行列表整批收取预览 | STRING / LIUXINYU_TEMPLATE_PARAMETERS | 是 |

## 输出

无输出口，仅用于画布上查看。

## 显示方式

| 输入 | 显示方式 |
| --- | --- |
| 参数组合 | 按 t1、t2…分列的表格，每行一条组合 |
| 字符串数组 | 按原下标逐条显示 |
| 单个字符串 | 整段显示，保留换行 |

## 怎么用

把[字符串排列组合](LiuxinyuStringCombinations.md)的“参数组合”或[组装字符串为字符串数组](LiuxinyuStringArrayBuild.md)的输出接到本节点，运行后展开节点查看；确认无误再把同一来源改接下游，例如“从模板生成文本”的“参数组合”。

条目多时连续滚动浏览，行列按可见区域动态显示，不用翻页。本节点没有输出口，数据到此为止；要继续传递请从上游节点并联连线。
