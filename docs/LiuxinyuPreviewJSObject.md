# 预览JS对象或数组

无输出节点，仅用于画布上查看：以可展开的树状结构显示对象或数组的属性名、数组下标、数据类型和值。

## 怎么用

把[字符串转为JS对象](LiuxinyuStringToJSObject.md)的输出接到“对象或数组”，运行后在节点上逐层展开查看。点选条目可查看完整内容，支持复制 JSON。

输入必须是解析后的对象或数组；接到数字、字符串等标量（例如“使用js点符号语句读取对象”读出的单个值）时会报错，提示请连接解析后的对象或数组。

条目多时连续滚动，不分页。普通滚轮滚动预览内容，Ctrl 加滚轮缩放画布，两者互不干扰。

## 与预览文本的区别

[预览参数组合或字符串数组](LiuxinyuPreviewText.md)面向字符串、字符串数组和参数组合；本节点面向嵌套的对象和数组，能逐层展开结构并复制 JSON 文本。
