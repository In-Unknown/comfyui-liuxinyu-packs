# 预览JS对象或数组

无输出节点，仅用于画布上查看：以可展开的树状结构显示对象或数组的属性名、数组下标、数据类型和值。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `对象或数组` | 解析后的对象或数组（例如“字符串转为JS对象”的输出）；接到数字、字符串等标量（例如“使用js点符号语句读取对象”读出的单个值）会报错，提示请连接解析后的对象或数组。上游执行列表整批收取预览 | DICT / ARRAY | 是 |

## 输出

无输出口，仅用于画布上查看。

## 怎么用

把[字符串转为JS对象](LiuxinyuStringToJSObject.md)的输出接到“对象或数组”，运行后在节点上逐层展开查看。点选条目可查看完整内容，支持复制 JSON。

条目多时连续滚动，不分页。普通滚轮仅在预览内容能继续滚动时被接收；内容放得下或已到边界时交还画布。快捷键滚轮沿用画布设置。

## 与预览文本的区别

[预览参数组合或字符串数组](LiuxinyuPreviewText.md)面向字符串、字符串数组和参数组合；本节点面向嵌套的对象和数组，能逐层展开结构并复制 JSON 文本。

## 节点内部绘制与操作

预览使用节点的原生画布成员 `addCustomWidget` 绘制，不创建覆盖画布的 HTML 页面。工具栏、树状列表、完整值详情、按钮及滚动条都在节点边界内布局和裁剪，跟随画布缩放和平移；调整节点大小后按当前内部空间排列。活动面板中的预览副本不会覆盖主画布的点击区域或滚动状态。

例如输入 `{"商品":{"名称":"示例","规格":["小号","大号"]}}`：运行后根对象默认展开；点击“商品”左侧箭头，再展开“规格”，可看到 `[0]`、`[1]`。点击名称或值所在行，下方出现完整 JSON 值的自动换行详情；再次点击同一条目取消选中并关闭详情，点击其他条目切换选中；点击箭头只改变展开状态，不取消选中；“复制此值”复制完整选中值，右上角双纸张复制图标复制完整结果，不受屏幕显示宽度影响。关闭详情后列表重新占用释放的空间。已移除独立“收起”按钮，折叠由箭头控制。按住 Ctrl 点击某个容器左侧的箭头：当前收起时递归展开它及所有后代；当前展开时同时收起它及所有后代，不影响其他分支。再次普通展开时，其下级仍保持收起。Ctrl 点击在松开鼠标时生效，拖离箭头或取消指针操作不会触发，也不会误触画布的 Ctrl 选择操作。

普通滚轮在指向的树列表或详情区域滚动，也可拖动各自的右侧滚动条；Ctrl／Meta 加滚轮不由预览处理，Shift 等快捷键沿用画布前置处理。当前包启用画布滚轮平移时，Ctrl 为水平平移、Shift 为垂直平移。点击条目后，上下方向键选择相邻项，左右方向键收起／展开容器，空格或 Enter 切换选中容器的展开状态。文本编辑框持有焦点时不拦截这些按键。画布文字不能像网页文本一样拖选，复制请使用上述按钮。

双击节点右下角调整尺寸的角落，会保持当前宽度，按当前已展开内容自动调整高度，并重置内部滚动位置。若完整值详情已打开，也计入它按当前宽度换行后的全部高度，使树列表和详情都不必内部滚动；不会擅自展开已收起的分支，不修改输入数据。再次双击可移除多余高度。

树状引导线依据实际父子和同级关系绘制：父节点箭头下方接竖向主干，各子项由短横线接入；父级还有后续同级项时，主干穿过当前展开分支继续向下，最后一个子项的中心处收尾。每层分别连接，折叠后隐藏其下级线条；过深且没有缩进空间的层级不重复堆叠线条。线条使用低对比度灰色，选中行内使用 #353535，随画布缩放并受列表裁剪。

可点击箭头、条目和按钮悬浮时显示手型鼠标；滚动条显示上下调整鼠标。移出、切换工作流或删除节点后交还鼠标样式，不覆盖其他控件持有的样式。

列表仅绘制可见行，不分页。长键名和值在列内裁剪，点击行可看完整值；详情内长文本自动换行并可独立滚动。新一次执行替换结果、展开各组根项并清除旧选择和滚动位置；不把运行结果写入工作流配置。上游执行列表产生多组结果时分别显示根项，复制全部时输出包含各组的 JSON 数组。

## 限制与验证

顶部不显示“对象 · N 项”或结果组数摘要，仅保留复制图标。节点不显示常驻操作说明，操作方式见本帮助页；底部仅用于显示复制成功或失败反馈。剪贴板复制依赖浏览器授予的权限，失败会在节点底部显示“复制失败”。节点仍只读，不修改输入对象，没有输出口。此次布局实现的命令行测试覆盖树展开、详情和复制、节点边界、万项数组的可见行绘制、滚轮隔离及活动面板副本；实际页面视觉与鼠标操作需刷新后验收。
滚轮事件与 JSON Schema 填写模版一致：像素单位直接使用 deltaY，行单位每行 16，页单位为当前滚动区域高度；不把 deltaX 转为垂直滚动。每次立即将滚动位置限制在有效范围，只有位置实际改变才阻止默认行为与事件传播。树列表和详情是两个独立区域，在详情边界不会暗中滚动树列表。

## 自然高度与表单组件一致性

收到结果、展开或收起分支、打开或关闭详情时，默认按照当前内容自然高度调整节点，不设置列表高度上限。树列表和详情各自按实际行数及换行测量，不再用固定的 55%／45% 比例切分空间；内容放得下时完整显示。用户手动调整的节点高度会保留，只有实际空间不足才出现滚动；双击右下角清除手动高度并恢复完整内容高度。宽度保持不变。

箭头使用与 JSON Schema 填写模版相同的几何三角：展开宽 10、高 6，收起宽 6、高 10，置于 24 高的内容行中心，行间保留 4 的间隔。悬浮与按下分别提亮箭头。文本复用表单字体和字形基线计算，按实际文字垂直居中；长文本在列内省略，完整值见详情。按钮沿用表单的 3 单位圆角和默认、悬浮、按下颜色。只读预览不引入表单的编辑、删除或校验操作。

## 完整 JSON 语法着色

下方详情按 JSON 词法着色，参照 VS Code 深色主题：属性名浅蓝、字符串橙色、数字浅绿、布尔值和 null 蓝色，逗号与冒号灰白；对象和数组括号按嵌套层级使用黄、紫、蓝循环配对。转义引号和反斜杠仍属于字符串，不会误识别为结构符号。着色直接绘制于节点画布，不引入 HTML 层。

自动换行后保留每段的语法颜色，同一行共用基线；颜色只影响显示，不改变 JSON、复制结果、内容高度或滚轮规则。
