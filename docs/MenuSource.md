# 右键菜单来源标签

在经典画布的右键菜单中，以小号灰蓝色 `liuxinyu` 标明本包新增的选项，便于从默认选项中找到它们。沿用原生底色、选项文字、悬浮和禁用效果，无需添加节点或设置开关。

## 入口与操作

更新前端脚本后按 `Ctrl+F5` 刷新页面，不需要重启后端。

| 菜单选项 | 出现位置与条件 | 对应说明 |
| --- | --- | --- |
| `整理节点` | 选择至少两个节点后，右键节点或画布空白处；实际整理支持 2～40 个节点 | [整理节点](GraphLayout.md) |
| `检查/同步后端工作流文件` | 画布空白处右键，文件同步机制初始化完成后出现 | [工作流文件变动提示](WorkflowFileSync.md) |
| `查看未保存差异` | 画布空白处右键 | [工作流文件变动提示](WorkflowFileSync.md) |

## 输入与输出

这是自动生效的界面标记，没有节点输入口、输出口或用户参数。读取本包创建的菜单项，在菜单显示来源；不产生执行数据，也不往工作流保存标记。

## 显示示例

选中多个节点，在画布空白处右键，本包选项连续出现时可看到类似：

```text
原生菜单选项
────────────────────────────────
整理节点                   liuxinyu
检查/同步后端工作流文件     liuxinyu
查看未保存差异             liuxinyu
```

具体顺序由当前菜单决定；这里只有来源标记，没有额外的可点击标题或子菜单。直接点击原选项文字或同一行的标签区域，即执行原来的操作。

## 分组与主题

- 每一条本包选项右侧都显示来源，包括连续排列的选项，逐项明确归属。
- 本包选项与其他选项的边界使用细分隔线；已有原生分隔线的地方不再叠加一条。
- 标签颜色混合当前文字色与灰蓝色，以适应明暗主题；不用醒目的整行底色。禁用时继承原生禁用效果。
- 仅标记本包明确创建的上述菜单项，不通过名称猜测其他插件或原生选项的来源。节点内部按钮、文件列表菜单等其他入口不在本次范围内。

## 常见问题

| 现象 | 说明或处理 |
| --- | --- |
| 没有“整理节点” | 先选择至少两个节点，再打开节点或画布菜单；端口自己的菜单不是普通节点菜单 |
| 刷新后仍没有标签 | 使用 `Ctrl+F5` 重新加载前端资源；本功能适用于原生经典画布菜单，其他扩展替换菜单渲染时需另行适配 |

## 开发与验证

`menu_source.js` 通过现有扩展加载方式安装样式，菜单生产者显式标记自己的条目。使用原生菜单的 `className` 支持和 CSS 相邻选择器，不替换原生菜单构造器，不扫描页面或重排菜单。

命令行验证：`node tests/test_graph_layout.cjs`、`node tests/test_workflow_file_sync.cjs`。覆盖菜单标记、已有类名和回调保留、禁用状态、样式只安装一次，以及原整理和文件同步行为。最终标签颜色、分隔线和点击观感由页面验收。
