# 函数生成精度数列

输入数学表达式，按每个自由变量的范围、间隔与小数位采样，输出值执行列表、采样坐标和完整高精度数列。支持有限求和、逐层截断的无穷级数，以及独立于数值计算的符号性质分析。适合参数网格、级数实验和高精度数列生成。

节点 ID：`LiuxinyuFunctionGrid`；分类：`utils/math`。公式上方的 `i 分析` 按钮展开与按钮锚定的非模态分析卡片，显示当前步骤、各个求和的结论与依据。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `函数` | 默认 `sin(x) + y`，多行数学表达式；自由变量按从左到右的出现顺序生成采样端口 | STRING | 是 |
| `{变量} 最小值` | 默认文本 `0`，采样起点；十进制范围为 -9223372036854775808～9223372036854775807 | FLOAT / INT / STRING | 否 |
| `{变量} 最大值` | 默认文本 `1`；范围同最小值，不小于最小值；恰好落在步长上才包含 | FLOAT / INT / STRING | 否 |
| `{变量} 间隔` | 默认文本 `0.1`，必须为正且不超过 9223372036854775807 | FLOAT / INT / STRING | 否 |
| `{变量} 小数位数` | 默认文本 `2`，非负整数，最多 9223372036854775807；指定采样坐标允许的小数位数，不等于函数值的有效数字保证 | INT / STRING | 否 |
| `{求和索引} 运行项数` | 仅上限为 `INF` 或 `∞` 的索引生成，默认文本 `5000`；范围 1～9223372036854775807；每次进入这个求和都计算这么多项 | INT / STRING | 否 |

上述动态控件采用单行十进制文本编辑并保存，避免浏览器 `Number` 把大整数舍入。没有 2048 的范围上限。参数仍有数学语义限制：间隔必须为正，小数位数非负，运行项数为正整数。输入框不接受千位分隔逗号。Python 精确解析整数；浮点输入本身已经丢失的精度无法恢复，完整 64 位整数请使用文本或精确 INT 来源。

隐藏 `axes_json`（STRING，默认 `{}`）随工作流保存动态配置，不是用户手填控件。结构如下；连接到对应动态端口的值优先于存储值：

```json
{
  "axes": {"x":{"min":"0","max":"1","step":"0.25","precision":"2"}},
  "series": {"k":"5000","项数":"50"},
  "order": ["x"],
  "series_order": ["k","项数"]
}
```

API 动态名称为 `min1/max1/step1/precision1` 等；无限求和按出现顺序命名 `terms1/terms2`。名称与公式解析结果对应。界面按变量身份保留参数和已有连线，不因重新编号将 x 的连线转给 y；编辑到语法不完整时暂不删除原端口。

加载已保存的工作流时，按 `axes_json` 保存的变量和求和索引顺序同步恢复端口及输入框，然后再异步解析公式、更新分析。已有参数端口不必等待符号分析完成才能连接；重建端口后同步更新布局，避免出现有端口却没有对应输入框、鼠标命中位置重叠的过渡状态。

“多输入数学运算”的 `FLOAT` 结果可直接连接最小值、最大值和间隔，不需要转字符串。小数位数及运行项数接受 `INT / STRING`，数学运算的结果即使数值恰好为整数，端口仍为 `FLOAT`；需要通过“数字取整”等整数输出节点后连接。端口类型兼容与数值合法是两件事：例如间隔可连接 FLOAT，但执行时仍要求其为正数。

### 端口亮起却连不上，或最小值连线无法拖动

旧工作流可能保存了内部 `axes_json` 输入端口。其隐藏输入框为零高度时，端口可能与紧随其后的最小值端口重叠：画面显示可连接的数值端口，鼠标却命中内部字符串端口，造成 FLOAT 拖入后没有连线；向外拖动时则可能从内部端口新建线，而没有移动最小值的已有连线。

新版在整个工作流及连线恢复完成后，清理未连接的内部配置端口，通过 ComfyUI 的端口删除方法同步调整后续连线索引，保留采样配置及数值端口的连接。若内部配置口确有旧连线，则保留连接并显示为独立的“采样配置（旧版连线）”端口，不再与隐藏输入框共享位置。正常使用无需操作这个内部参数。

更新后刷新页面即可加载修复，无需重启后端；旧工作流重新加载时自动处理。建议保存一次更新后的工作流。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `值执行列表` | 保留原输出位置与语义：普通双精度结果组成嵌套数组，最外层拆分为执行列表；每次下游收到外层一项 | ARRAY（执行列表输出） |
| `采样坐标` | 原有 `order`、`shape`、`axes` 保留；新增精确十进制字符串坐标 `exact_axes` 及本次十进制工作精度 `working_precision` | DICT |
| `高精度数列` | 新增在末尾：与普通数列同形状的十进制字符串数组，作为一个完整数组输出，不拆成执行列表 | ARRAY |

普通输出会再次舍入为二进制浮点数，不能承担任意精度保证。超出普通浮点范围的位置输出 `null` 并警告，高精度字符串仍保留结果；非零值在普通输出下溢为 0 时也警告。极大坐标的 `axes` 可能舍入成相同值，但内部使用 `exact_axes` 精确坐标计算。

高精度输出里的元素是字符串。后续若转为普通 FLOAT，会重新受双精度限制；保存原字符串才保留这些位数。常数公式的高精度输出是单项数组，例如 `0.1+0.2` 得到 `["0.3"]`。

### 三个输出如何连接

- `值执行列表`：需要下游逐项执行时使用。`x` 从 0 到 2、步长 1、函数 `x+1` 得到三个执行项 1、2、3；下游按 ComfyUI 执行列表机制分别处理。多变量结果只拆最外层，内层数组不会继续自动展开。
- `采样坐标`：连接“预览JS对象或数组”，查看变量顺序、各维长度及精确坐标，与结果按索引对应。
- `高精度数列`：需要整体数组或保留精度时使用。同一示例一次输出 `["1.0","2.0","3.0"]`，每项为十进制字符串。

第一输出原名“多维数列”，现改为“值执行列表”；输出编号、类型、拆分规则和已有连线不变，旧工作流加载时会同步显示新名称。

## 直接照做：生成正弦采样

1. `函数` 填 `sin(x)`。
2. `x 最小值` 填 `0`，`x 最大值` 填 `1`，`x 间隔` 填 `0.25`，`x 小数位数` 填 `2`。
3. 运行后，“值执行列表”输出 `0、0.2474…、0.4794…、0.6816…、0.8415…` 五个执行项。
4. 将“高精度数列”接“预览JS对象或数组”，查看一个完整的五项十进制字符串数组。

采样使用十进制整数步进。范围 0～1、步长 0.3 时得到 0、0.3、0.6、0.9；1 不落在步长上，因此不包含。

## 直接照做：拉马努金圆周率公式

`函数` 填入：

```text
9801/(2*sqrt(2)*(sum(k=0 to INF) [((4*k)!*(1103+26390*k))/((k!)^4*396^(4*k))]))
```

将 `k 运行项数` 设为 `3`，不需要自由变量采样端口。点击 `i` 查看分析：级数由比值极限 `1/96059601 < 1` 证明绝对收敛。运行后，“值执行列表”只有一项，约为 `3.141592653589793`；“高精度数列”只有一个字符串，开头为 `3.1415926535897932384626490657…`。这仍是三项截断得到的近似，不能把全部显示位当成 π 的正确位。

分析器还会把尾部比值写成 `P(t)/Q(t)`（t≥0），计算系数比的上界 q，并验证 `qQ(t)−P(t)` 各系数非负。此公式得到 `q=1/96059601`，进而给内部级数的严格尾界 `a_3/(1−q)`。这是内部求和的界；倒数及外部系数的误差传播属于复合表达式层，面板明确标出该界的对象。

## 求和语法与作用域

```text
sum(k=1 to 10) k^2
∑(项数=0 to ∞) 1/项数!
sum([k=1] to [INF]) [(-1)^(k+1)/k]
```

- `sum` 与 `∑` 等价；`INF` 与 `∞` 等价。`INF` 区分大小写，只能作为求和上限。
- 有限上下限都必须算出整数，范围在有符号 64 位内；两端包含，每次加 1。终点小于起点时为空和，结果为 0。
- 索引支持多字符英文、中文及数字后缀，例如 `k`、`term_index`、`项数`；必须是合法标识符，不能使用函数名、常量名或保留字。
- 索引在整条公式中必须全局唯一，包括并列求和。内层可以读取外层索引，例如 `sum(k=1 to 3) sum(m=1 to k) m`，结果为 10。
- 索引只在自己的通项及其内层作用域有效。`(sum(k=1 to 3) k)+k` 错误；该末尾 k 不会被偷偷变为采样变量。
- 自由变量仍生成采样控件，求和索引不生成采样范围控件。`sum(k=0 to INF) x^k` 只为 x 生成采样范围，为 k 生成运行项数。

**用方括号界定通项，或用圆括号包住整个求和。** 裸通项一直延伸到当前分组的结束。并列求和建议写为：

```text
sum(k=1 to 3) [k] + sum(m=1 to 2) [m]
(sum(k=1 to 3) k) + (sum(m=1 to 2) m)
```

两种写法均得到 9。不要把 `sum(k=1 to 3) k + 100` 理解成“先求和再加 100”；它的通项是 `k+100`，结果为 306。求和头部起始定义与上限的方括号可选。

## 无限截断项数与嵌套

表达式：

```text
sum(t=1 to INF) [sum(m=1 to INF) [1/(t*m)^2]]
```

末尾出现 `t 运行项数` 和 `m 运行项数`，均默认 5000。t 每轮都重新进入 m 求和，因此每个 t 都会计算 5000 个 m，通项次数为 5000×5000，而不是全局共用 5000 项。若有采样网格，还要对每个采样点执行一次整个表达式。

实际计算始终是用户指定的有限截断，不自动替换为符号求出的无穷和、不因证明收敛就提前停止。发散和未知也照常计算有限项；单项无定义、复数或非有限结果仍报错，因为那是数值定义域问题。

## 收敛性、证明与严格误差界

编辑完成后自动进行符号分析；正式执行时使用实际输入项数重新分析。计算仅使用本机 SymPy 与 mpmath，不调用付费 API。符号常量按精确整数、有理数构造，避免先转换为浮点近似再做证明。

每个无限求和只给三类结论：**确定收敛、确定发散、暂时无法确定**。有限和单独标记为“有限和，不适用无穷级数判别”。发散或未知使用 ComfyUI 官方 toast 服务发出警告，解释对应理由，不阻止计算；无需在模态框中确认。

| 判别或推导 | 实际使用范围与证据 |
| --- | --- |
| 通项趋零必要条件 | 解析计算绝对值通项极限；非零可证明发散 |
| 比值判别 | 精确求出比值极限；小于 1 得绝对收敛，大于 1 得发散，等于 1 不作结论 |
| 全尾部比值上界 | 用比值单调性或有理式系数比较证明所有剩余项的比值≤q<1，实际计算首个遗漏项及几何尾界；记录差多项式作为证据 |
| 根值判别 | 在其他路径未确定时尝试解析根值极限，严格使用与 1 的大小关系 |
| 直接比较、p 级数 | 固定幂次、已知符号系数及三角因子幅值界；不会把 `1/k^k` 当固定 p 的级数 |
| 极限比较 | 对适用的非负有理通项，以分子分母次数构造 p 级数，验证极限为有限正数 |
| 积分判别 | 核对连续延拓定义域、非负和单调不增，再解析计算广义积分 |
| 莱布尼茨判别 | 验证交错结构、非负单调幅值及趋零；给首个遗漏项的严格余项界 |
| Dirichlet 判别 | 当前提供可证明三角部分和界的线性相位形式，以及非负单调趋零权重；由分部求和给尾界 |
| Abel 判别 | 当前尝试可分解为已证交错基级数与单调有界因子的形式；条件逐项检查，不仅按外观分类 |
| SymPy 组合判别 | 仍未确定时调用 `Sum.is_convergent`；面板明确标记该接口没有暴露内部逐步证明，不虚构具体判别过程 |

检查原始通项的分母零点、阶乘定义域及其他定义域条件，不因为符号约分就忽略奇点。例如 `(k-10)/(k-10)` 在 k=10 仍无定义。不能排除奇点时不报告确定收敛。

**收敛证明不是数值精度证明。** 例如 `sum(k=1 to INF) [(-1)^(k+1)/k]`：

- 幅值 `1/k` 单调趋零，由莱布尼茨判别收敛；绝对值为调和级数，故是条件收敛。
- 计算 N 项时，严格 `|R_N| ≤ 1/(N+1)`。N=5000 时为 `1/5001`，不因“已证明收敛”就变成 0。
- 该界只控制有限截断与无穷和之间的差，不包含计算与输出舍入误差。

几何级数使用严格几何尾界；p>1 的 p 级数使用积分尾界；阶乘等形式若能证明整个尾部的比值上界 q<1，则给对应几何控制界。**只有比值极限小于 1，还不足以直接给某个 N 的误差界。** 无法取得界时明确写“尚未获得严格截断误差界”，不用相邻部分和之差替代。

简单有理式的余项界会代入实际项数并化简，例如 `1/10001`。复杂阶乘或巨大幂仍可保留 `Subs(表达式, k, 5001)`，表示将 k 精确代入 5001；`Integral(...)` 表示保留的精确积分。面板的“计算与证明过程”逐步列出运算、输入表达式、结果、判别条件及理由；比值极限等于 1 会记录“无判别力”，并继续其他方法。

### 参数范围与逐点证明

分析使用变量控件的最小值、最大值和步长。编辑时读取页面配置，正式执行时读取实际连接值。优先在配置闭区间的笛卡尔积上证明：

| 形式 | 范围分析 |
| --- | --- |
| 几何级数 | 求公比和首项的范围；当统一 `q=max|r|<1` 时给一致绝对收敛、统一尾界及部分和上界；单参数跨边界时求解收敛域、发散域及零首项例外 |
| p 级数 | 求指数 p 和系数范围；`p_min>1` 时用统一 p 级数与积分界；单参数跨越 p=1 时解出两侧区域 |
| 交错 p 级数 | `p_min>0` 时验证统一莱布尼茨条件并给首个遗漏项界；按 p>1 与 0<p≤1 区分绝对、条件收敛 |
| 其他参数形式 | 对实际采样网格逐点代入后做符号证明，记录每个点的判别过程和失败原因；结论标明“离散采样网格”，不扩展为整个连续区间 |

例：`sum(n=0 to INF)x^n`，x 范围 0～0.5，运行 20 项。程序求出 `r=x∈[0,1/2]`、`q=1/2`、首项为 1，得到一致绝对收敛和统一尾界 `1/524288`。范围改为 0～1 时，报告 `[0,1)` 收敛、`{1}` 发散；这是范围内结论不同，并非判别器没有结果。采样网格若不包含发散边界，逐点结论会另外注明其范围。

检查原式中分母与负指数定义域，避免先化简后丢失参数奇点。区间方法受阻时记录具体表达式和符号求解结果，再执行逐点证明。

### 实际数值诊断

每次有限求和实际累计 `S_N=Σa_n` 和 `A_N=Σ|a_n|`，计算 `κ=A_N/|S_N|` 及 `max(0,log10κ)` 的消去敏感度。这里不是按公式外观套用说明文字。多参数或嵌套求和记录全部调用次数、外层索引和参数；面板展示条件数最大的一次调用，汇总所有调用的双精度范围风险。

| 指标 | 计算与含义 |
| --- | --- |
| 求和条件数 | 从实际通项算 `A_N/|S_N|`；S_N=0 且 A_N>0 为无穷大，全零时相对条件数无定义 |
| 消去敏感度 | `max(0,log10κ)`，表示输入项相对扰动可能放大的十进制位数；不是本次必然丢失的位数 |
| 实际求和误差 | 以已计算通项的精确有理数/二进制值之和为参照，与实际累加结果比较，给绝对和相对误差；相对误差在参照和为零时不定义 |
| 高精度参考重算 | 通项包含近似函数值时，提高 30 位工作精度，以同一参数坐标完整重算一次表达式，匹配各层求和的外层索引，记录参照值、绝对差异和相对差异；它是实际数值估计，与严格界分列 |
| 通项来源 | 全部为有理数时，参照值是原始数学通项的精确和；含近似函数值时，参照对象是已经求出的有限精度通项，单独标明误差计算对象 |
| 普通输出转换误差 | 把 binary64 结果恢复为精确有理数，与内部计算结果比较；数值为零时显示实际零误差 |
| 溢出、下溢、次正规数 | 统计通项进入 binary64 的范围风险，并报告实际普通输出的范围类别；任意精度内部结果另行保留 |
| 顺序累加对照模型 | 用 `u=2^-53`、`γ_k=ku/(1-ku)`、`k=N−1` 算 `γ_k A_N` 和 `γ_kκ`；注明正常有限范围等前提，作为双精度顺序求和模型，不冒充实际 fsum 的误差 |
| 总误差合成 | 对有已证截断界、精确数学通项的单层级数，将截断界、求和误差及输出转换误差相加；误差数值先向上舍入，面板同时给合成式与近似显示值 |

内部对纯有理数求和全程使用精确分数；出现近似函数值时使用 mpmath.fsum，并从实际结果计算求和环节误差。通项的近似函数求值误差与累加误差是不同对象，诊断字段明确记录参照范围。对于超过一百万位二进制指数的极端近似值，数值计算继续，但精确诊断展开会记录预算和具体指数，避免诊断本身展开不可控的大整数。

直接照做：`sum(n=0 to ∞)(-1)^n/(2n+1)`，n 运行项数填 5000：

1. `b_n=1/(2n+1)`；差分 `b_(n+1)−b_n=−2/((2n+1)(2n+3))≤0`，极限为 0，莱布尼茨判别给收敛。

### 直接照做：幂律余项与目标项数

1. 公式填 `sum(n=1 to INF)1/n^2`，`n 运行项数` 填 `20`。
2. 展开“误差界”：正值递减函数的积分比较得到 `1/(N+1)≤R_N≤1/N`，当前范围为 `[1/21,1/20]`。
3. 展开“收敛速度”：上下界乘以 N 后均趋于 1，夹逼得到 `R_N~1/N`，渐近阶 `Θ(N^-1)`，首项常数 1。
4. 要求 `|R_N|≤ε` 时，充分条件为 `N≥ceil(1/ε)`。面板提供符号项数条件，运行项数仍由用户设置。

对 `sum(n=0 to INF)(1/2)^n`，精确余项为 `R_N=2^(1−N)`；正公比使部分和严格递增，上确界为 2，有限 N 的部分和始终小于 2。面板分别记录上确界和取到条件。

### 参数空间、边界与敏感度

对 `sum(n=0 to INF)x^n`，设 x 的范围为 `-1`～`1`、步长 `1`：

- 内部 `|x|<1`：绝对收敛，和函数 `F(x)=1/(1-x)`，精确余项 `x^N/(1-x)`。
- 边界 `x=1`：`S_N=N`，趋于正无穷；`x=-1`：偶数项部分和为 0，奇数项部分和为 1，上下极限为 1、0。
- 在内部求导得 `F'(x)=1/(1-x)^2`、`F''(x)=2/(1-x)^3`，相对参数条件数为 `|x/(1-x)|`。
- 紧区域上取 `|x|≤q<1`，统一尾界为 `q^N/(1-q)`；导数由可求和的 `j q^(j−1)` 支配。由一致收敛和逐项求导定理得到连续性、可微性及紧区间逐项积分。

对 `sum(n=1 to INF)x^n/n`，系数比值极限为 1，收敛半径为 1；边界独立代入：`x=-1` 条件收敛、`x=1` 发散。边界证明与内部幂级数定理分开记录。

对 `sum(n=0 to INF)x^n/(n+1)`，符号求和给闭式 `−ln(1−x)/x`，系统核对闭式的成立区域后，继续计算零点、正负区域、导数符号、驻点及值域。`x=0` 的左右极限均为 1，因此识别为可去奇点并记录连续补充值 1；`x=1` 的对数自变量有零点，绕行一周使闭式变化 `−2πi/x`，因此识别为对数分支点。实参数采样仍按原级数执行；复解析结构作为闭式的附加分析展示。对有理闭式，极点阶数由分子/分母零点重数之差计算，留数由洛朗负一次项系数计算。解析延拓记录闭式、奇异候选集合及与原收敛区间连接的解析分支。

值域分析分别保存上下确界与极值取到位置；导数正负区域表示参数方向的单调性，区别于部分和随项数变化的单调性。有理和函数还计算绝对敏感度和相对条件数的值域。具体方程求解遇到障碍时，该属性记录输入方程、所用运算和符号库返回的原因，其余已经完成的运算保留。

几何幂级数在完整 `(-1,1)` 上非一致收敛也有直接证书：对每个 N，`sup|x^N|=1`，一致收敛所需的通项一致趋零条件失败；同时 `x→1−` 时余项上确界为无穷。在 `|x|≤q<1` 的紧子区间，统一几何尾界趋零，且绝对值项上确界的和有限，得到正规收敛；连续和函数在紧子集上一致连续。

对 `sum(n=1 to INF)(-1)^n/n^p`，区域为 `p>1` 绝对收敛、`0<p≤1` 条件收敛、`p≤0` 发散。参数导数含 `log(n)`，k 阶导数含 `log(n)^k`；在 `p≥p_min>0` 的紧区域，幅值在 `n>exp(k/p_min)` 后递减趋零，由一致交错判别支持逐项求导。多参数几何底如 `(x+y)^n` 以 `|x+y|<1` 描述区域，并计算梯度和二阶混合偏导。

### 数值观察与算法误差

计算过程中同步累计正项和、负项绝对值和、正负零项数量、非零通项的变号次数及频率，并记录非空部分和的最小/最大值和首次出现的索引。频率的分母是非零项之间的相邻间隔数；空序列及至多一个非零项时频率记为 0。这些结果的范围是本次实际计算的索引和参数，单独列在“有限项结构与极值”。

设已计算通项的精确和为 T，实际累加结果为 Ŝ，A 为这些通项的绝对值和。累加前向误差是 `|Ŝ−T|`；分量相对后向误差是 `η=|Ŝ−T|/A`，它是允许每个非零输入项独立相对扰动时所需的最小最大扰动量。全零输入且结果为零时记为 0。纯有理数运算的两种累加误差均为 0；含近似函数的通项另通过提高 30 位精度重新计算，列出观测差异。

例如 `sum(n=0 to 2)[10^10*(1-n)+n*(2-n)]`，通项为 `10^10,1,-10^10`：条件数为 `20000000001`，正项和 `10000000001`，负项绝对值和 `10000000000`，变号 1 次。最大部分和在索引 1 取到，最小部分和在索引 2 取到；精确有理数算法的累加前向/后向误差均为 0。

### 双重求和与截断区域

公式填 `sum(n=1 to INF)sum(m=1 to INF)1/(2^n*3^m)`，n、m 分别填 `4`、`5`。定义域检查通过后，把通项分离为 `2^-n · 3^-m`，两个绝对值和分别为 1、1/2；由 Tonelli 得双重绝对值总和 1/2，再由 Fubini 得到两种迭代顺序都等于 1/2。

有限矩形和为 `(1−2^-N)(1−3^-M)/2`；精确矩形余项为 `1/2−(1−2^-N)(1−3^-M)/2`。矩形两轴独立趋于无穷及对角区域穷尽全部索引时，极限都为 1/2。每轴运行项数保持独立，执行计算仍遵循原嵌套顺序。

当前可构造此类换序证书的是固定下限、笛卡尔积索引区域、可分离成两个绝对收敛因子的双重级数。依赖外层索引的边界、更深嵌套、非可分离通项保存实际结构及正在检验的条件，分析面板展示停止步骤。原始分母在约分前检查，避免代数化简消除除零位置。

### 比值事实复用与通用渐近推导

证明阶段得到的通项比值在属性阶段复用。对非负幅值 `b_n`，优先用 `b_(n+1)−b_n=b_n(r(n)−1)` 检查单调性；这个检查有确定符号时直接形成证书，避免重复展开阶乘差分与导数。

若算得 `q=lim r(n)` 且 `0<q<1`，报告几何上界族 `O(ρ^N)`（`q<ρ<1`）、绝对值尾和渐近式 `b_(起点+N)/(1−q)`，以及每项渐近增加的十进位数 `−log10(q)`。对有理比值再计算 `α=lim n(r(n)/q−1)` 和二阶余量；两者有限时，由可和的对数余量证明 `b_n~C q^n n^α`，给出余项上界阶 `O(q^N N^α)`。例如 `sum(n=1 to INF)n^2/2^n` 得到 `q=1/2、α=2`，其多项式修正保留在报告中。

极小或极大的严格截断界保留精确符号表达式，同时计算其十进对数方便阅读。阶乘对数通过 `log(n!)=loggamma(n+1)` 计算，避免为了显示界而展开巨大整数；对数数值标为近似显示，严格证书仍是原不等式。

## 高精度计算与范围

采样坐标由 Python 整数十进制步进生成。整数、有限小数、普通分数的加减乘除、整数次幂及阶乘优先使用 Python 大整数和 `Fraction` 精确计算。非有理数函数使用独立 mpmath 任意精度上下文，至少 80 位十进制工作精度；根据公式数字和坐标的位数、量级自动增加保护位。不是先做双精度计算再补零。

求和按指定索引顺序生成通项；全部通项为有理数时保持精确分数累加，不再按分母位数切换为近似。遇到近似函数值时转为高精度 `fsum`。精确求和的分子、分母随项数增长，可能增加计算耗时；内部整数和有理数不受 binary64 范围限制。

诊断中的二进制有限精度通项采用精确二进制累加，最后统一转换为分数计算条件数与误差，避免每一项都反复展开和约分。相同阶乘调用位置复用最近一次整数结果：索引连续增加时按阶乘递推，索引回退或跨越较大时重新计算；该缓存局限于本次求值器。嵌套复核每个参数坐标完整执行一次表达式，各层根据相同外层索引匹配结果，避免内层再递归触发复核。上述优化保留全部配置项数、原通项求值与精确有理数语义。

例如 `0.1+0.2` 高精度输出为 `"0.3"`，`0.1+0.2-0.3` 和 `1/3+1/3+1/3-1` 精确为 `"0.0"`；`9223372036854775807-9223372036854775806` 为 `"1.0"`。有限小数结果和整数结果可完整输出，巨大整数不受 Python 默认整数转字符串位数限制。循环小数最终显示为有限位十进制近似；`sin`、π 及切换到 `fsum` 的求和也仍有近似误差。并非对任意病态消去或任意表达式都能保证全部输出位正确。符号证明和严格截断界不依赖这种近似。中间计算可以超出 64 位；64 位限制针对用户的整数范围/次数控件，不是 Python 数值大小上限。

参数允许大范围不代表计算可以瞬间完成。任意精度解决数字表示问题，不会把 5000×5000 次嵌套求值变为 5000 次；极大项数、极大小数位数或密集采样可能消耗很长时间和大量内存。求和循环定期检查 ComfyUI 中断；单个库函数内部运算的中断需等该次调用返回。全部采样结果与精确坐标驻留内存，节点不会静默截断用户指定的项数。

## 其他表达式与输出结构

运算支持 `+ - * × / // %`、乘方 `^` / `**`、后缀阶乘 `!` 和绝对值 `|表达式|`。阶乘只接受非负整数；连续 `!!` 不解释为双阶乘，需明确写函数嵌套。支持嵌套绝对值，例如 `|1-|3|| = 2`。

支持数字系数省略乘号：`2n`、`0.5x`、`2项数`、`2pi`、`2sin(x)`、`2(n+1)` 分别按显式乘法解析。多字符名称整体保留，`xy` 是一个变量，`x*y` 才是两个变量相乘；`n(n+1)`、两个括号之间等其他省略模式仍请写乘号。科学计数法保留原语义，`2e3` 是 2000。隐式乘法与 `*` 同优先级，`1/2n` 按 `(1/2)*n` 解析；分母为整个 `2n` 时写 `1/(2n)`。

常量 `pi`、`e`；函数 `sin/cos/tan`（弧度）、`asin/acos/atan/atan2`、`sqrt`、`abs`、`ln`、`log`、`log10`、`exp`、`floor`、`ceil`、`round`、`min`、`max`、`pow`、`factorial`。`log(x,10)` 指定底数，`min/max` 至少两个参数。`-2^2` 为 -4，`2^3^2` 为 512，`3!` 为 6。`round` 在高精度上下文中按最近偶数舍入。

默认 `sin(x)+y` 的 x、y 各 11 个采样点，形状 `[11,11]`，共 121 个结果。“值执行列表”下游每次收到一行 11 个数值；“高精度数列”下游一次收到整个 11×11 字符串数组。“采样坐标”包含原顺序和精确坐标，可对应每个元素。

## 帮助入口与更新

节点“信息”面板由 ComfyUI 从本包 `docs/LiuxinyuFunctionGrid.md` 加载，README 的节点链接指向同一文件；`i 分析` 展示本次公式的分析报告，不是节点使用说明。本节点的帮助响应要求浏览器重新校验，新版前端扩展加载时还会主动重新获取一次帮助，替换此前可能保存的旧 HTTP 响应。没有第二份独立维护的帮助副本。

已打开的“信息”面板由前端保留当前内容，单纯重启后端不会刷新该面板。更新代码后刷新当前页面，再重新打开节点帮助；新版输出表应包含“值执行列表 / 采样坐标 / 高精度数列”，并包含拉马努金公式示例。无需新建页面。

## 常见问题与验证

| 现象 | 检查方法 |
| --- | --- |
| sum 索引重复 | 为每个求和分配全局唯一名称，包括并列求和 |
| 自由变量意外出现 | 检查函数拼写、`INF` 大小写与通项边界；用方括号包住通项 |
| 证明收敛但误差还较大 | 收敛只描述无限极限；查看当前 N 的严格截断界 |
| 显示未知仍能计算 | 正常；未知代表尚未证明，有限项仍有明确计算含义 |
| 出现除零、负数阶乘或复数结果 | 修正通项定义域与起止值；这类错误不属于仅提示的收敛警告 |
| 大整数控件值不准确 | 用十进制字符串，不经 JavaScript Number 或上游 FLOAT 中转 |
| 普通结果 null 或 0，但高精度结果非零 | 普通双精度范围不足，读取高精度输出；检查已发出的警告 |

沿用包根自动注册和原动态控件保存方式，新增解析/分析辅助模块由 `__init__.py` 先加载。依赖现有运行环境的 SymPy、mpmath，无新增远程服务。修改后重启后端、刷新当前页面；原两个输出保持编号，新输出追加在末尾。信息控件参考同包 `text_preview.js` 的 `addDOMWidget` 和生命周期，样式与浮层逻辑分别位于 `function_grid_info.css` / `function_grid_info.js`。命令行测试见 `tests/test_function_series.py` 与 `tests/test_function_grid.cjs`，涵盖数学判别反例、数值精度、真实节点调用、动态控件与连线保留，以及浮层定位、边缘避让、键盘关闭、分组状态保留和帮助重新校验；卡片的页面视觉及实际点击交互由用户验收。
