# 函数生成精度数列

输入数学表达式，按每个变量的范围、间隔与小数位采样，输出多维数列和采样坐标。适合批量生成正弦曲线参数、网格搜索配置等数值序列。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `函数` | 数学表达式，变量按公式中从左到右的顺序对应下方动态端口 | STRING（默认 `sin(x) + y`，多行） | 是 |
| `{变量} 最小值` | 该变量的采样起点，一定包含 | FLOAT（默认 0.0） | 否 |
| `{变量} 最大值` | 恰好落在间隔的整数倍上才包含 | FLOAT（默认 1.0） | 否 |
| `{变量} 间隔` | 采样步长，必须大于 0，最大值不能小于最小值 | FLOAT（默认 0.1） | 否 |
| `{变量} 小数位数` | 0～15 的整数；最小值、最大值、间隔都不能超出该精度 | INT（默认 2） | 否 |

动态端口按公式中从左到右的变量顺序自动生成，端口随表达式中的变量增加，中英文变量名都可以。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `多维数列` | 完整嵌套采样数组，按最外层拆分为执行列表，下游逐项处理 | ARRAY |
| `采样坐标` | 包含 `order`（变量顺序）、`shape`（形状）、`axes`（各变量全部采样值）的字典，可还原每个值的位置；上游接执行列表时下游逐项处理 | DICT |

## 直接照做：生成 0～1 的正弦数列

1. “函数”填 `sin(x)`。
2. 变量 `x` 的四个端口自动出现：最小值 `0`、最大值 `1`、间隔 `0.25`、小数位数 `2`。
3. 运行后“多维数列”输出 `0、0.2474…、0.4794…、0.6816…、0.8415…` 共 5 项，普通下游逐项执行。

## 变量与采样端口

变量从表达式自动识别，按公式中从左到右的顺序对应编号端口，中英文变量名都可以。默认表达式 `sin(x) + y` 识别出 `x`、`y`，生成“x 最小值/最大值/间隔/小数位数”和“y 最小值/最大值/间隔/小数位数”两组端口。

例：范围 0～1、间隔 0.3、小数位 2，采样为 `0、0.3、0.6`，最大值 1 不落在 0.3 的整数倍上所以不包含。采样内部用十进制整数步进，避免浮点累积误差；间隔在当前数值范围内小于双精度分辨能力时、或范围超出双精度时会直接报错。

## 表达式支持

运算：`+ - * / // %` 和乘方 `^` 或 `**`；常量 `pi`、`e`。函数：`sin/cos/tan`（弧度）、`asin/acos/atan/atan2`、`sqrt`、`abs`、`ln`、`log`、`log10`、`exp`、`floor`、`ceil`、`round`、`min`、`max`、`pow`。`log(x, 10)` 可指定底数，`min/max` 至少两个参数。三角函数一律使用弧度，要按角度计算请先换算，例如 `sin(x*pi/180)`。

没有变量的常数公式（如 `pi/4`）返回单项数组。计算遇到无定义或非有限结果（如 `sqrt(-1)`、除零）时，报错会标出对应坐标，例如 `函数在 x=-1 处无法计算：…`。

## 输出结构

“多维数列”是完整嵌套 ARRAY，按最外层拆分并由下游节点逐项执行。默认参数下 `sin(x) + y` 的 x、y 各有 11 个采样点，共 121 个值、形状 `[11,11]`：下游每次收到一行 11 个值。“采样坐标”输出包含 `order`（变量顺序）、`shape`（形状）和 `axes`（各变量全部采样值），可用来还原每个值的位置。

所有采样点结果保存在内存中，点数太多会占用大量内存并拖慢运行，请控制范围与间隔。
