# 位运算符

通过下拉菜单选择按位与、按位或、异或、取反和移位。整数按二进制位运算；两个布尔值做 `& / | / ^` 得到布尔值；两个 Python 集合做 `& / | / ^` 得到交集、并集或对称差。

节点 ID：`LiuxinyuBitwiseOperator`；分类：`liuxinyu/逻辑运算`。适合处理标志位、整数掩码和已有集合值；它与会短路的[布尔运算符](LiuxinyuBooleanOperator.md)是两个不同节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `运算符`（`operation`） | 默认 `&`；可选 `&`、`\|`、`^`、`~`、`<<`、`>>`；在节点控件中固定选择 | COMBO | 是 |
| `A`（`a`） | 左操作数；整数或布尔，集合仅用于 `& / \| / ^` | ANY（INT / BOOLEAN / Python set） | 是 |
| `B`（`b`） | 二元运算的右操作数；移位时是非负整数位数，布尔按 0 或 1 处理；`~` 时隐藏 | ANY（INT / BOOLEAN / Python set） | 二元时是；`~` 时不使用 |

可变输入数量指随运算符切换一元／二元：`~` 只有 A，其余只有 A、B。需要连续对多个值运算时串联节点，例如 `(a & b) & c`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `结果` | 保留实际运算类型：整数、布尔或 Python 集合。单个完整值，不展开集合，也不转换为数组或文本 | ANY（INT / BOOLEAN / Python set） |

## 直接照做：检测一个整数标志位

1. 添加整数节点 A，值设为 `6`，其二进制为 `110`。
2. 添加整数节点 B，值设为 `2`，其二进制为 `010`。
3. 分别接本节点的 A、B，选择 `&`，输出为整数 `2`。
4. 若需要 bool，将这个结果接[比较运算符](LiuxinyuCompare.md)的 A，整数 `0` 接 B，选择 `!=`。
5. 比较结果为 `true`，可接官方 `If/Else Switch`。

将 A 改成 `4`（`100`）时，`4 & 2` 得到 `0`，比较结果为 `false`。

## 运算符与示例

| 运算符 | 输入和含义 | 输出示例 |
| --- | --- | --- |
| `&` | 整数按位与；两个集合取交集 | `6 & 3` → `2`；`{1,2} & {2,3}` → `{2}` |
| `\|` | 整数按位或；两个集合取并集 | `6 \| 3` → `7`；`{1,2} \| {2,3}` → `{1,2,3}` |
| `^` | 整数按位异或；两个集合取对称差 | `6 ^ 3` → `5`；`{1,2} ^ {2,3}` → `{1,3}` |
| `~` | 整数按位取反，相当于 `-A-1` | `~3` → `-4`；`~True` → `-2`；`~False` → `-1` |
| `<<` | A 向左移动 B 位 | `3 << 2` → `12` |
| `>>` | A 向右移动 B 位 | `12 >> 2` → `3`；`-8 >> 2` → `-2` |

## 返回类型与混合输入

| A 与 B | 运算 | 结果类型与规则 |
| --- | --- | --- |
| 两个整数 | `& / \| / ^` | INT |
| 两个布尔值 | `& / \| / ^` | BOOLEAN；例如 `True ^ True` → `False` |
| 整数与布尔混合 | `& / \| / ^` | INT；布尔按 0 / 1 参与，例如 `True & 2` → 整数 `0` |
| 两个 set | `& / \| / ^` | set，不承诺集合元素显示顺序 |
| 整数或布尔 | `~` | INT；布尔也明确返回整数 |
| 整数／布尔，及非负整数／布尔位数 | `<< / >>` | INT；例如 `True << True` → `2` |
| 集合与整数混合 | `& / \| / ^` | Python TypeError，不做隐式转换 |

整数不限固定的 8、32 或 64 位宽；没有自动截断或溢出回绕。右移负数保留符号；移动零位保留整数值。需要固定宽度时，可再接 `&` 与相应掩码组合。

## 集合不是数组或 JSON 文本

本节点接收已经存在的 Python `set`。示例中的 `{1,2}` 表示运行时集合，不表示可以直接把同样文字接入字符串口。JSON 没有 set 类型；普通数组 `[1,2]` 也不会自动变成集合。

若上游实际输出列表、字符串、浮点数或 `frozenset`，本节点会报告类型不支持。只做表中这些运算，不增加集合构建或隐式转换功能。

## 执行顺序与动态端口

二元位运算不短路，A、B 都是普通依赖。即使 `False & B` 的结果可预先猜到，也要准备 B；希望跳过分支应使用布尔运算符或官方切换节点。

选择 `~` 时删除 B 端口及连线；再选择二元运算时恢复空的 B 端口，需要重新连接。二元运算之间切换保留 A、B 连线。运算符和连线随工作流保存，重新加载时同步端口；更新前端后需要刷新页面。

完整集合作为一个值运算。执行列表则遵循 ComfyUI 的逐项调用和列表对齐规则，输出对应执行列表，不自动对整列累计。

## 常见问题与报错

| 现象 | 原因及处理 |
| --- | --- |
| `~True` 得到 -2 | 按要求返回整数按位取反；逻辑取反请使用布尔运算符的 `not` |
| `1.0` 被拒绝 | 浮点数不自动变整数；需要时先明确取整／转换再连接 |
| 移位报 negative shift count | B 不能是负数；按需要改为相反方向的运算 |
| 数组无法做集合运算 | 列表不等于 set；本节点不会自动去重或转换类型 |
| 缺少 B 无法提交 | 除 `~` 外都必须连接 B；空集合是合法的实际值，不等于缺少输入 |
| `& / \| / ^` 结果没有变成 true/false | 除两个布尔操作数外，本来就不保证 BOOLEAN；需要条件时再接比较运算 |
