# 执行列表收集为数组

把上游送来的完整执行列表一次性收集成一个数组。保留顺序和嵌套数组，不展开数组元素。适合把逐项流转的数据转成“一个完整值”，交给需要整体输入的节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `执行列表` | 上游送来的执行列表，整批收取 | ANY | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `完整数组` | 按顺序收齐全部项组成的一个完整数组；一个完整数组值，不会自动逐项执行 | ARRAY |

## 直接照做：统计执行列表的项数

1. 产生多项输出的节点（如“匹配路径”）接本节点的“执行列表”。
2. “完整数组”接“结构化数据变换（JSONata）”的 `data0`。
3. JSONata 表达式填 `$count(data0)`，运行后“结果”即执行列表的项数。

## 与普通下游的区别

执行列表默认让普通下游逐项执行；本节点是整体处理类节点，一次收齐全部项再组成一个数组。输出 ARRAY 是一个完整值，普通下游一次得到整个数组，不会自动逐项执行。数组、执行列表与图片批次的区别见 [DataLists](DataLists.md)。

## 保留与不展开

| 执行列表收到的项 | “完整数组”输出 |
| --- | --- |
| `1`、`2`、`3` | `[1,2,3]` |
| `[1,2]`、`[3]` | `[[1,2],[3]]`，嵌套数组原样保留 |
| 一个含 4 张图的图片批次 | `[<4图批次>]`，仍是 1 项，不拆成 4 项 |

典型组合：执行列表 → 收集为数组 → JSONata 的 `data0`，之后即可用 JSONata 表达式对整批数据查询、分组或变换。需要把多路执行列表先接成一路再收集时，先经“顺合任意执行列表”。
