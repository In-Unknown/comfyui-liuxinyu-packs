# 保存图像到绝对路径

将图像张量或已编码图像字节保存到指定绝对路径。同一“图片”口接受两种类型；单图直接写文件，张量批次写入同名子文件夹，字节输入按一个完整文件保存。覆盖关闭时自动追加编号避免重名。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `图片` | IMAGE张量或完整IMAGE_BYTES；支持执行列表，依次处理，每份字节是一个文件 | IMAGE,IMAGE_BYTES | 是 |
| `文件夹` | 绝对目录路径，不能为空；默认D盘AI输出目录，可用“选择文件夹”按钮 | STRING | 是 |
| `文件名` | 默认 `test.png`；仅纯文件名，包含支持的扩展名，不允许路径分隔符 | STRING | 是 |
| `覆盖已有文件` | 默认开启；关闭则为文件或批次目录追加 `_1`、`_2` 等可用后缀，检测同名文件和目录冲突 | BOOLEAN | 是 |

## 输出

本节点无数据输出口。执行后在界面显示PNG预览和保存路径；预览是临时文件，指定目录下才是永久结果。

## 怎么用

1. 将“图像张量编码为图像字节”的JPEG输出接本节点“图片”。
2. 文件夹填 `C:\images\encoded`，文件名填 `product.jpg`，关闭覆盖。
3. 首次运行得到 `product.jpg`；如有冲突文件或同名目录，选取 `product_1.jpg` 等可用名称。
4. 若输入是3张图的IMAGE批次，则写入 `product` 目录中的 `product-1.jpg`、`product-2.jpg`、`product-3.jpg`。序号位数按批次大小补零。

## 字节直写与转码

支持 `.png`、`.jpg/.jpeg`、`.webp`、`.bmp`、`.tif/.tiff`、`.gif`、`.avif`，AVIF需要当前Pillow支持。未知扩展名报错，不会将PNG写成其他后缀。

先完整验证字节，按实际内容判断格式。同格式直接写原字节，不从预览重编码；不同格式按[编码默认值](ImageBytes.md)转换。需要指定质量、交错或透明背景时，先接“图像字节转码”，再用匹配后缀保存。重新编码不保证保留元数据；同格式直写保留整个文件。

动画或多页字节同格式完整保存，预览仅首帧。跨格式时若有多帧则报错，请先用转码或解码节点显式逐帧输出，避免静默丢帧。

## 批次、列表与缓存

字节执行列表依次保存，一个字节项不等于一个张量批次。多个列表项使用同名且允许覆盖时，后项会覆盖前项；需要分别保存时关闭覆盖或为每项提供不同文件名。张量保留原有PNG/JPEG/WEBP/BMP保存方式；JPEG/WEBP质量95。

同一节点的图片内容和保存参数不变时复用预览缓存，不重复保存。删除临时预览后可重建预览，也不会重新写永久结果；若要重写永久文件，改变保存参数后执行。缓存按字节内容区分输入；重启后旧内存缓存不保留。永久结果不随预览缓存清理。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 路径错误 | 文件夹须为绝对路径，文件名只填名称，不能填完整路径 |
| 原JPEG另存PNG变大 | 这是跨格式转码；要保持JPEG体积请用jpg/jpeg后缀 |
| 透明度不符合预期 | 字节输入先用编码/转码节点控制Alpha，再同格式保存 |
| 多张字节只剩一个文件 | 关闭覆盖或提供不同文件名；列表不会自动变成批次目录 |

## 端口显示排序

选中节点，悬浮端口后按 `↑` / `↓` 可以调整显示顺序。例如将“图片”下移到“文件夹”之后，目录输入和“选择文件夹”按钮会作为一组保留在上方，图片端口排在按钮之后；文件名和覆盖选项仍对应原参数。具体操作和保存行为见[端口显示排序](PortOrder.md)。
