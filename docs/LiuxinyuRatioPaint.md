# 绘制蒙版绘制画笔于比例图像

在上游图像上用官方遮罩编辑器手绘画笔与蒙版：输出带彩色笔迹的图像和 MASK。底图更新但宽高比不变时，自动复用并等比缩放已画的笔迹与蒙版；批次中的所有图片共用同一组图层。搜索“画笔”“比例图像”“ratio paint”“mask editor”可找到本节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `输入图像` | 底图 IMAGE；批次为空时报错“输入图像批次不能为空。”，批次多张时共用同一组图层，预览第一张 | IMAGE | 是 |
| `image` | 隐藏的高级输入，记录图层文件位置，不需要手动填写 | STRING | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `图像` | 底图与彩色笔迹按笔迹透明度合成的结果，张数与输入批次一致。普通输出，不是执行列表：上游接执行列表时逐批各运行一次，每次输出该批次的一组结果 | IMAGE |
| `蒙版` | 绘制区域为 1（白），未绘制区域为 0（黑）；批次每张同一份。普通输出，不是执行列表 | MASK |

## 直接照做：给底图画一块标记并取蒙版

1. 底图接“输入图像”，点击节点上的“打开遮罩编辑器”按钮：节点会先运行所需上游、更新预览，然后自动打开官方遮罩编辑器。
2. 在编辑器里用画笔涂抹，保存并退出。
3. 再次运行工作流：保存后图层文件内容已变化，节点重新执行，“图像”输出合成笔迹的底图，“蒙版”输出绘制区域。
4. 之后替换上游底图（例如改成同比例的其他分辨率），再运行一次，笔迹会等比缩放覆盖到新底图；随时点“打开遮罩编辑器”继续绘制或擦除。

## 比例复用与图层文件

- 宽高比不变（旧宽×新高 = 新宽×旧高）：蒙版双线性、画笔 Lanczos 等比缩放到新尺寸，覆盖到最新底图上，可继续打开编辑器修改。
- 宽高比变化：改用空白图层重新绘制；之前的图层文件仍保留在磁盘上。
- 图层文件位于 ComfyUI input 目录的 `liuxinyu_ratio_paint/<随机子目录>/`，包含未绘制底图、可编辑画笔与蒙版等 clipspace 图层。它们是继续编辑所需素材，清理 input 或更换电脑会丢失，应随工作流备份。

## 常见问题

- 预览有笔迹、下游没收到：编辑器里保存后必须再次运行工作流输出结果；只点“打开遮罩编辑器”只会更新预览。
- 点按钮报“无法确定节点的执行位置”或“节点已静音或被绕过”：把节点放回主画布或独立子图，并启用节点后再试。
- 提示“保存的蒙版或画笔图层文件不存在，请恢复 input 中的编辑文件。”：`liuxinyu_ratio_paint` 下的图层文件被删或未随工作流迁移，从备份恢复后重新运行。
- 换底图后笔迹消失：宽高比变了，节点启用空白图层；把底图改回原比例，或在新图层上重画。
- MASK 想用于局部重绘：把“蒙版”输出直接接下游 inpaint 类节点，白色为绘制区域。
