# 图片信息节点

输入一张图片或图片批次，返回尺寸、颜色数量及明暗统计。无需填写文件路径，可直接接任意 IMAGE 输出。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `图片` | IMAGE 张量，支持单张、批次和执行列表 | IMAGE | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `宽度` | 图片像素宽度 | INT |
| `高度` | 图片像素高度 | INT |
| `色彩数` | 不同 RGB 颜色的数量；同一种颜色出现再多次仍只算一种，透明度不参与区分 | INT |
| `明度中位数` | 全部像素明暗值排序后的中间值，反映典型亮暗程度 | FLOAT |
| `明度最高值` | 整张图最亮像素的明度 | FLOAT |
| `明度最低值` | 整张图最暗像素的明度 | FLOAT |
| `R 明度最高值` | R 通道自身的最大 0～255 值，不乘明度权重 | INT |
| `R 明度最低值` | R 通道自身的最小 0～255 值，不乘明度权重 | INT |
| `G 明度最高值` | G 通道自身的最大 0～255 值，不乘明度权重 | INT |
| `G 明度最低值` | G 通道自身的最小 0～255 值，不乘明度权重 | INT |
| `B 明度最高值` | B 通道自身的最大 0～255 值，不乘明度权重 | INT |
| `B 明度最低值` | B 通道自身的最小 0～255 值，不乘明度权重 | INT |

全部输出口均为执行列表口径：批次及执行列表逐张统计，各输出按图片顺序给出数值列表，单张图片给出一项，下游逐项处理。

各通道的最大值可能来自不同像素，不一定组成图片里真实存在的一种颜色。

## 怎么用

图片 → 本节点；将想查看的数值输出接数值/对象显示节点，或接后续数学计算。

例如将“宽度”接多输入数学运算，乘 0.5，再接数字取整，就能为另一个节点计算半宽尺寸。本节点只统计，不会自动显示一份表格或修改图片。

## 明度怎样算

使用加权灰度：明度 = 0.299R + 0.587G + 0.114B，范围 0～255，不是三个通道的最大值，也不是 HSL 的亮度。

纯红 RGB(255,0,0) 的明度为 76.245，白色为 255，黑色为 0。全红的 100×50 图片会输出宽100、高50、色彩数1、三个明度统计都为76.245；R最大/最小都是255，G/B都是0。

中位数按全部像素计算，重复颜色按出现次数计入，像素数为偶数时取中间两项平均。例如同样多的黑白像素，中位数为127.5。

## 批次与精度

多张图分别统计，各输出都是对应顺序的执行列表。例如第一张宽790、第二张宽1000，则宽度输出两项790、1000，普通下游通常逐项执行，不会自动求整体最大值。

统计基于8位RGB：输入限幅0～1，乘255取最近整数，恰好半整数取偶数。因此极细微的浮点差异可能归为同一颜色。

灰度按R=G=B处理。RGBA忽略透明度，**全透明像素中存储的RGB也参加统计**，不会先与背景合成。长图按行分块精确统计，不抽样、不缩小；大图首次计算仍可能耗时。
