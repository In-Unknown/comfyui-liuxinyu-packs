# 批量任意为执行列表

把一个输入值整体重复指定次数，供下游逐项处理。适合准备 N 份相同任务输入，再交给分包子流完成一套处理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `任意` | 图片、文字、数字、数组、字典、Latent、模型等，保留原始类型 | ANY | 是 |
| `重复次数` | 大于或等于 0 的整数，默认 1 | INT | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `执行列表` | 输入值重复指定次数后的执行列表，下游逐项处理；上游已是执行列表时逐项重复，次数 2 时 A、B 变为 A、A、B、B | ANY |

输入字符串 `产品A`，重复次数 3，输出就是 `产品A、产品A、产品A` 三项。输入 5，重复 0 次，输出空执行列表。

## 配合分包子流

```text
一个任务输入 → 本节点（次数3）→ 分包执行子流回归 → 本包处理 → 回归分包子流条件
```

起点得到三包相同输入。要生成不同随机结果，仍需改变种子等实际参数；重复输入不会自动绕过 ComfyUI 缓存，也不会自动增加种子。

## 它不会拆开图片批次

输入是一个包含 4 张图片的 IMAGE 批次，重复 3 次后得到 3 项，每项仍含 4 张图片，并非逐张拆开的 12 个执行项。完整数组 `[1,2]` 重复两次后得到两项完整数组。

如果上游已经是执行列表 A、B，次数为 2，则结果为 **A、A、B、B**，不是 A、B、A、B。

本节点复用原值，不复制出 N 份模型或图像内存。下游若要修改张量，应使用会产生独立结果的处理节点，避免原地更改共享输入。
