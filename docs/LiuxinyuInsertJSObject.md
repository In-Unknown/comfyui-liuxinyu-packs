# 插入字段到字典或者js对象

按点号路径和数组下标找到挂载位置。目标为字典时插入新增字典的键值对；目标为数组时，把新增值作为一个元素追加到末尾。

节点 ID：`LiuxinyuInsertJSObject`。与[使用js点符号语句读取对象](LiuxinyuReadJSObjectPath.md)共用路径解析与查找逻辑，不执行 JavaScript 或 Python 表达式。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `对象或数组` | 原始完整数据，例如“字符串转为JS对象”的输出；不能直接输入原始 JSON 文本 | DICT / ARRAY | 是 |
| `挂载访问语句` | 点号和数组下标组成的路径；默认留空，表示挂载根位置 | STRING | 是（可留空） |
| `新增值` | 目标为字典时必须是字典；目标为数组时可为任意值 | ANY | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `完整对象或数组` | 插入后的完整数据，保持挂载位置之外的结构和顺序；一个完整值，不展开为执行列表 | ANY |

## 语句写法

| 语句 | 挂载位置 |
| --- | --- |
| 留空 | 根对象或根数组 |
| `product.analysis` | product 内的 analysis |
| `products[0]` | products 数组的第一个元素 |
| `[0][1]` | 根数组第一项中的第二项 |
| `["a.b"].items` | 键名包含点号时，用带引号的方括号访问 |

路径必须已经存在。下标从0开始；不支持负数、通配符、函数调用或自动创建中间层。`items.length` 在读取节点里是数字，因此不能作为插入的挂载位置。

## 字典：添加键值对

原始数据：`{"product":{"name":"健身凳"}}`；挂载访问语句：`product`；新增值：`{"topic":"产品稳定性","score":8}`。

结果：

```json
{"product":{"name":"健身凳","topic":"产品稳定性","score":8}}
```

一次可以添加多个键值对。值可以是对象、数组、数字、文本、布尔值、null 或其他可连接的原生值。已有同名键时报错，不覆盖也不递归合并；新增值为 `{}` 时不新增字段。

## 数组：追加任意值

原始数据：`{"items":[1]}`；挂载访问语句：`items`。

| 新增值 | 结果 |
| --- | --- |
| `"文本"` | `{"items":[1,"文本"]}` |
| `false` | `{"items":[1,false]}` |
| `null` | `{"items":[1,null]}` |
| `{"name":"A"}` | `{"items":[1,{"name":"A"}]}` |
| `[2,3]` | `{"items":[1,[2,3]]}` |

数组值也只追加为**一项**，不会展开。图片张量、Latent 等同样可作为原生值追加；这些值不一定能进一步转换为 JSON 文本。

## 输入保护与循环

节点不修改输入数据或新增值。只复制挂载路径上的字典/数组容器，未修改的分支与新增值保留引用；不会深拷贝图片、模型或张量。

如果上游传入多个执行项，ComfyUI 会分别执行此节点，各次结果不会自动累积。连续多次插入应把上一轮完整结果作为下一轮输入，可用“跳回点”和“条件回归”携带结果。

## 报错情况

- 根输入不是字典或数组，或路径不存在、下标越界、访问语句不合法。
- 挂载位置是字符串、数字、布尔值、null 等，不能容纳字段或新元素。
- 挂载位置为字典，但新增值不是字典。
- 新增字典中任意一个键与目标已有键冲突：整次插入报错，不执行部分插入。

本节点不负责分类、字段类型检查、引用集合校验或循环控制；这些由工作流按实际任务组织。
