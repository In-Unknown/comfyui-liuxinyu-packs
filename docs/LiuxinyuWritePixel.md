# 修改图片像素 RGB

在图片指定的一个像素位置写入颜色，返回修改后的完整图片。适合测试颜色处理、设置标记点或修正一个像素。

## 输入怎么填

| 输入 | 含义 |
| --- | --- |
| 图片 | 要修改的 IMAGE，支持图片批次 |
| X、Y | 左上角为 0、0，X 向右，Y 向下 |
| R、G、B | 0～255 的整数，例如红色为 255、0、0 |
| Z（可选图片索引） | **不接线：全部图片的同一位置都修改；接 0：只改第一张；接 1：只改第二张** |

Z 是可选连接口，不填写或不连接表示全部，不要把 0 当成“未指定”。

## 示例

把图片接入，设 X=10、Y=20、R=255、G=0、B=0，输出接预览。图片左起第 11 列、上起第 21 行变为红色。

输入是 3 张图片的批次时：Z 不接则三张都改；把整数 1 接到 Z 则只改第二张。输出仍保留原来的整个批次。

## 输出与限制

只改一个像素，不是画一个有半径的圆点；原图很大时需要放大查看。X/Y/Z 都不能越界，例如 790 像素宽的图，最大 X=789。

会复制结果，不修改上游原图；RGBA 保留透明度，所以透明位置改了 RGB 仍可能不可见。灰度输入扩展成 RGB。RGB 写入按数值除以 255 处理，保留图片张量的精度与设备。
