# 跳回点

与「条件回归」成对使用，反复处理**同一组数据**。条件为 true 时跳回再处理一轮；为 false 时离开循环，将本轮结果传给下游执行。例如反复调整图片直到尺寸达标，或带着计数器逐轮修改文本。

## 接线

1. 初始数据接跳回点「输入 1、输入 2……」。连接后自动增加下一对空端口，最多 100 对。
2. 「输出 1、输出 2……」接本轮处理节点，类型跟随同编号输入。
3. 「调回句柄」**直接**接一个「条件回归」的同名输入。
4. 条件回归会复制起点的数据端口和类型。将本轮更新后的数据接回同编号输入；不改变的数据也要从起点对应输出接回去。
5. 将“是否需要跳回再处理一轮”的布尔结果接条件回归。为 false 时，本轮结果从条件回归输出传给下游。

```text
初始数据 → 跳回点 → 本轮处理 → 条件回归 → 最终结果
             └── 调回句柄 ────────┘
                 是否跳回循环 ────┘
```

不用画反向连线，内部会把回归值送入下一轮。

## 执行顺序

先执行一轮，再检查条件：`true` 把本轮回归输入送回跳回点，再执行一轮循环，此时不执行回归之后的下游节点；`false` 不再跳回，结束本循环并把本轮结果交给下游正常执行，**不是停止整个工作流**。因此即使第一次条件为 false，循环内处理仍然执行一次。

例如初值 0，每轮加 1，并用“新值小于 3”作为跳回条件：得到 1 时为 true，跳回；得到 2 时为 true，再跳回；得到 3 时为 false，不再跳回，将 3 传给下游执行。条件应检查**处理后的值**；如果检查的值永远不变，循环可能无法结束。

## 数据与限制

- 每个端口每轮传一个完整值。数组、字典、IMAGE 图片批次均原样作为一个对象传递，不拆分。
- 空或多项 **ComfyUI 执行列表**不能直接作为循环初值或回归值；先合并成一个数组/批次，或用「分包执行子流回归」逐项进入本循环。空数组本身可作为一个完整值。
- 起点和回归的已连接数据端口必须一一对应，类型必须一致。INT 回归 FLOAT 时先显式转换；图片尺寸和批次数可以改变，但仍需保持 IMAGE 类型。
- 每次运行重新从初始输入开始；只返回最后一轮结果，不收集所有历史轮次。
- 可嵌套，但必须按 `A跳回 → B跳回 → B回归 → A回归` 闭合，不支持交叉或一个句柄对应多个回归。
- 循环分支必须汇回配对的条件回归。没有数据输出口的保存节点建议放在循环结束之后。
- 每轮仍遵循 ComfyUI 的普通节点缓存。需要每轮不同的随机内容时，应反馈变化的种子，而不是只返回相同输入。
- 已执行 10,000 轮仍要求跳回循环时会报错；可用 ComfyUI 的中断按钮停止当前任务，已保存文件不会撤销。

「分包执行子流回归」用于逐个处理不同对象，本节点用于反复更新同一组对象。两者可配合：外层逐图分包，内层对当前图片按条件多轮处理。
