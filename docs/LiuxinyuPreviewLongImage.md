# 预览超长图片

在节点内查看普通图片、超长图或多张图片。直接连接 IMAGE，无需路径；本节点用于查看，正式导出文件请接保存节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `图片` | 要预览的图像批次，须为含批次维度的 [批次, 高度, 宽度, 通道] 浮点张量。上游执行列表整批收取预览 | IMAGE | 是 |
| `超宽图查看方向` | 超宽图片的查看起点：从左向右（默认）或从右向左 | COMBO | 否 |
| `超高图查看方向` | 超高图片的查看起点：从上到下（默认）或从下到上 | COMBO | 否 |

## 输出

无输出口，仅用于画布上查看。

## 第一次使用

1. 将加载、拼接或切分结果接入“图片”，运行。
2. 多张图片先显示缩略图网格，点击某张进入单图。
3. 长图可以在图片视口中滚动查看；Esc 返回网格，左右方向键切换图片。
4. 拖动节点尺寸改变观看区域。查看细节时放大画布，等待短暂稳定后恢复当前尺度的清晰图。

## 什么时候会滚动

| 原图比例 | 显示方式 |
| --- | --- |
| 比16:9更宽 | 允许横向滚动，按视口高度缩放 |
| 比9:16更高、更窄 | 允许纵向滚动，按视口宽度缩放 |
| 位于两者之间，包含正好16:9和9:16 | 等比完整显示、居中 |

横向和纵向方向选项分别决定长图的查看方向。调整节点后若图片已经完整容纳，自动居中，表示还有隐藏内容的边缘阴影随之消失；阴影不是图片本身的边框。

## 多图怎么排列

图片数量不需要能被行数或列数整除。节点会根据当前容器选择排列，最后一行可以不满；条件合适时贴合外缘，改变容器比例时可能出现适当留白。

超长图缩略图可能只展示开头的一段，用于快速定位图片；点击进入单图才能查看完整内容。这不代表原图被裁掉。

## 为什么缩放时会模糊

画布缩放或移动期间使用较小的预览以减少卡顿；停稳后优先恢复可见区域中心附近图片的清晰度。单图也按当前需要加载清晰图块，初次加载可能先模糊后变清晰。

原始临时PNG按输入像素尺寸保存，没有以前的16384最长边压缩限制。屏幕上的预览档位不会改变后续节点的原始图像数据。

首次生成大图预览可能需要额外时间和临时磁盘空间；之后相同输入复用预览。新结果会替换旧的临时预览，因此旧执行历史图片可能失效，重要结果请另行保存。

## 常见问题

- 预期多张却只看到一张：先检查拼接节点是否已经把所有图合成一张。多目录各自拼接可用分包子流。
- 多张切片尺寸不同：可以直接输入执行列表，不要求统一为同尺寸批次。
- 更新后始终模糊或显示旧样式：刷新页面，必要时Ctrl+F5，并重新执行生成预览。若仍异常，记录图片数量、尺寸及复现操作。
- 缺少批次维度的自定义图片数据会报错；合法IMAGE应保持批次、高度、宽度、通道四个维度。
