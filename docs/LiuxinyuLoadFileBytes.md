# 从路径加载字节数据

读取本地任意文件的原始字节，不判断文件类型、不做文本或图片解码。适合先加载已有JPEG，再通过验证节点直接发送原文件；也可向其他支持BYTES的节点提供二进制文件。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `文件路径` | 默认空，运行时须为存在的文件绝对路径；可点击“选择文件”按钮，或接上游路径字符串 | STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `字节数据` | 完整文件的不可变bytes，不添加格式标记、不解码；每个路径输出一个值 | BYTES |

## 怎么用

1. 添加本节点，点击“选择文件”，选择 `C:\images\product.jpg`。
2. 将“字节数据”接“字节数据提取图像字节”，格式选JPEG。
3. 将提取节点“图像字节”接Harness图片口，或接保存节点并将文件名设为 `copy.jpg`。
4. 有效JPEG会保留原编码字节；若文件实际为PNG但命名为jpg，提取节点会根据内容识别并转换成JPEG。

也可以读取 `C:\data\sample.bin`；输出仅为BYTES，不保证能接图片提取节点。不会扫描文件夹；要读多个文件，可用“从目录中匹配路径或目录”的路径执行列表逐项传入。

## 文件选择和路径

选择按钮复用本包Windows原生文件选择器；对话框属于运行ComfyUI的电脑。其他环境手动填写服务器绝对路径。路径前后空白会去除，不要带命令行引号，不接受URL或文件夹。任意文件不显示图片即时预览。

## 内容变化与缓存

使用与现有加载节点相同的文件内容指纹，文件变化后重新读取；同名、同大小文件也会检测内容变化。每次读取完整文件到内存，较大文件会占用相应内存。工作流保存路径，不打包文件内容。空文件合法，输出 `b""`；随后图片提取会因没有图片内容而报错。

## 常见问题

相对路径、空路径、目录、文件不存在或无读取权限会报错。BYTES不能直接表示已验证的IMAGE_BYTES，需显式提取；文本内容想转成字符串时使用已有文本加载节点。类型与连接说明见[图像编码与字节数据](ImageBytes.md)。
