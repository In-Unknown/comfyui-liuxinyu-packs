# 字符串排列组合

把多组候选字符串做笛卡尔积，枚举所有组合；每条组合带着 t1、t2…的对应值，通过一个输出口交给[从模板生成文本](LiuxinyuTextFromTemplate.md)的“参数组合”。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `t1`～`t100` | 每组候选字符串：可为字符串执行列表，或一条 JSON 数组文本，例如 `["苹果", "香蕉", "梨子"]`；普通文本整条算一个候选，不按逗号或换行拆分；连接后自动出现下一组，端口随连接增加，最多 100 组 | STRING | 是（至少两组） |
| `同位去重` | 按候选下标排除组合，例如 `t1,t2` 排除两路下标相同的组合；多组规则用分号分隔，如 `t1,t2; t3,t4`；留空不去重。默认留空 | STRING | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `参数组合` | 组合条目的执行列表，每条含 t1、t2…的对应值，下游每次处理一条组合：t1 为红、蓝，t2 为 S、M 时输出红S、红M、蓝S、蓝M 四条 | TEMPLATE_PARAMETERS |

## 怎么用

1. 至少连接两组输入 t1、t2，连接后自动出现下一组，最多 100 组。
2. 每组可以是字符串执行列表，或一条 JSON 数组文本，例如 `["苹果", "香蕉", "梨子"]`；普通文本整条算一个候选，不按逗号或换行拆分。
3. 把“参数组合”接到“从模板生成文本”的“参数组合”，或先接[预览参数组合或字符串数组](LiuxinyuPreviewText.md)查看。

例如 t1 为 `红`、`蓝`，t2 为 `S`、`M`，得到四条组合：红S、红M、蓝S、蓝M。按输入顺序枚举，最后一组变化最快；各组长度可以不同，重复候选保留。少于两组时报错“请至少连接两组候选字符串。”；JSON 数组文本格式不正确时也会报错提示改写为 `["苹果", "香蕉"]` 这样的字符串数组。

## 同位去重

“同位去重”按候选下标排除组合，不比较文本内容：

| 设置 | 效果 |
| --- | --- |
| `t1,t2` | 排除两路下标相同的组合 |
| `t1,t2,t3` | 三路下标两两不同 |
| `t1,t2; t3,t4` | 两组规则，用分号分隔 |
| 留空 | 不去重 |

例如 t1、t2 都从同一批名单生成，填 `t1,t2` 会排除两个位置取到同一条的组合。比较的是下标：t1 的第 1 条与 t2 的第 1 条即使文字不同也会被排除。填写未连接的名称（如 t5）时报错“同位去重中的 t5 不是已连接的输入，请使用 t1,t2 等输入名称。”；只写一路的规则不生效。
