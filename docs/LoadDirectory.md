# 加载目录

加载目录节点通过系统原生文件夹选择对话框选取一个目录，输出该目录的完整路径、文件夹名和父目录路径。不做文件读取或校验，只做路径字符串拆解。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `文件夹路径` | 目录的绝对路径。可点击下方的「选择文件夹」按钮调用系统原生对话框选择，也可手动输入或连接上游字符串。 | `STRING` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `完整路径` | 输入的路径原样返回（已去除首尾空白）。 | `STRING` |
| `文件夹名` | 路径的最后一级目录名。 | `STRING` |
| `父目录` | 该目录的上一级路径。若输入是盘符根（如 `C:\`），父目录为空字符串。 | `STRING` |

## 使用示例

- 把 `D:\项目\素材` 拆成文件夹名 `素材` 和父目录 `D:\项目`。
- 与「在绝对路径中的相对路径」配合：先取基准目录，再拼接子路径。
- 与「从目录中匹配路径或目录」配合：直接把完整路径送入其目录输入。

## 注意事项

- 空输入或纯空白输入时，三个输出都为空字符串。
- 不检查目录是否真实存在，只做字符串处理。
