# 从路径加载图片

LoadImageFromPath 节点从指定的绝对路径加载图片文件，输出为 IMAGE 类型及图片的宽度和高度。节点上会显示已加载图片的预览。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `文件路径` | 要加载的图片文件的绝对路径。支持 .png / .jpg / .jpeg / .webp / .bmp 等格式。 | `STRING` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `图片` | 加载的图片，转换为 IMAGE 张量，可供下游节点处理。 | `IMAGE` |
| `宽度` | 图片的宽度（像素）。 | `INT` |
| `高度` | 图片的高度（像素）。 | `INT` |
