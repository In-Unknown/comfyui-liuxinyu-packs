# 长图切分节点

直接在节点“信息”页或下列页面查看分步用法：[自动切块](LiuxinyuSplitLook.md)、[边界检查](LiuxinyuSplitBoundaryPreview.md)、[最终切分](LiuxinyuSplitSegments.md)。以下为三者共同的数据格式和工作流程。

- **切分预览（自动切块）**：按“每块切分距离”切块，单位像素，可设置相邻块重叠像素。重叠必须小于每块切分距离；例如距离 1000、重叠 100，起点为 0、900、1800……，到达图像末端即停止。
- **切分检查图（边界放大）**：每个边界输出一张检查图；“边界放大范围”表示沿切分方向向边界两侧各取多少像素。
- **最终切分（按边界）**：输出不带标尺的原始像素切片，保留精度、通道和设备。

三个节点均提供“切分方向”：默认上下切分，也可左右切分。原有高度参数在左右切分时表示宽度，已有工作流默认仍按上下切分、无重叠执行。
上下切分的标尺在左侧，边界放大图在顶部；左右切分的标尺在底部，取底部标尺附近区域放大并放在左侧。数字始终保持横向，空间不足时省略部分刻度数字以防重叠。

三个节点均处理输入批次中的全部图片，按图片顺序、每张图内从上到下或从左到右的顺序输出。
输出是 ComfyUI 图片列表，每项仍为 `[1, H, W, C]` 张量；不同项可以有不同高度或宽度。
可以直接连接官方 `PreviewImage` 或本包的“预览超长图片”。

“切分检查图（边界放大）”和“最终切分（按边界）”使用相同的边界格式，支持两种写法：

- **数值数组（比例）**：`[0.1, 0.2]` 表示整张图 10%、20% 的位置。可以直接连接“多个数值组成数组”输出。每个数值必须大于 0 且小于 1，不用填写两端的 0、1。
- **对象数组（百分比）**：`[{"percent": 10}, {"percent": 20}]` 表示同样的位置。`name` 可选；`percent` 的数值必须大于 0 且小于 100。`{"percent": 0.1}` 表示 0.1%。

只接受以上两种数组，不混用数值和对象，不再接受 `boundaries` 包裹、`y_percent` 或 `x_percent`。
`percent` 按当前切分方向解释：上下模式按高度、左右模式按宽度。输入口类型为 `ARRAY`。

最终切分会将边界排序，自动补入图像两端；边界必须产生非空的切片。
`[0.1, 0.2]` 会生成两张边界检查图，或三段最终切图：0～10%、10～20%、20～100%。位置按当前输入图的高度或宽度计算，不是每个分块内部的比例。

## 从 LLM 文本输入切分位置

连接：**LLM 远程回复 → 字符串转为字面量 → 完整字面量（第二个输出） → 切分数组**。

推荐给 LLM 的输出要求：

> 只输出合法 JSON 数组，例如 [{"percent":10},{"percent":20}]。percent 是相对整张图片、沿切分方向的位置百分比，必须大于 0 且小于 100。按位置升序输出，不要重复，不要包含两端，不要添加说明文字。

“字符串转为字面量”增加 JSON 对象、对象数组和完整 Markdown JSON 代码块的解析。
原第一个“字面量”输出仍将数组拆成下游逐项执行的列表；新增第二个“完整字面量”输出保留完整数组或对象。
因此切分时必须连接第二个输出。类型、数据和原有节点 ID 保留，旧连线继续逐项执行。
对象可用于其他读取/预览节点，切分节点仍只接受上述两种数组；格式不成立时延续原行为，回退为字符串。
原“字符串转为JS对象”节点也仍可用于解析纯 JSON。
