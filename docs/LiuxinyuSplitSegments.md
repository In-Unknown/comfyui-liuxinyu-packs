# 最终切分（按边界）

按整张图的指定位置裁切，输出不带标尺、标签和额外边框的原始像素切片。用于最终保存、下游图像处理或重新拼接。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `图片` | 要裁切的原图，支持批次及执行列表 | IMAGE | 是 |
| `切分数组` | 切点数组，仅支持数值比例 `[0.1, 0.2]` 或对象百分比 `[{"percent": 10}]`，位置按整张图及当前切分方向计算，自动补齐两端，不能为空 | ARRAY | 是 |
| `切分方向` | 上下切分：从顶部向底部；左右切分：从左向右。默认“上下切分” | COMBO | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `切分结果` | 原始像素切片的 IMAGE 执行列表，每项是单张图片，下游逐项执行；多张原图按输入顺序处理，每张内部按顶部到底部或左到右输出 | IMAGE |

## 最快的用法

1. 把原图接“图片”。
2. 两个浮点数 0.1、0.2 接“多个数值组成数组”，数组输出接“切分数组”。
3. 选择“上下切分”，输出接“预览超长图片”或保存节点。
4. 运行后得到三段：0～10%、10～20%、20～100%。

它们的相对长度是 **10%、10%、80%**。输入数组表示刀落在哪里，不表示每段各有多长。

## 切点格式

- 数值比例：`[0.1,0.2]`，每项严格大于 0 且小于 1。
- 对象百分比：`[{"percent":10},{"percent":20}]`，每个 percent 严格大于 0 且小于 100，name 可选。

两种写法效果相同。不要混合形式，不接受 y_percent/x_percent，不用外层 boundaries 包裹。自动补齐整图起点和终点，所以不要手动写 0、1 或 0%、100%。数组不能为空。

文本或 LLM 回复需先经过“字符串转为字面量”，连接第二个“完整字面量”输出。第一个输出会把数组拆开，不适合这里。

## 尺寸例子

高 1000、宽 790 的图，沿上下方向用 [0.1,0.2] 切分，得到 790×100、790×100、790×800 三张图。

同一数组用于宽 1000 的图，选左右切分，则按 X=100、200 分割。percent 不区分 X/Y，由方向决定。

位置先排序，再按当前原图尺度换算到最近整数像素。不是上一个切点之后再移动百分之几，也不是某个预览块内部的百分比。

## 输出及常见问题

复制原图像素切片，保留通道、透明度、数值精度与设备；不加标尺，不重新缩放，不提供重叠选项。

- 切点重复或距离太近：整数化后可能形成空段，节点会报错。
- 切点靠近两端：可能被取整到 0 或完整长度，也会形成空段，应调整位置。
- 切完结果带标尺：图片输入接了自动切块的预览块，应改接原图。
- 多张图的切片要各自合并：将切分和合并放进“分包执行子流回归”的子流范围内。
