# Shift 准直移动

拖动节点或组时按住 Shift，以本次拖动起点为基准锁定水平或垂直方向，便于把多个画布对象沿同一方向挪动。无需添加节点，前端扩展加载后生效。

## 操作步骤

1. 选中一个节点、多个节点、组，或同时选中节点和组。
2. 按住鼠标拖动。比如已经从起点向右移动120、向下移动35。
3. 此时按住 Shift，横向位移更大，因此立即清除新增的35纵向位移；此后对象保持起点的Y坐标，只允许左右移动。
4. 保持 Shift 并松开鼠标完成移动；松开Shift或结束拖动后辅助线消失。使用原生撤销即可撤销整次移动。

也可以先按住 Shift 再拖动：原生拖动开始后的首次非零移动决定方向。点击但未实际拖动，不会修改位置或绘制辅助线。

## 方向判断与切换

| 操作或情况 | 行为 |
| --- | --- |
| 水平位移绝对值大于垂直位移 | 锁定水平方向，恢复每个对象的起始Y |
| 垂直位移绝对值大于水平位移 | 锁定垂直方向，恢复每个对象的起始X |
| 两者相等，且位移非零 | 固定选择水平方向 |
| Shift持续按住 | 方向不因鼠标后来偏向另一边而切换；可沿同一轴反向拖过起点 |
| 拖动中松开Shift | 立即补回锁轴时被过滤的位移，回到鼠标对应的自由拖动位置；无需再移动一下鼠标，后续按原生方式移动 |
| 同次拖动再次按Shift | 根据当前位置相对本次最初起点重新判断，不另设起点 |

浅蓝虚线连接鼠标最初抓取位置与对象当前对应位置，两端以小圆圈标记。它显示实际受约束的位移，不跟随鼠标在被锁定轴上的偏离；只作显示，不会保存到工作流。

## 多选、组与其他可移动对象

沿用原生选择和组成员遍历：单节点、多选节点、组、嵌套组、组内节点，以及进入同一原生拖动路径的转接点和子图输入输出边界都使用同一约束。重叠选择的对象不会因同时属于组和选择集合而重复移动。每个对象恢复自己的起始坐标，因此保持原有相对布局，不会把整批节点挤在同一条线上。

固定的对象仍遵循原生固定规则。Ctrl/Command对组内容的原生移动规则保持。画布平移、框选、连线、控件调值和调整节点/组尺寸不属于本功能；这些操作原有的Shift含义不变。先按Shift点击转接点等可能被原生解释为连线，此时不会强行改为移动；要准直移动转接点，先开始拖动再按Shift。

## 网格、撤销和生效范围

锁轴期间，松手时的Shift网格吸附及“始终吸附网格”不会再次挪动这批对象，避免破坏准直或相对间距。非锁轴拖动仍使用原生吸附。保持原生拖动事务，按住Shift、松开Shift不会额外创建撤销步骤。

辅助线随画布缩放保持屏幕线宽；原生边缘自动平移产生的对象移动也受锁轴约束。切换图、取消指针或拖动结束清理本次状态；窗口失焦解除轴锁，防止Shift抬起事件丢失后继续锁住。

实现适配当前经典LiteGraph画布的原生拖动入口。其他前端模式或第三方完全替换移动逻辑时，需要另行适配，不能仅凭有选中框保证支持。更新JS后刷新页面，无需重启后端。

## 开发与验证

实现位于 `axis_drag.js`，沿用包内扩展注册和保留原回调的方式。命令行行为测试覆盖两种轴、拖中锁定、预先Shift、多选嵌套组、重复成员、固定对象、释放与重按、自动平移、缩放、吸附优先级、撤销事务和取消清理。默认不执行浏览器自动化；实际鼠标手感和辅助线显示由用户刷新后验收。

测试使用当前安装的原生CanvasPointer类及原生拖动生命周期，包含 `finally` 属性赋值会立即结束旧操作的行为。本扩展不重新包装该属性，避免普通拖动刚开始就被结束。14组检查包含无Shift正常移动、Shift抬起立即追上鼠标、多组成员与自动平移的完整位移恢复；更新后需要刷新页面卸载旧脚本。
