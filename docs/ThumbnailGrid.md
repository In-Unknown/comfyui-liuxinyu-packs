# 缩略图排列规则

`SaveSelectedFromBatch` 和 `LiuxinyuPreviewLongImage` 共用 `thumbnail_grid.js`，
调用当前 ComfyUI 前端公开的 `window.comfyAPI.imagePreview.calculateImageGrid`。
规则已与本机前端 1.53.6 的源代码及用户提供的截图、视频抽帧核对。

## 官方规则

- 逐一尝试从 1 到图片总数的列数，行数向上取整，允许最后一行不满。
- 每个候选布局按宽、高限制等比缩小图片，不超过原始像素尺寸；选择图片总显示面积最大的布局，相同面积时保留先找到的列数。
- 整组水平居中、顶部对齐，末行从左开始。不为填满空白而拉伸或裁切普通图片。
- 同比例图片无缝排列；混合比例图片使用正方形格子，每张图在格内等比居中。自定义节点不添加官方混合比例模式的灰框和 2px 内边距。

固定高度逐渐拉宽时，某个列数的布局会先受宽度限制（贴左右边缘），再受高度限制（两侧留白）；
新的列数获得更大的显示面积后切换排列，又可能贴边。这就是参考视频里的周期性变化。
偶数列时，交替黑白方图的同色块上下相邻，会看起来像竖条，图片并没有被拉长。

## 自定义节点的实现

- DOM 控件使用 `margin: 0`，取消默认的两侧 10px 内缩。满足宽度限制条件时，图像可以直接贴节点外缘。
- 从实际预览容器读取小数尺寸，不再用节点尺寸减固定值，也不对每格单独取整。
- CSS Grid 使用共享的小数边界；同比例缩略图铺满格子，避免累计舍入产生边缘空隙。
- `ResizeObserver` 在绘制前同步更新布局，不再延迟一帧排版。
- 零内边距会覆盖原生缩放角，因此两个底角有透明命中区，转交原生画布处理拖动；控件命中检测也让出缩放角。图片仍然显示到边缘。
- 长图缩略图保留原来的 9:16 / 16:9 截取范围和方向阴影；单图放大另按滚动规则处理。

## 本轮检查

三个 JS 文件通过 `node --check`，改动通过 `git diff --check`。
已检查官方计算接口、控件 margin 支持、非整数尺寸、混合比例和图片加载完成后的重排路径。
按用户要求，本轮不展开完整浏览器交互回归，连续拖动、边缘观感和选择操作交由用户实际验收。
