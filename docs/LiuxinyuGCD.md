# 最大公因数

求两个或更多整数共同的最大正因数，输出非负 INT。适合约分宽高比、找共同网格步长。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `数值`（number0、number1……） | 参与计算的整数，允许负数，符号不影响结果；端口随连接增加，最多 100 个，至少连接两个 | FLOAT / INT | 是（至少 2 个） |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `最大公因数` | 所有输入的最大公因数，非负；上游接执行列表时逐项各算一次 | INT |

## 例子：把 1920×1080 化成 16:9

1. 把整数 1920、1080 接两个数值输入。
2. 输出最大公因数 120。
3. 分别用 1920÷120、1080÷120，得到 16、9。

继续连接更多输入时会自动增加插口，最多 100 个，至少两个。

允许负整数，符号不影响结果，例如 -12、18 得到 6。12.0 可以，12.5 会报错。GCD(0,6)=6，GCD(0,0)=0；如果后面要用结果做除数，要考虑全零输入的情况。
