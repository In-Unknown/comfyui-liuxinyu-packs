# 排序字符串数组

对字符串数组做逐段自然排序；不修改文本内容，不去重。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `字符串数组` | 要排序的字符串数组，整批收取 | STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `字符串数组` | 排序后的字符串数组，STRING 执行列表，下游逐项处理 | STRING |

## 排序规则

每条字符串拆成“连续数字”和“单个其他字符”的片段，逐段比较。片段类别从先到后为：

1. 符号（按字符编码）
2. 数字（连续数字整体按数值比较）
3. 大写字母 A～Z
4. 小写字母 a～z
5. 其他文字（不区分大小写比较）
6. 中文（Windows 简体中文拼音，逐字比较）

## 示例

| 输入 | 输出 |
| --- | --- |
| `A10`、`A9`、`A2` | `A2`、`A9`、`A10`，数字按数值比 |
| `苹果`、`香蕉`、`梨子` | `梨子`、`苹果`、`香蕉`，按拼音 l、p、x |
| `!a`、`1a`、`Aa` | `!a`、`1a`、`Aa`，符号最先，大写先于小写 |

空字符串排在最前。数字段比较前去掉前导零，`007` 与 `7` 的排序键相同，两者保持原有相对顺序。中文按字比较拼音，多音字不按词句含义推断读音；中文拼音排序依赖 Windows 的简体中文本地数据。

## 常见问题

- 排序键相同的条目保留原顺序（稳定排序）。
- 排序前后都可用[预览参数组合或字符串数组](LiuxinyuPreviewText.md)核对。
