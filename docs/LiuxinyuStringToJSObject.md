# 字符串转为JS对象

把标准 JSON 文本解析成对象或数组，保留嵌套结构、数字、布尔值和 null，供读取、预览和转换类节点使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `字符串` | 标准 JSON 文本，对象键和字符串必须用英文双引号；只解析 JSON，不执行 JavaScript 表达式。默认 `{}`，支持多行 | STRING | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `JS对象` | 解析出的对象或数组；一个完整值，数组也整体传递，不会自动拆成下游逐项执行的列表；后端用字典和列表承载数据 | ANY |

## 怎么用

| 输入文本 | 输出 |
| --- | --- |
| `{"name":"苹果","tags":["红","甜"]}` | 含嵌套数组的对象 |
| `[1,2,3]` | 数组 |
| `{"ok":true,"note":null}` | 布尔值与 null 保留类型 |

顶层必须是对象或数组；填 `苹果`、`123` 这类标量会报错，提示输入 JSON 对象或数组，例如 `{"name":"苹果"}` 或 `[1,2,3]`。出现 `NaN`、`Infinity` 等非标准值时报错提示改用标准 JSON 数值或 null。格式错误时报错标明行号、列号和原因，例如多余的逗号、缺少引号。
