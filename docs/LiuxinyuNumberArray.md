# 多个数值组成数组

把几个分散的数字组成一个完整数组，适合向切分节点提供全部切点，或把一组参数整体传给下游。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `数值 1` | 连接整数或浮点数，连接末尾输入后自动增加下一个输入口（数值 2、数值 3……），无固定数量上限；按输入口从上到下的编号顺序组装，未连接的输入不占数组位置 | INT / FLOAT | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `数值数组` | 按端口顺序组成的数组：全部为整数时输出整数数组，含浮点数时全部转为浮点数；没有输入时输出空数组。一个完整数组值，不会自动逐项执行 | ARRAY |

## 直接照做：在长图的 10%、20% 处切两刀

1. 添加两个浮点数节点，分别设为 `0.1`、`0.2`。
2. 第一个接“数值1”，连接后会出现下一个输入；第二个接“数值2”。
3. 把“数值数组”输出接到“最终切分（按边界）”的“切分数组”。
4. 将原图接到最终切分，选择上下或左右切分后运行。

本节点输出 `[0.1,0.2]`。两刀分别位于整张图的 10%、20%，最终得到 0～10%、10～20%、20～100% 三段，而不是长度为 10%、20%、70% 的三段。

## 数据类型与顺序

| 输入 | 输出 |
| --- | --- |
| 整数 2、3 | `[2,3]`，整数数组 |
| 浮点数 2.0、3.5 | `[2.0,3.5]`，浮点数组 |
| 整数 2、浮点数 3.5 | `[2.0,3.5]`，统一为浮点数组 |

## 常见问题

- 不接收文本 `"0.1"`、字典或布尔值。LLM 返回的是文本时，使用“字符串转为字面量”，接它的“完整字面量”输出。
- 接切分节点时必须是 0～1 之间的比例，不能填 10、20。本节点只是组数组，是否为有效切点由切分节点检查。
- 本节点不是用来收集执行列表的。某个数值输入若来自执行列表，ComfyUI 会按它的列表规则多次执行组数组，而不是自动将所有项收成同一个数组。
