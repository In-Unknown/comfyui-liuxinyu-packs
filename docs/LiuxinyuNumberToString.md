# 数字转换为字符串

把整数、浮点数等数字转成文本，直接使用 Python 的字符串形式，不额外做四舍五入或补零。适合把数值拼进提示词、文件名或 JSON 文本。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `数字` | 连接整数、浮点数或其他数字输出（含 Decimal），例如 `123` → `123`、`3.14` → `3.14` | ANY | 是 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `字符串` | 数字的字符串形式，不额外四舍五入或补零；上游接执行列表时逐项各转一次 | STRING |

`3.0` → `3.0`（保留 `.0`）；`1/3` 这类计算结果 → `0.3333333333333333`，不会截成 `0.33`。想要固定小数位数或补零，请改用其他文本格式化节点。

布尔值会被明确拒绝，接错时节点会提示实际收到的类型和值；需要把任意内容原样转文本时，改用“任意转换为字符串”。
