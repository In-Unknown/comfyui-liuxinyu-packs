# 数字转换为字符串

把整数、浮点数等数字转成文本，直接使用 Python 的字符串形式，不额外做四舍五入或补零。适合把数值拼进提示词、文件名或 JSON 文本。

整数 `123` → `123`；浮点数 `3.14` → `3.14`；`3.0` → `3.0`（保留 `.0`）；`1/3` 这类计算结果 → `0.3333333333333333`，不会截成 `0.33`。想要固定小数位数或补零，请改用其他文本格式化节点。

输入只接收整数、浮点数及其他数字（含 Decimal），不接收布尔值、字符串或图片：布尔值会被明确拒绝，接错时节点会提示实际收到的类型和值。需要把任意内容原样转文本时，改用“任意转换为字符串”。
