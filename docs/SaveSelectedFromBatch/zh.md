# 从批次中选择保存图片

SaveSelectedFromBatch 节点将输入的整批图片先暂存到 ComfyUI 临时目录用于在节点上预览，再根据「多选序列」自动保存到目标文件夹，或等待你在节点预览中勾选后手动点击「保存所选」按钮保存。适合在批次生成后从多张图片中挑选保存。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `图片` | 要保存的输入图像批次。整批图片会先暂存到 ComfyUI 临时目录用于在节点上预览，然后根据「多选序列」自动保存到目标文件夹，或等待你在节点上勾选后手动保存。 | `IMAGE` |
| `文件夹` | 保存文件的绝对路径。仅预览时可留空；自动保存或点击「保存所选」前，需填写绝对路径，或点击「选择文件夹」按钮选择。 | `STRING` |
| `文件名` | 保存时使用的文件名前缀，需包含扩展名（支持 .png / .jpg / .jpeg / .webp / .bmp）。仅接受纯文件名，不能包含路径分隔符。保存时按 `{stem}_{k}.{ext}`（k 从 1 递增）的顺序写入目标文件夹；多次保存会追加编号，不会覆盖已有文件。 | `STRING` |
| `多选序列` | 可选。指定要自动保存的批次下标，0-based，以英文逗号分隔，例如 `1,3,6,0`。为空时进入手动选择模式，需在节点预览中勾选图片后点击「保存所选」按钮。非空时按这些下标自动保存到目标文件夹，但仍可继续手动勾选并触发额外保存。 | `STRING` |

## 先预览，再保存

最小示例：图片接入，文件夹和多选序列留空，运行后查看缩略图；选择一个保存目录，文件名填 `detail.png`，点击需要的图片，再点“保存所选”。第一次保存通常得到 `detail_1.png` 等文件，再保存会继续编号。

自动保存示例：同一个输入批次有5张图片，多选序列填 `0,2,4`，表示第1、3、5张；运行前先填写有效保存目录。索引从0开始，最后一张的索引是图片数量减1。

自动模式的索引按每个输入批次分别解释，不是整个执行列表的全局索引。例如切分输出的每项只有1张图，给多选序列填 `2` 会越界；希望从所有切片中挑第3张时，保持序列为空，先运行，再在完整预览中手动选择。

将图片接入本节点，保持「多选序列」为空即可运行预览，此时不用填写保存目录。
预览完成后选择文件夹、勾选图片，再点击「保存所选」，无需重新运行上游节点。
手动选择支持切分节点输出的不同尺寸图片列表，按预览中的全局下标选择。
点击缩略图后以绿色高亮及边框标记选中，不再显示对勾。
自动保存的「多选序列」仍按每次输入批次内的下标解释。
运行后，预览会将本次多选序列实际选中的图片显示为绿色高亮，包含连接上游传入的序列；不会清空或改写原来的序列。复用缓存预览时也会恢复本次选中状态。

空目录在实际保存时会提示「请先选择保存文件夹」，不会再先转换成 `.` 而误报相对路径。

完全相同的图片和参数会复用上次预览，不重复自动追加保存文件；如果就是想再保存一份，可再次点击“保存所选”。文件名只能是带扩展名的纯文件名，目录单独填写。本节点没有图片数据输出，分包工作流中通常放在回归之后。
缺少批次维度的输入会在写文件前被拒绝，避免把图片的每一行当成一张图片。

缩略图与长图预览共用官方列数计算，支持质数数量、末行不足和条件合适时贴节点外缘。
具体排列规则见 [缩略图排列规则](/extensions/comfyui-liuxinyu-packs/docs/ThumbnailGrid.md)。
