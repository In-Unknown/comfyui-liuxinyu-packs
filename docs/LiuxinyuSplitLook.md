# 切分预览（自动切块）

把长图按固定像素距离切成较容易查看的预览块，并添加整张图的位置标尺。用于观察内容、确定正式切点，也可把预览块交给视觉模型判断边界。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `图片` | 要查看的原图，通常是一张拼接好的长图，支持批次及执行列表 | IMAGE | 是 |
| `每块切分距离` | 每块在切分方向上的像素数；上下时是高度，左右时是宽度。默认 2000，范围 100～20000 | INT | 是 |
| `切分重叠像素` | 下一块从上一块末端往回退多少像素；0 不重叠，必须小于切分距离。默认 0，范围 0～19999 | INT | 否 |
| `切分方向` | 上下切分：从顶部向底部；左右切分：从左向右。默认“上下切分” | COMBO | 否 |

可以先试距离 2000、重叠 100，再根据文字大小和查看习惯调整。重叠便于看到落在块边缘的内容。

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `预览块` | 带标尺的预览块执行列表，每项一块，下游逐项执行；不同块允许不同尺寸，每项保留单张图片的批次维度 | IMAGE |

## 怎么接

加载或拼接好的原图 → 本节点 → 预览超长图片。

先运行观察预览上的百分比，确定切点后，把**同一张原图**接“切分检查图（边界放大）”或“最终切分（按边界）”。正式裁切不要改接本节点的预览块，否则会包含标尺，百分比基准也变成分块本身。

## 一个具体例子

图片高 2500，距离 1000，重叠 100，上下切分得到：

| 块 | 在原图中的范围 | 内容高度 |
| --- | --- | --- |
| 1 | 0～1000 | 1000 |
| 2 | 900～1900 | 1000 |
| 3 | 1800～2500 | 700 |

范围按起点包含、终点不包含理解。到图像末端就停止，最后一块可能短一些。重叠设为 0 时起点变为 0、1000、2000。

## 标尺与输出

上下切分时标尺在左侧，左右切分时在底部，数字保持横向；标尺表示相对于整张输入图的位置。标尺占用额外区域，预览块的宽高不等于纯内容切片的宽高。

输入多张图时，先输出第一张的所有块，再第二张的所有块。

如果后面要把每张原图的切片各自汇总，请使用分包子流，避免全部切片混合。带标尺、带重叠的预览块直接拼接不会还原原图；无标尺的生产切片使用“最终切分（按边界）”。
