# 按节点 ID 或名称查找

在 ComfyUI 页面按 **Ctrl+F**，输入节点 ID 或名称，即可在当前打开的整个工作流中定位节点。搜索包含主图和所有通过宿主节点引用的嵌套子图；定位子图内部节点时，沿原生导航逐层进入，然后选中节点、调整到清晰可读的缩放并居中。返回父图时，聚焦对应的子图宿主节点。

适合根据报错、检查报告或交流中提到的编号快速寻找节点，不需要先知道它在哪一层。无需添加节点，也无需先保存工作流。

## 入口与操作

1. 刷新加载本扩展后，在 ComfyUI 页面按 **Ctrl+F**。macOS 也支持 **Command+F**。
2. 右上角出现“查找节点”面板，输入例如 `729` 或 `渠道汇报`。输入时显示匹配结果及所在子图路径。
3. 仅有一个结果时按 **Enter** 或点击“定位”，也可直接点击结果。
4. 多个结果时必须选择其中一项。Enter 只把焦点移到第一项，不直接跳转；点击结果，或用 Tab 选择后再按 Enter 确认。名称和 ID 搜索都遵循此规则。
5. 定位成功后面板关闭，目标节点被选中、缩放并居中。使用原生子图导航返回父图时，对应子图宿主也会被选中并聚焦。

面板没有遮罩，不锁定画布。按 **Esc** 或点右上角 **×** 关闭；再次 Ctrl+F 会聚焦现有输入框，不重复创建面板。

面板仅保留容器外描边，输入框、定位按钮、结果按钮和关闭按钮均无描边。定位按钮默认透明，与面板同底色；仅悬浮时显示原来的按钮底色，按住时以 120 毫秒动画缩至 94% 并保持，松开时以相同时长恢复原大小。结果按钮悬浮或键盘聚焦通过底色变化提示，输入框聚焦和输入时保持原底色。关闭按钮保持透明底色，悬浮和聚焦都不高亮，视觉上只显示“×”，点击范围仍保留完整按钮区域。未输入时不显示额外说明文字，输入后才显示匹配状态。

## 输入

本功能是前端搜索，没有节点输入端口。

| 参数 | 描述 | 数据类型 | 必需 |
| --- | --- | --- | --- |
| `节点 ID、名称或完整路径` | 数字编号精确匹配，如 `729`、`#729`；完整路径如 `771:745:729`。其他文字按名称部分匹配，例如 `渠道汇报`，忽略英文大小写，搜索当前标题、原始显示名称、子图名称和节点类型。前后空白会去掉 | STRING | 是 |
| `当前工作流` | 从当前已加载的主图及其嵌套子图读取节点，包含尚未保存的编辑；不搜索其他标签页、磁盘文件或未实例化的子图定义 | 画布图对象 | 自动读取 |

## 输出

没有节点输出端口，不产生执行数据。

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `查找结果` | 节点 ID、标题、所在子图层级以及完整 ID 路径。重复 ID 分别列出不同实例路径 | 前端结果列表 |
| `定位视图` | 沿原生子图导航进入目标所在图，选中节点并调整缩放、居中；返回上层时聚焦该层的宿主节点 | 画布视图状态 |
| `状态提示` | 没有找到、多项匹配、节点或工作流已变化等情况显示在面板内 | STRING |

## 使用示例

假设主图的 `771` 是“生成渠道汇报”，其中 `745` 是“工作流输入准备”，`729` 位于 745 内：

1. 在主图或任意其他子图按 Ctrl+F。
2. 输入 `729`，结果显示 `主图 → 生成渠道汇报 (#771) → 工作流输入准备 (#745)`。
3. 按 Enter，依次打开 771、745，选中并居中 729。
4. 也可以直接输入 `771:745:729`，准确选择这一条实例路径。

若三个不同子图都有 `659`，输入 `659` 会显示三条结果；点击所需路径。搜索 `65` 不会匹配 `659`，数字编号不按前缀匹配。输入 `渠道汇报` 则按名称查找；若有多个结果，必须选择其中一项后才跳转。

## 搜索历史

- 焦点在搜索输入框时，按 **↑** 回填更早的搜索词，按 **↓** 回填较新的搜索词；到达最早或最新位置后不循环。
- 首次按 ↑ 时保留当前正在输入的草稿，按 ↓ 回到历史末尾会恢复草稿。修改回填的文字后，会以修改后的内容作为新的草稿。
- 回填会立即刷新候选列表，但不自动定位；仍需按 Enter 或选择结果。输入法组合输入期间，以及带 Ctrl、Alt、Shift 或 Command 的方向键不触发历史回填。
- 按 Enter、点击“定位”、选择结果或关闭面板时记录非空搜索词；不把输入过程中的每个字都记入历史。没有匹配结果的查询也可以找回。
- 最近使用的词放在末尾，同样文字去重，最多保存 50 条。历史保存在当前浏览器、当前站点的本地存储中，刷新后保留，各工作流共用；不会写入工作流文件或随文件传到其他电脑。浏览器不允许存储时，仍可在当前页面内使用历史。

## 定位缩放与返回父图

- 普通节点按约 **190%** 缩放定位，对应大约 220 画布单位宽的节点在屏幕上显示为 418 CSS 像素，接近示例截图的可读尺寸。
- 大节点会适当缩小：为标题和标记预留宽 40、高 80 画布单位，再按画布可见宽高的 80% 计算适配比例；实际缩放取该比例和 190% 中较小者，仍受原生画布缩放范围约束。
- 定位使用当前画布尺寸和设备像素比计算，不改变节点本身的尺寸或位置。
- 例如从 729 返回上一层，视窗聚焦 745；再返回主图，聚焦 771。直接从深层点击主图导航，也聚焦 771。
- 进入子图前先聚焦其宿主，让原生视图缓存记录该位置；退出时等待原生视图恢复，再重新聚焦正确宿主。共用同一子图定义的多个实例，按本次实际选择的宿主路径处理。
- 后续手动打开其他子图时会更新返回路径，避免回到原来搜索的另一个实例。切换工作流会清空此临时路径，不跨工作流定位，也不把搜索路径保存进文件。

## 子图与重名编号

- 搜索从当前工作流主图开始，无论打开面板时在哪个子图，搜索范围都一致。
- 搜索沿实际宿主节点进入子图，不仅扫描定义表。同一子图有多个宿主实例时，各路径分别保留。
- 定位使用原生 `setGraph`、`openSubgraph`，保留原生子图导航事件及返回入口，不重新载入工作流。
- 子图切换可能沿用 ComfyUI 原生的视图恢复或适配缩放；等待该步骤后再按上述定位比例聚焦目标。已经在目标图时，也调整到定位比例。
- 折叠节点仍可定位，不自动展开或改变节点大小。只搜索普通节点和子图宿主，不搜索 `-10`、`-20` 这样的子图虚拟边界编号。

## 快捷键、焦点与保存

- Ctrl+F 在 ComfyUI 页面内替代浏览器查找，包括焦点位于文本框时；其他网站不受影响。Ctrl+Shift+F 不被本功能拦截。
- 全局处理 Ctrl+F 和面板打开时的 Esc；历史 ↑／↓ 仅在搜索输入框内处理。中文输入法组合输入期间不触发快捷键。
- 面板不使用模态遮罩，不持续强制聚焦。关闭或定位完成时，仅在页面仍处于前台时恢复焦点。
- 查找不修改节点坐标、尺寸、内容、端口或连线，搜索历史仅保存在浏览器本地。图导航、选择和视窗位置按 ComfyUI 原有机制处理，不主动保存工作流或清除未保存标记。
- 切换或重新加载工作流后关闭面板并取消待完成的定位。点击结果前还会检查目标是否仍属于当前工作流；节点删除后会提示重新查找。

## 常见问题

| 现象 | 说明或处理 |
| --- | --- |
| Ctrl+F 仍打开浏览器查找 | 更新前端脚本后刷新页面，必要时 Ctrl+F5；确认本包前端没有被禁用，无需重启后端 |
| 提示没有找到 | 确认当前标签页是目标工作流，编号与节点 ID 标记一致；这里只搜索当前已加载内容 |
| 相同编号或名称出现多次 | 按完整层级选择，或输入 `宿主ID:内部宿主ID:节点ID`；回车不会擅自跳转第一项 |
| 编号来自后端错误报告 | 如 `771:745:729` 可直接搜索；运行时动态生成的循环内部临时 ID 并非保存节点 ID，应使用报告中的原始显示节点编号 |
| 提示工作流或节点已变化 | 重新输入或点击定位，获取当前图中的结果 |
| 大节点定位后不到 190% | 为尽可能显示完整节点，会按可见区域缩小；定位后仍可正常滚轮调整 |

## 开发与验证

历史测试覆盖上下回填、边界不循环、草稿恢复、编辑后重置位置、去重与 50 条上限、跨页面上下文恢复，以及输入法与修饰键不受影响。

`node_find.js` 通过 `app.registerExtension` 注册 `liuxinyu.NodeFind`，沿用包根目录 `WEB_DIRECTORY = "."` 的前端加载方式，样式在 `node_find.css`。按宿主路径递归搜索时使用分支级循环检测，防止异常递归引用，同时保留共享子图的各个实例。

居中使用与“视窗回归原点”相同坐标体系的原生 `centerOnNode`，缩放使用 `setZoom`。逐层打开后等待渲染帧，避免原生视图恢复覆盖定位结果。监听 `litegraph:set-graph` 与 `subgraph-opened` 更新宿主路径并处理返回聚焦；节点原始名称参照 `original_node_name.js` 的定义缓存方式。无需修改核心、后端 API 或节点注册映射。

运行 `node tests/test_node_find.cjs` 检查 ID 精确匹配、名称部分匹配与大小写、完整路径、重复实例、多结果回车不跳转、循环引用、嵌套导航、190% 缩放与大节点适配、逐层返回及直接返回主图、手动进入其他实例、原生延迟视图恢复、失效目标、工作流切换取消，以及快捷键和面板生命周期。可追加本机前端 bundle 路径作为第一个参数，直接使用其真实 `openSubgraph` / `centerOnNode` 方法验证；第二个参数可传任意保存的 UI 工作流 JSON，只读核对其中全部节点的 ID、实例路径和重复编号，不依赖历史节点仍然存在。页面的实际视觉显示与快捷键交互仍需刷新后验收。
