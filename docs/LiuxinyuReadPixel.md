# 读取图片像素 RGB

读取指定位置的红、绿、蓝通道值，输出三个 0～255 的整数。用于检查某点颜色、比较处理前后颜色，或把采样颜色交给改色节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 |
|---|---|---|---|
| `图片` | 要采样的 IMAGE 批次，须为非空浮点张量 [批次, 高度, 宽度, 通道]，支持灰度、RGB、RGBA | IMAGE | 是 |
| `X` | 从左向右的像素位置，从 0 开始，默认 0 | INT | 否 |
| `Y` | 从上向下的像素位置，从 0 开始，默认 0 | INT | 否 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---|---|---|
| `R` | 红色通道值（0～255）。执行列表，下游逐项处理：批次每张图各产生一项，按图片顺序对应 | INT |
| `G` | 绿色通道值（0～255）。执行列表，同 R 按批次逐张输出 | INT |
| `B` | 蓝色通道值（0～255）。执行列表，同 R 按批次逐张输出 | INT |

## 怎么用

1. 将加载或生成的图片接“图片”。
2. X 是从左向右的位置，Y 是从上向下的位置，均从 **0** 开始。
3. R、G、B 输出分别接数值显示或后续计算节点。

例如一张宽 790、高 1000 的图，左上角是 X=0、Y=0，右下角是 X=789、Y=999。读取红色像素会得到 R=255、G=0、B=0。X=790 已越界。

## 多张图片

同一批次有 3 张图时，会读取每张图的同一 X/Y，三个输出各自形成含 3 项的执行列表，按图片顺序对应。普通下游会逐项处理，不会自动把颜色求平均。

本节点没有 Z 选择输入；要只读某一张，先在上游选出那张图。

## 数值规则

图片内部通常用 0～1 浮点数；读取时限制在该范围，乘 255 后取最近整数，恰好半整数时取偶数。灰度图三个通道相同；RGBA 忽略透明度，读取透明像素时仍返回它存储的 RGB。

读取不会改变图片。所选位置越界或包含 NaN/无穷大时会报错。
