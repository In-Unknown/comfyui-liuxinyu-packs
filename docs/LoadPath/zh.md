# 加载路径

LoadPath 节点通过系统原生文件选择对话框选取文件路径，输出完整路径、文件名、无后缀文件名和后缀。若文件为图片则显示预览。可手动输入或通过下方的「选择文件」按钮选择文件。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `文件路径` | 文件的绝对路径。可点击下方的「选择文件」按钮调用系统原生对话框进行选择，也可手动输入。 | `STRING` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `完整路径` | 所选文件的完整绝对路径。 | `STRING` |
| `文件名` | 文件名（含扩展名）。 | `STRING` |
| `无后缀文件名` | 文件名（不含扩展名）。 | `STRING` |
| `后缀` | 文件后缀（最后一个「.」后的字符，无则空）。 | `STRING` |
