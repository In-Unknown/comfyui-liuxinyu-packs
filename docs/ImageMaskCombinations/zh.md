# 遮罩区域图片排列组合

ImageMaskCombinations 节点接收多张同尺寸候选图片和一张遮罩，穷举所有有序对 `(i, j)` 组合：以图片 i 为底图，在遮罩白色区域内贴入图片 j，黑色区域保留底图，灰阶按透明度混合。输出全部合成结果的图片批次，并同步输出与批次逐张对齐的组合索引字符串列表。适合在一次生成多个候选后，快速穷举某个局部区域的替换方案，挑选局部最优结果。

## 输入

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `候选图片` | 动态增长的图片端口。第一个端口为必填（实心），每连接一个端口，下方会自动出现一个新的可选端口（空心），最多 50 个。每个端口可接单张图片或图片批次，所有图片最终展平为同一个候选序列，编号从 0 开始。所有图片必须同尺寸。 | `IMAGE` |
| `遮罩` | 合成遮罩。白色表示用贴入图替换的区域，黑色保留底图，灰阶为半透明混合。尺寸与图片不一致时自动按最近邻缩放对齐；若输入遮罩批次，取第一张。 | `MASK` |
| `包含自身组合` | 关闭（默认）时输出 N×(N-1) 个组合，排除 `i=j`（结果与原图相同）的无意义组合；开启时输出 N×N 个组合，对角线为各候选原图，可作为对照基线。 | `BOOLEAN` |

## 输出

| 字段 | 描述 | 数据类型 |
| --- | --- | --- |
| `合成图片` | 全部组合的图片批次，按底图 i 优先、贴入图 j 次之的行优先顺序排列。 | `IMAGE` |
| `组合索引` | 字符串列表，与合成图片批次逐张对齐，格式为 `底图->贴入图`，例如 `0->2` 表示以第 0 张为底、在遮罩区域贴入第 2 张。 | `STRING`（列表） |
